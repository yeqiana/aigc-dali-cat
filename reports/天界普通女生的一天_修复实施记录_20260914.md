## R-20260914-05 Authority / Continuation Candidate Budget 语义修复

### 暴露

Ledger 已把 authority-refresh 与 user-continuation 视为独立直接用户授权，但 Raw Candidate Budget 仍把它们算进 ordinary repair，导致 repair bucket 用完后必须人工写 override。

### 实施

- 新增 `authority_refresh` raw-budget lane：semantic key = Frame Contract SHA；每个直接用户授权的新合同最多 1 张 retained candidate。
- 新增 `user_continuation` raw-budget lane：semantic key = continuation capture id/index；每次明确用户继续最多 1 张 retained candidate。
- 两者都不重置、不借用 ordinary repair/user-exception；技术失败可释放未提交 claim；仍受 Episode 总候选预算限制。
- image worker / batch worker / production recovery / product image import / blocked RAW recovery 全部传递 semantic key。

### 验证

`tests/system/test_authority_refresh_budget.py` 覆盖同合同只允许一张、新合同需新的匹配授权、continuation index 一次一张、普通 repair 用满后不影响 authority lane。

状态：✅ 完成。
