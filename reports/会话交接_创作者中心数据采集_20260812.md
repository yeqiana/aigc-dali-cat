## 四、浏览器连接方案（重要：踩过坑，别重走）

### 4.1 用户 Chrome 已打开创作者中心，但本会话无法直接控制

- Chrome 扩展（Codex 浏览器插件）已安装且启用，native host 注册正确。
- **但浏览器控制需要特权执行通道（`mcp__node_repl__js`），当前会话没有暴露该工具**，直接运行 `browser-client.mjs` 报错：`Browser use requires privileged node_repl capabilities`。
- 用户主 Chrome 进程（PID 175000）**未开启** `--remote-debugging-port`，无法 CDP 连接。

### 4.2 已尝试且失败的路径（接手会话不要重复）

| 方案 | 结果 |
|---|---|
| 直接 import `browser-client.mjs` 连接 | 失败：需要特权 node_repl |
| 复制 Chrome 用户 profile 的 Cookies | 失败：`Cookies` 文件被 Chrome 进程独占锁定（`IOException`） |
| 用 .NET FileShare.ReadWrite 读 Cookies | 未成功（策略拦截/文件锁定） |
| `sqlite3` 直接读源 Cookies 库 | 失败：`unable to open database file` |
| 无头 Playwright 遗留 profile | 无抖音登录态，不可用 |

### 4.3 可行的接手路径（推荐按顺序尝试）

1. **首选：让新会话先尝试 tool discovery 找 `node_repl js` 工具**（`tool_search` 搜 `node_repl js`，limit 10）。找到后按 Chrome 插件 SKILL 流程连接：`setupBrowserRuntime()` -> `agent.browsers.get("chrome")` -> 读取当前打开标签页。
2. **备选：Playwright CLI（已在项目环境可用）**：
   - `cmd /c "npx --yes --package @playwright/cli playwright-cli open https://creator.douyin.com/creator-micro/content/manage --headed --browser chrome"`
   - 该浏览器无登录态，会要求扫码/登录，需要用户配合在弹出窗口完成一次登录（若用户 Chrome 已登录，可用"扫码登录"或直接输入账号密码）。
   - 登录后立即 `state-save` 保存登录态文件，后续用 `state-load` 复用。
   - 采集命令：`snapshot`、`eval`、`find`、`screenshot`。
3. **兜底：请用户手动在创作者中心复制数据贴给会话**（逐篇：播放/点赞/评论/收藏/分享/吸粉/均浏览图/划走率），会话负责整理进报告。
