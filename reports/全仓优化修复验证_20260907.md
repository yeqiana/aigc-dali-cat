## 实际行为与边界

| 情况 | 处理 |
|---|---|
| 限流、超时、临时服务故障 | 有界重试，失败帧单独处理；成功帧保留 |
| 某帧不可继续但其他帧依赖满足 | 优先继续独立帧 |
| WORK/WEB 宿主动作 | 记录 HOST_WAIT 与可执行请求，不改为假审批或忙循环 |
| 图片已生成但账本提交失败 | worker lifecycle 保存 transaction id、PID、输出、终态 result 与 provider receipt；恢复时重新走 Ledger 的正常验证后再补 Queue，不重复生成 |
| 账本已成功但队列未写入 | 从 Ledger 当前 candidate 回放 Queue 的 `generated` 状态；不改 Episode stage |
| 调用已发出但没有 worker 终态 receipt | 标为 `interrupted_unknown`，不自动重试、不伪造通过；无依赖的兄弟帧仍可继续 |
| 无进度的成功退出 | 有界检测后能力等待，不能无限空转 |
| 正式阶段推进 | 仍由 canonical stage + 实际证据验收；不能用 warning 豁免 |
