## 二、对标基准

### 鼠鼠（传播效率）

#### 2.1 已知结构差异

| 维度 | 鼠鼠 | 我们 |
|------|------|------|
| 叙事结构 | 第一人称 + 日常裂缝 + 短平快 | 同结构 + 系列视觉母题 + 连环证据 |
| 节奏 | 短篇快节奏，单篇独立 | 首篇 35 张偏长，需压到 20-25 张 |
| 评论区 | 围绕未解钩子激烈争论 | 折多山 0 评论，钩子未触达 |
| 视觉 | 随手拍不完美 | 角色锁定 + CRT 母题 + 伪纪录片质感 |
| 世界观 | 单篇自治，无跨篇连接 | 108 道班轻量世界观，冷启动不展开 |

#### 2.2 鼠鼠关键数据（外部观察，非精确）

#### 2.3 鼠鼠结构自评框架

每篇验收时，对照以下鼠鼠结构要素自评（是/否）：

- [ ] 第一人称 + 身份即时代入（前 3 句）
- [ ] 日常动机 + 情绪锚点（考研失败散心级）
- [ ] 具体异常（单张识别，非"感觉不对"）
- [ ] 合理解释 -> 证据推翻
- [ ] 渐进升级（不一次讲完）
- [ ] 结尾留白（事实层 + 解释层双钩子）
- [ ] 评论区分裂启动（评论区有争论）

### Zayn（世界观深度）

#### 2.4 已知结构差异

| 维度 | Zayn | 我们 |
|------|------|------|
| 世界观包装 | 伪档案/伪机构风格，成熟厚重 | 108 道班轻量世界观，冷启动不展开 |
| 叙事密度 | 单篇信息量大，需读者投入 | 单篇自治，不要求补课 |
| 跨篇连接 | 强连接，多角色多线索交织 | 冷启动每篇只允 1 条暗线 |
| 节奏 | 慢，氛围优先 | 比 Zayn 更快，信息节奏更紧凑 |
| 视觉 | 档案质感、资料卡片、机构文件 | 随手拍不完美 + CRT 电视母题 |
| 目标读者 | 深度悬疑受众，愿意追系列 | 鼠鼠式碎片化刷到的路人 |

#### 2.5 Zayn 关键数据（外部观察，非精确）

| 指标 | Zayn 表现 | 我们当前 |
|------|------|:--:|
| 内容形态 | 图文为主，35 篇作品 | 图文，16 篇已发布统计样本 |
| 单篇篇幅 | 偏长，信息密集 | 35 张偏长，需压缩 |
| 系列连接强度 | 强（需追看理解全貌） | 弱（每篇自治） |
| 粉丝黏性 | 高（核心粉深度互动） | 47 粉；仍处冷启动 |
| 新读者门槛 | 较高 | 低（冷启动核心竞争力） |
| 发布模式 | 偶尔一天两次 | 周 2-3 篇目标 |

#### 2.6 Zayn 结构自评框架

每篇验收时，对照以下 Zayn 结构要素自评（是/否）：

- [ ] 世界观信息通过证据链自然露出（非字幕硬塞设定）
- [ ] 至少 1 个"资料/档案"类实物证据（照片背面字、考勤表、工作证等）
- [ ] 系列视觉母题在关键节点承担剧情信息（非装饰）
- [ ] 单篇自治（新读者不需前作理解基本冲突）
- [ ] 节奏比 Zayn 更快（每 5-6 张必须有信息变化）
- [ ] 伪档案/机构视觉语言统一（冷启动不强求）
