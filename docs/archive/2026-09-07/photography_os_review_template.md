# Photography OS 回归评审模板 V1.0

> 用途：Photography OS Regression Test 的人工评审记录模板。评审人填写后，本文件可直接作为下一轮 Codex 回归测试任务的输入。
> 关联规则：[`rules/photography_os_default_rules.md`](photography_os_default_rules.md)
> 关联语法：`standards/capture_grammars/FIRST_PERSON_CASUAL_SNAPSHOT_V1.json`
> 权威口径：NON_AUTHORITY_TEST_ONLY；本模板不推进任何 episode stage。

---

## 0. 使用说明

1. Codex 按模板第 9 节执行回归测试，产出 `meta/tests/photography-os/<run_id>/`（契约、图片、report）。
2. 人工按第 1-8 节评审并回填；评分 0-10，给出依据。
3. 回填完成后把本模板（或其中"下一轮执行指令"节）交给 Codex，作为下一轮输入。
4. 结论映射：
   - `PASS` → 可扩测（01-10 / 下一篇作品）或进入 Visual Lock；
   - `CONDITIONAL_PASS` → 修复指定缺陷后重测；
   - `FAIL` → 先修摄影者锚点 / 前 3 张人物关系，再重测。

## 3. 分项评审

### 3.1 真实摄影感（权重最高）

- 分数：{8.9}
- 优点：{车内视角 / 停车路边随手拍 / 夜间低光 / 手持手机介入 / 生活性构图 / "我当下就是顺手拍一下"的味道}
- 问题：{个别图仍偏"记录景物"而非"必须拍它"}
- 改进建议：{每张图优先满足"这张不是因为好看才拍，是因为当下必须拍"}

### 3.2 第一人称执行

- 分数：{8.2}
- 优点：{车内视角、拿手机拍的视角、摄影者站旁边拍同伴、"我在现场，我看到，我记录"的感觉}
- 问题：{固定摄影者身份不够稳：到底谁在拍 / 是主角本人还是同行者 / 司机还是同伴互拍，锚点不够强}
- 改进建议：{默认固定一个主要摄影者并贯穿 01-05；例如"默认摄影者为同行女主本人，仅在有明确理由时允许同伴替她拍"，或"默认摄影者为同行者 A，主角只在必要时入镜"}

### 3.3 人物关系建立（前 3 张）

- 分数：{7.6}
- 优点：{有旅行感、路上感、异常感、情绪感}
- 问题：{前 3 张偏风景/车/山路/远处东西，"彼此"的同行感、命运绑定感不够浓}
- 改进建议：{前 3 张至少两张包含：车内有人回头说话、副驾/后排人物局部、某人下车看路牌另一个人在车里拍、同伴的手/包/手机/外套/动作、某人正在拍某人正在看}

### 3.4 情绪推进

- 分数：{8.8}
- 优点：{情绪线清楚：01-02 普通出行 → 03-04 不对劲、拍证据 → 05 情绪落到人身上；"异常不是风景，而是正在伤害人"}
- 问题：{}
- 改进建议：{保持情绪爬坡，避免每张都像说明图}

### 3.5 动作进行时 / 代入感

- 分数：{8.7}
- 优点：{正在开车、正在停车、正在拍远处亮点、正在夜里观察、正在情绪崩溃；不是"展示结果"}
- 问题：{部分山体/路边图更像"我到过这里"而非"我此刻因为这件事必须拍它"}
- 改进建议：{每帧明确"必须拍"的动作理由，写入 Moment Contract}

## 4. 提示词评审

- 优点：{目标/范围明确；启用项（FIRST_PERSON_CASUAL_SNAPSHOT / Photographer / Moment / Opening Memory / Emotion Curve）到位；禁止旧图/旧 Visual Test/复用历史，回归干净；每张强制回答 5 问}
- 关键缺口：{缺少"固定摄影者身份 + 前 3 张优先人物关系而不是风景"的强约束；否则模型易滑回"旅行风景照 + 少量剧情图"}

## 8. 下一步建议

推荐顺序：

1. 用同样方法把本作品扩到 **01-10**，重点看前期人物关系、异常进入后是否丢相册感、连续 10 张摄影者身份是否漂移。
2. 再拿一篇已完成作品（如《瓶中世界》/《怪物旧谈》）做同类测试。
3. 两篇都明显提升后，再考虑把规则升成 Story OS V2.2 核心能力。

## 9. 下一轮执行指令（可直接交给 Codex）

> 把下面内容（含元信息替换）作为 Codex 任务输入。以下为强化版标准回归测试提示词。

```text
读取 story 分支。

执行《彼此的天上》Photography OS Regression Test。

目标：
不是完整生产。
只验证 Story OS V2.1.5 Photography OS 是否提升真实摄影感与人物代入感。

测试范围：
Frame 01-05（可扩展为 01-10，见元信息）。

必须启用：
- FIRST_PERSON_CASUAL_SNAPSHOT
- Photographer Contract
- Moment Contract
- Opening Memory Contract
- Emotion Curve

必须遵守：
- 默认固定一个主要摄影者，身份明确并贯穿全部帧
- 每张图都要像真实手机相册里的照片
- 每张图优先表现"事情正在发生"，不是展示结果
- 前 01-03 必须优先建立人物关系、同行状态、日常感，不要过早变成纯风景照
- 异常从 04 开始进入
- 05 必须体现异常对人物情绪的影响

禁止：
- 使用旧图片
- 使用旧 Visual Test
- 使用旧 Frame 输出
- 复用历史生成结果
- 生成过于完整、海报化、导演式、第三人称展示图
- 连续多张纯风景图削弱人物存在
- 相机界面/手机屏幕入画（物理不可能）

重新生成：
01-05 五张测试图。

要求：
像一个年轻人在真实经历这件事时，用手机留下的照片。
允许轻微偏构图、遮挡、反光、手抖、局部模糊、低光噪点，但不要故意过度做旧。

每张必须回答：
1. 谁拍的？
2. 为什么此刻拍？
3. 摄影者在哪里？
4. 当时正在发生什么动作？
5. 人物情绪是什么？

额外要求：
- 每张图要说明这张图为什么值得被保存在手机里
- 每张图要避免"只是漂亮"
- 更重视生活感、关系感、异常介入感

输出：
- 图片
- Frame Contract
- Photographer Contract
- Moment Contract
- Opening Memory Contract
- Emotion Curve
- 生成耗时
- 与旧版差异说明

不要进入完整 Production。
```
