## 四、`.storyos_tmp/` 明细（55 个文件 / 11.66 MB）

| 子类 | 数量 | 示例 | 判定 |
| --- | --- | --- | --- |
| 一次性会话探针脚本（`.py`） | 约 45 | `probe_*.py`、`show*.py`、`release_*.py`、`patch_*.py`、`fill_*.py` | 历史会话临时工具，非 Runtime 依赖 |
| 预览与产物图 | 8 | `a01_prev.jpg`、`p01_prev.jpg`、`release-critic/*.png`（6 张） | 评审预览，非正式资产 |
| 文本与脚本 | 3 | `probe2.txt`、`style_intro.txt`、`_session_cleanup.ps1` | 会话辅助 |

引用扫描结果：全仓仅 3 处引用 `.storyos_tmp`，且都位于 workbench 探针脚本内部：

- `workbench/_rel_critic.py:22` → `root / '.storyos_tmp/release-critic'`
- `workbench/_rel_critic2.py:24` → 同上
- `workbench/_rel_stage.py:9` → 同上

结论：`.storyos_tmp` 不被 `episodes/_system/` 任何 Runtime 代码引用，属一次性会话产物。归档前只需确认上述 3 个 workbench 脚本不再需要运行（它们本身也是历史探针）。

注：`.storyos_tmp/*.jpg` 与 `release-critic/*.png` 当前处于 Git 跟踪状态，与「图片默认本地保留」的提交规则不一致，可在归档时一并按本地派生物处理，无需单独提交图片。
