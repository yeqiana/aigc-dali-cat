## 二、字幕系统

### 样式参数

| 项目 | 值 |
|------|-----|
| 字体 | SimHei 黑体 (C:\Windows\Fonts\simhei.ttf) |
| 字号 | 固定 64px |
| 颜色 | 白色 #FFFFFF |
| 描边 | 黑色 #000000，宽度 5-6px |
| 位置 | 单行 78%、双行 72%、三行 66%（距顶部） |
| 最大宽度 | 画面宽的 82% |
| 换行 | 智能中文换行（优先标点处断，防止单字孤儿行） |
