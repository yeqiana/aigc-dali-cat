## 四、什么可以删除

删除必须满足全部条件：

1. 内容已被后续文档完整覆盖；
2. 不是验收/审计/事故原始证据；
3. 全仓引用扫描为 0，或引用已同步更新；
4. 不承担当前规范/入口角色；
5. Git 历史足以恢复且删除理由写入治理记录。

当前旧治理文档明确要求历史验收证据不删除。因此本轮对尚未证明“完全重复”的文档优先**归档而非 rm**。

## 五、active docs 最终目标

```text
docs/
├── README.md
├── standards/          # 当前强制规范
├── architecture/       # 当前有效架构，不放历史实现流水账
├── governance/         # 当前治理策略/审计入口
├── runbooks/           # 当前运行手册
├── templates/
└── archive/            # 历史设计/实现/冻结未来设计
```

目标不是追求“文档越少越好”，而是让 AI/人打开 `docs/` 时默认读到当前事实，而不是把 2026-09-09 的旧阶段设计误当今天的生产权威。
