# StoryOS Episode 阶段权威矩阵（2026-10-10）

这是代码约定说明，**不是新的运行时 Gate 或第二份状态文件**。唯一入口为 `episodes/_system/episode_state_persistence.py`，模式取自 `storage_config.episode_meta_store_config()["mode"]`。

| mode | Canonical 读取 | JSON 文件 | 错误处理 |
| --- | --- | --- | --- |
| `mysql` | MySQL | 非 Authority，不能故障回退 | MySQL 读取异常向上抛出；记录不存在不能从 JSON 复活 |
| `dual` | 优先 MySQL，兼容回退 JSON | 迁移兼容投影/备选读取，不能凌驾于已读到的 MySQL | 遵守 `load_with_source` 现有兼容规则，禁止另建读取器 |
| `json` | Episode 本地 JSON | 文件权威 | 按当前文件校验语义 |

`AGENTS.md` 与 `SKILL.md` 是给开发和执行代理读取的入口，既有“唯一文件阶段事实源”口径属于历史 JSON 时代的简写。以后不得以该简写为由覆盖 MySQL 权威。

## 非权威区

- `meta/story-gates.json`、Review/Pixel Evidence、Generation Attempt、Revision、Ledger 具有各自的专有事实与合同，但不代替 Episode stage。
- Runtime Trace、执行回执、Checkpoint、Redis Hot State、UI 投影绝不能另造 stage 或在 MySQL 故障时放宽门禁。
- 正式写入只允许当前持久化事务和既有 transition/gate 流程；不存在的 JSON 不等于阶段丢失。

## 改造边界

本轮不改变 `load_with_source`、MySQL 或 JSON 文件，不自动迁移 Episode，也不触发付费生产。后续需要在真实双 Episode Canary 中独立核验恢复语义。
