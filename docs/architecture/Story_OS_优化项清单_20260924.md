# Story OS 优化项清单

> 记录 2026-09-22 ~ 2026-09-24 提出的提速 / 省 token / 提质量 / 稳生产优化项与落地状态。
> 本文是进度盘点，不是创作规范、生产配置、门禁或第二状态机。

## 0. 结论与口径

核心目标：用本地确定性算法替代一部分 LLM 视觉审核，提速 + 省 token + 提质量，同时修稳生产（尤其 MySQL 连接）。

已落地：本地视觉工具影子诊断、字幕位置直过、一批就地 bug 修复、性能埋点。

**口径红线：净提速 / 省 token 至今没有真实跑批数据背书。** 现有数据全部是《东海龙宫》《误入桃花源》的离线回放推断，不能据其宣称已取得生产提速。

## 1. 主线一：本地视觉工具接入（提速 / 省 token 主战场）

落点：`episodes/_system/`、`config/storyos.yaml`；配套文档 `docs/architecture/`。

| 能力 | 作用 | 状态 |
| --- | --- | --- |
| RapidOCR + ONNX | 检测原图文字与字幕矩形重叠（字幕盖字），省去视觉模型重复查坐标 | ✅ 已接入影子诊断 + 字幕审核入口 |
| OpenCV YuNet | Visual Lock baseline 人脸框候选，减少模型处理纯坐标问题 | ✅ 已接入影子诊断（`visual_face_diagnostic.py`） |
| OpenCV SFace | 角色母版相似度排序，提前揪出漂移帧 | ⏸ 离线（`identity_sface_diagnostic.py`，样本不足） |
| Pillow ImageChops | 发布前字幕像素完整性检查（对比底图/发布图，只允许字幕区变化） | ✅ 已接入发布前 |
| 本地字幕位置直过 | 满足「语义审核已过 + OCR 完整无重叠 + 布局/渲染完整」即本地放行，跳过该帧视觉 Critic | ✅ 已接入（`local_gate_enabled=true`） |
| gate_hint | 把 OCR/人脸阳性提示注入仍要运行的 Critic 上下文 | ✅ 已接入（`gate_hint=true`） |

配置键（`config/storyos.yaml`）：

- `runtime.review.local_vision_shadow.enabled`：是否运行 RapidOCR / YuNet 影子诊断。
- `runtime.review.local_vision_shadow.gate_hint`：是否把影子阳性提示注入 Critic。
- `runtime.review.local_gate_enabled`：是否启用本地字幕位置直过（默认开）。

关键取舍（用户已确认）：**位置检查通过即整帧放行，接受「字幕盖住人脸 / 手部 / 道具 / 线索」的漏检风险。** 关闭 `local_gate_enabled` 即恢复全量审核。

## 2. 主线二：审核逻辑与门禁调整

- **字幕审核时机前移**：从「渲染到图上再审核」改为「字幕生产后就审核内容对不对」。方向已确认；代码体现为 `caption_mode=deferred_until_production_ready` + 字幕语义证据绑定当前字幕 SHA。🔶 需在真实集验证。
- **本地直过开关**：默认打开，本地工具直接审、不走 LLM 视觉；可切换是否进正式门禁。✅ 已落地。
- **原则不变**：FULL / PATCH Review、Evidence Gate、`episode-state.json` 阶段推进仍是权威；本地工具只产出可重建的派生诊断，不授予 PASS。

---

## 3. 主线三：性能观测 / 埋点

- `episode_performance.py` 补 FULL / PATCH Review 计时：尝试次数、目标帧数、分片数、耗时，区分 Active / HOST_WAIT / USER_WAIT / IDLE。
- `frame_semantic_review.py` / `incremental_frame_review.py` 审核入口计时，异常与中断路径也收口。
- 字幕审核遥测埋点：`summary.vision_review_telemetry` 的 `local_skipped_frames / vision_call_count / vision_elapsed_seconds / vision_tokens`。
- `quota_observability` 日志计数（best effort，不等于订阅额度）。

🔶 均属「先埋点」，真实数字要等跑批后才读得出来。

## 4. 主线四：稳定性与正确性就地修复

| 位置 | 修复 |
| --- | --- |
| `platform/repository/mysql/mysql_connection.py` + `mysql_connection_pool.py` | 远程 MySQL 走 NAT 被 RST（2013 / WinError 10054）：read/write timeout 10→60、池 `ping=7`（执行前探活重连）、重连退避重试 3 次（0.5s/1.0s） |
| `evidence_gate.py` | `run_gate` 改走 `episode_state_persistence.load()`，兼容 MySQL 权威模式（本地无 `episode-state.json`） |
| `runtime_observability.py` | `generated_at` 每次刷新，修指标快照排序错乱 |
| `preimage_task_contract.py` | `source_authority_sha256` 回填权威值，不再因 scoped worker 截断嵌套 map 而误判 |
| `environment_contract.py` | daypart 推断按文本最早出现，「night after dusk」不再误判成 dusk |
| `story_creator.py` | `series` 字段从空串改为标题 |
| `caption_ocr_diagnostic.py` / `local_vision_shadow.py` | `_pin_stdlib_platform()` 修 RapidOCR 被本地 `platform` 模块遮蔽的导入 bug |

以上为当前工作区**未提交**改动（`git diff` 10 个文件 +48 行）。

## 5. 已评估、暂缓 / 不引入

| 项 | 原因 |
| --- | --- |
| BGE 中文向量检索（选题去同质化） | 故事指纹库仅 2 篇、`sample_size=0`，不足以验证召回 |
| SQLite FTS5 | 中文分词 / 别名召回未验证 |
| YOLO / CLIP / FAISS / 向量库 / 工作流框架 / 本地 LLM | 不能替代核心语义审核，徒增模型与依赖维护面 |
