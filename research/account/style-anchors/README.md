# 账号共享风格锚点

这里存放经过人工确认的少量成片，用于学习**采集质感**，不是复制剧情、人物、地点或构图。

## 状态

- `candidate`：根据正式分镜 / 缩略图 / 对照板提出，尚未看最终单张成片；
- `locked`：已逐张看最终 publish 成片，并通过真实性与连续性复审；
- `rejected`：曾进入候选，但因电影感、设备漂移、构图过度设计等原因淘汰。

没有最终单张实图证据时，**禁止写 `locked`**。

## 风格体系

- `M00_县镇现实侵入式手机纪实/`
- `F01_流水席_暖噪人群民俗/`
- `F02_村子_冷灰返乡旧数码/`
- `F03_旧镇_湿灰漂泊生活/`

每个子风格最终只保留 3–5 张。
