# Workflow: Extend

## 适用场景
在已有稳定页面或组件内新增视图区块、新指标列、辅助动作或扩展抽屉。

## 执行步骤
1. **检查既有资产**：复用既有 Design Tokens、Status Tokens 及已有公共组件。
2. **Preflight 确认**：Task Type = EXTEND，识别是否需要只读扩展前端 Contract。
3. **分层实现**：
   - 核心视图保持原有布局与响应式流；
   - 新增内容在既有设计语言中自然延展，保持一致视觉密度与等宽/非等宽字体规范。
4. **边界覆盖**：检查 Empty、Loading、溢出与极端数量。
5. **验证**：执行模块级集成验证与桌面视口检查。
