# 一、母风格 M00：县镇现实侵入式手机纪实

## 1.1 一句话定义

> **像某个普通人真的回过一次村、进过一次席、住过一次小镇，然后把不对劲的事顺手拍了下来。**

这三篇共享的不是“恐怖滤镜”，而是：

> **中国县镇 / 乡村现实空间里的私人记录感；异常必须从现实里长出来，不能压过现实。**

观众第一反应应当是：

> “这地方 / 这辆车 / 这桌饭 / 这条路真像我见过。”

第二反应才是：

> “等一下，里面是不是有东西不对？”

## 1.2 使用范围

M00 是**可选视觉母风格**，不是全账号强制风格。

- 采用 M00：必须登记主子风格，执行本细则；
- 不采用 M00：继续执行主规范通用真实性要求；
- 科考、神话遗址、古籍志怪、特殊实验记录等若有独立采集语言，不得被强行套入 M00；
- 任何系列都不能因为“共享风格”而豁免主规范“四把锁”。

## 1.3 母风格优先级

`现实成立 > 拍摄行为成立 > 年代/地域成立 > 人物/道具连续 > 异常可读 > 氛围 > 漂亮`

如果“更漂亮”和“更像真的”冲突：

> **选更像真的。**

如果“更恐怖”和“更像普通生活”冲突：

> **先保普通生活，再让异常侵入。**

# 二、M00 的八个视觉 DNA

## 2.1 空间：先有生活，再有异常

优先出现真实中国县镇 / 乡村 / 小镇的生活结构：

- 县乡中巴、旧客运点、村口、小卖部、普通民房；
- 土路、旧水泥路、山路、临时岔路、低矮围墙、电线杆；
- 普通饭桌、塑料凳、搪瓷杯、风扇、旧窗帘、廉价家具；
- 临时棚子、裸灯泡、圆桌、蒸碗、扣肉、汤盆、一次性餐具；
- 老旅店、小商店、卷帘门、旧招牌、潮湿楼梯、窄巷；
- 与剧情无关但合理存在的生活杂物。

**禁止为了“干净”删掉所有生活杂物。**

真实感的重要来源之一：

> 画面里有一些“导演根本没必要安排，但生活中本来就会有”的东西。

## 2.2 光线：现场光，而不是为观众打光

主光源必须能在现场解释：

- 阴天 / 晴天自然光；
- 雨天 / 雾天漫射光；
- 黄昏天光；
- 车厢顶灯；
- 老式白炽灯 / 裸灯泡；
- 日光灯；
- 小店、旅店、路灯、手电；
- 手机 / MP4 / 电视 / CRT 屏幕光。

允许：

- 局部过曝；
- 暗部掉细节；
- 色温混杂；
- 人脸没有被“照顾”；
- 窗外和室内无法同时正确曝光。

禁止：

- 为“恐怖”统一压暗；
- 戏剧性轮廓光；
- 专业三点布光；
- 所有人脸都正好被柔光照亮；
- 为异常额外安排不明来源的“电影光”。

## 2.3 色彩：低饱和，但不是统一脏滤镜

母色域：

- 灰白；
- 土黄；
- 旧蓝；
- 脏绿；
- 褪色红；
- 水泥灰；
- 灯泡暖黄；
- 阴雨灰绿。

原则：

> **颜色来自环境与设备，而不是后期套一个“复古 LUT”。**

允许同一篇因为光源、天气和设备自然发生色偏。

不允许每张统一套：

- 青橙；
- 墨绿恐怖滤镜；
- 棕黄“民国感”；
- 强暗角；
- 胶片漏光；
- 人造颗粒覆盖。

## 2.4 清晰度：受控的不完美

| 现场原因 | 允许结果 |
|---|---|
| 走路 / 弯腰 / 回头 | 轻微手抖、方向性拖影 |
| 夜晚 / 弱光 | 慢快门糊、暗部彩噪、对焦犹豫 |
| 老手机 / 廉价数码 | 边缘软、JPEG压缩、细节涂抹 |
| 翻拍屏幕 | 摩尔纹、反光、亮度溢出、轻微偏焦 |
| 雨 / 雾 / 湿玻璃 | 局部反差下降、水滴遮挡 |
| 车内外大光差 | 窗外过曝或车内偏暗 |
| 临时抓拍 | 主体被裁一点、构图不完整 |

**禁止“为了旧”每张都同样糊、同样噪、同样偏黄。**

## 2.5 构图：记录事件，不展示设计

鼓励：

- 主体偏位；
- 视线被桌沿、座椅、树枝、窗框、门框挡住；
- 前景进画；
- 拍不全；
- 水平略歪；
- 镜头高度符合真实站位；
- 重要东西第一次只被“碰巧拍到”。

禁止：

- 每张主角 / 异常正中间；
- 完美对称；
- 低机位英雄仰拍；
- 为了“震撼”创造无人能站到的机位；
- 每张都像预告片关键视觉。

**剧情豁免：** 若居中或直视镜头本身就是异常证据，必须在正式分镜中预先登记；生成后不得为了救图补理由。豁免的审查方式见《真实性与共享风格锚点规范 V1.1》。

## 2.6 人物：首先是生活中的人

人物优先呈现：

- 背影；
- 侧身；
- 手、脚、肩膀；
- 被桌子 / 车座 / 门框切掉一部分；
- 正在做自己的事；
- 没有准备好被拍；
- 普通年龄、普通穿着、普通发型。

人物不要因为进入怪谈就突然：

- 全部面无表情；
- 全部盯镜头；
- 全部像演员；
- 全部穿“有故事感”的衣服。

异常来自：

> **普通人做了一件不正常的事。**

而不是：

> “一群一看就是鬼的人站在那里。”

## 2.7 异常：嵌进现实，不单独开特效层

可用载体：

- 屏幕内容；
- 路线顺序；
- 影子；
- 旧照片；
- 物件位置；
- 名单；
- 车票；
- 地图；
- 桌数；
- 人群行为；
- 光线 / 年代细节逐渐错位；
- 熟悉地点出现时间矛盾；
- 具象实体（题材确实需要时）。

异常升级：

`普通场景 → 一个小矛盾 → 第二证据 → 现实行为被影响 → 无法解释的结果`

不把：

`普通场景 → 突然巨怪 / 鬼脸 / 超自然光效`

当默认模板。

## 2.8 “恐怖度”不是画面暗度

恐怖主要来自：

- 太正常；
- 太熟悉；
- 行为逻辑不对；
- 时间对不上；
- 路线对不上；
- 人知道不该知道的东西；
- 一件普通物品开始证明未来 / 过去；
- 一个生活空间仍在正常运转，但规则已经错了。

> **不能用把画面压黑来代替故事不安。**

# 三、三个子风格

## F01｜流水席：暖噪人群民俗

### 3.1 核心句

> **热闹是真的，饭是真的，人也像真的；不对劲藏在人群秩序里。**

### 3.2 视觉参数

- 环境密度：高；
- 人群密度：高；
- 色温：偏暖但不统一；
- 主光：裸灯泡 / 白炽灯；
- 背景：树林或场地可自然死黑；
- 色彩：灰黄、土色、褪红；
- 画质：低清、JPEG、轻失焦、有限动态；
- 构图：桌沿、碗筷、树枝、帐篷边缘自然遮挡；
- 人物：老人、中年人、妇女、小孩，普通乡村宴席状态。

### 3.3 必须像真的东西

- 3–5桌首先就够，不一上来铺几十桌；
- 菜像乡村席，不像饭店摆盘；
- 桌椅材质与年代统一；
- 每个人有自己的生活动作；
- 招呼人坐下要热情自然，不邪笑；
- 主角坐下时前景有自己的碗筷，建立第一视角。

### 3.4 异常怎么长出来

`正常席面 → 只给外来者夹菜 → 桌数变多 → 灯/桌凳/衣服悄悄变旧 → 名单证据 → 普通人同时停下动作`

关键：

> “年代变旧”必须是渐变，不是突然变成穿越剧。

### 3.5 禁止

- 婚庆宣传片；
- 酒店宴会；
- 鬼宴滤镜；
- 所有人一开始就盯镜头；
- 青面獠牙；
- 大量烟雾 / 鬼火；
- 菜品过度精致；
- 电影级暖光。

## F02｜村子：冷灰返乡旧数码

### 3.6 核心句

> **一个本来熟得不能再熟的返乡空间，被旧设备证明“其实早就有人知道你会来”。**

### 3.7 视觉参数

- 年代子锚：2009年前后早期拍照手机 / 普通数码；
- 地域子锚：西北县城—乡村；
- 环境密度：中低；
- 人群密度：低；
- 色温：白天灰土，室内自然偏黄，屏幕局部偏冷；
- 画质：旧手机低动态、反光、屏幕摩尔纹、轻偏焦；
- 空间：中巴、奶奶家、小桌、搪瓷杯、村口小卖部、土路；
- 普通场景比例必须高于恐怖场景。

### 3.8 最重要的真实感

**旧设备不是“恐怖道具”，而是一件普通旧消费电子。**

MP4 / 小灵通 / 旧手机 / 数码相机应有：

- 固定型号母版；
- 使用磨损；
- 合理按键；
- 屏幕亮度有限；
- 翻拍时反光、摩尔纹；
- 与桌面、耳机、充电线、搪瓷杯等生活物同框。

### 3.9 异常怎么长出来

适合：

- 屏幕证据；
- 录像时间矛盾；
- 路线顺序；
- 熟悉地点；
- 影子与现实不一致；
- 旧设备提前记录未来；
- 地图 / 手写路线把零散证据连起来。

### 3.10 禁止

- 把旧设备拍成产品广告；
- 设备型号漂移；
- 屏幕干净得像 UI mockup；
- 全篇黑夜；
- 贴脸鬼；
- 过强森林恐怖氛围；
- 现代 HDR；
- “捡到旧物 = 必定鬼物”的固定套路。

## F03｜旧镇：湿灰漂泊生活

### 3.11 核心句

> **镇子旧，但不是废墟；人还在生活，所以“不该存在的旧”才成立。**

### 3.12 视觉参数

- 年代子锚：2010–2013普通国产安卓 / 廉价卡片机；
- 地貌：山区旧镇；
- 天气：阴天、雨、雾；
- 色彩：灰绿、湿水泥、旧蓝路牌、微黄室内灯；
- 画质：低动态、边缘软、轻失焦、JPEG；
- 机位：车内挡风玻璃、雨滴、路边旧牌、普通街巷；
- 人群：少，但不是“世界无人”；
- 建筑：旧但能住、能开店、能正常生活。

### 3.13 最重要的真实感

旧镇不等于：

- 鬼镇；
- 废墟；
- 无人区；
- 末日；
- 恐怖主题乐园。

正确状态：

> 卷帘门旧、墙面潮、招牌褪色，但店还能开；  
> 人穿普通衣服，照常过日子；  
> 路难走，但仍是现实中的路。

### 3.14 雨雾纪律

雨、雾、湿玻璃可以强化采集真实性，但非常容易电影化。

通过条件：

- 雾来自天气，不是“氛围烟机”；
- 湿玻璃会遮挡视线，不会刚好框出主体；
- 颜色不能统一调成高级青绿色；
- 景深不要过漂亮；
- 旧路牌 / 山路首先像现实交通设施。

### 3.15 禁止

- “Silent Hill”式空城；
- 电影级雾；
- 末世废墟；
- 超自然发光；
- 所有镇民敌对；
- 旧镇只剩“美术置景”；
- 过度电影化山路航拍。

# 五、风格选择规则

只有**主动采用 M00** 的项目才填写：

```text

故事年代：
主采集设备：
主光源：

异常载体：
禁止继承的代表性道具/剧情：
```

规则：

1. M00 可跨系列复用，但不是全账号强制；
2. F01/F02/F03 只提供采集语言，不提供情节；
3. 采用 M00 的新篇主子风格只选一个；
4. 辅助子风格最多借一个采集属性，如“F03湿玻璃”或“F02屏幕摩尔纹”；
5. 不得把“流水席、MP4、旧岔路”等代表道具当成视觉 IP 必须重复；
6. 与主规范“四把锁”同时执行。

# 八、正式生图提示词的风格层

## 8.1 M00 共用正向层

> 中国县镇/乡村真实私人相册记录，普通消费级手机或廉价数码相机的现场拍摄感，第一人称当事人随手记录，真实生活杂物和使用痕迹，构图略偏、可有自然遮挡和裁切，现场光线不均，有限动态范围，轻微偏焦/手抖/JPEG感按拍摄条件自然出现，低饱和但不套统一复古滤镜，画面首先像真实生活照片，其次才承载异常。

## 8.2 共用反向护栏

> 不要电影剧照，不要商业摄影，不要HDR，不要青橙调色，不要概念艺术，不要海报构图，不要完美对称，不要专业浅景深，不要所有人物看镜头，不要无来源轮廓光，不要统一脏滤镜，不要为了恐怖堆雾、鬼火、血腥和贴脸鬼。

## 8.3 子风格追加

**F01：**
> 夜间农村流水席，裸灯泡暖黄但不均匀，背景树林自然死黑，普通圆桌、塑料凳、家常席面、普通村民，热闹首先像真的，异常藏在行为和秩序变化里。

**F02：**
> 2009年前后早期拍照手机，中国西北县城乡村返乡生活，灰土低饱和，中巴、普通家居和旧消费电子真实磨损，翻拍屏幕可有摩尔纹和反光，异常藏在录像、路线、影子和物件位置里。

**F03：**
> 2010–2013普通国产安卓或廉价卡片机，阴雨山区旧镇，灰绿湿冷、低动态、边缘软、雨滴或湿玻璃自然遮挡，镇子旧但仍有人正常生活，不拍成废墟鬼城。

# 九、实际图片锚点资产规则

永久锚点建议放：

```text
research/account/style-anchors/
├── README.md
├── 候选锚点清单_V1.1.md
├── M00_县镇现实侵入式手机纪实/
├── F01_流水席_暖噪人群民俗/
├── F02_村子_冷灰返乡旧数码/
└── F03_旧镇_湿灰漂泊生活/
```

每个子风格最终只保留 **3–5张真正代表质感的成片**。

每张正式锁定前登记：

```text
anchor_id:
source_episode:
source_frame:
source_sha256:
role: ordinary | restricted | anomaly | evidence | transition | climax
status: candidate | locked | rejected
learn:
do_not_copy:
```

`learn` 只写：

- 光线；
- 采集缺陷；
- 构图行为；
- 生活材质；
- 色彩范围；
- 人物自然状态。

`do_not_copy` 必须明确：

- 人物身份；
- 具体地点；
- 代表道具；
- 异常机制；
- 字幕；
- 原图构图。

# 十、候选帧建议（不是自动锁定）

## F01 流水席

基于正式分镜，优先复核：

- 11：第一次看到3–5桌普通席面（ordinary/anomaly boundary）
- 14：第一人称坐进席里，前景碗筷（ordinary/POV）
- 19：红纸名单核心证据（evidence）
- 21：全场停下看镜头（climax，允许预登记直视豁免）
- 22：白天荒地现实验证（transition/reality-check）

## F02 村子

基于正式分镜与现有20格总览，优先复核：

- 01：中巴座椅缝里的MP4（ordinary）
- 02：花桌布/耳机/搪瓷器皿/MP4（ordinary）
- 03或04：旧屏幕翻拍，摩尔纹/反光（evidence）
- 09：村口小卖部现实验证（reality-check）
- 20：第8段录像终局物证（climax/evidence）

## F03 旧镇

基于正式分镜与现有雨巷/岔路对照图，优先复核：

- 05或06：旧岔路 + 雨中车内挡风玻璃（ordinary/restricted）
- 08：晨市正常营业（ordinary）
- 12：无服务 + 5:17，手机融入环境（evidence）
- 15：再次绕回同一街口（anomaly）
- 20：现实旧址 + 旧硬币残留（reality-check）

> 候选必须看最终 publish 单张成片后才能从 `candidate` 升为 `locked`。不得仅凭分镜或缩略图锁定。

# 十一、最终一票否决

采用 M00 的新篇，任一情况不得以 M00 通过：

- 去掉异常后不像普通生活照片；
- 生活细节明显是 AI 想象的“中式复古布景”；
- 设备时代错误；
- 前后清晰度 / 色调像换了摄影机；
- 中后段为了高潮突然变电影大片；
- 角色、道具、地点漂移；
- 恐怖主要靠鬼脸、血、雾、发光；
- 为复用风格重复三篇代表剧情或代表道具。
