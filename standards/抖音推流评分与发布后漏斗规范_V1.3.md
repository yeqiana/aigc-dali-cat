## 一、三套口径永久分离

1. **制作完成度**：作品本身是否达到发布质量。由主规范 12.2/12.3 决定。
2. **发布前传播结构分**：最终标题、封面、01–05、中段、不可逆升级、结尾、评论诱因、作者链是否成立。
3. **发布后平台实绩**：真实用户在 L1–L4 漏斗中发生了什么。

禁止：
- 用制作高分代替传播结构分；
- 用平台结果反向修改发布前预测；
- 只写一个模糊的“综合 9.x”；
- 把某一发布时间的单篇爆发解释成平台对该整点直接加权。

---

## 二、9 项传播结构卡

| 维度 | 优先级 | 目的 |
|---|:---:|---|
| 实际标题承诺 | A | 让陌生用户知道核心异常/阅读问题 |
| 实际封面停留 | S | 第一眼停下来 |
| 封面→图01兑现 | S | 进入正文后不降级、不换题 |
| 01–05消费债 | S | 前5张制造继续阅读需求并至少兑现一次 |
| 06–10信息净增 | S | 同源复现必须增加规则/后果/人物压力 |
| 11–15不可逆升级 | S | 异常真正改变人物或现实 |
| 16–结尾回报 | S | 兑现承诺 + 现实残留 + 可重读证据 |
| 评论诱因 | A+ | 正文自然形成双解释/回看/经验联想 |
| 作者链 | A+ | 单篇自治前提下形成主页继续消费理由 |

### 2.1 试运行门禁

以下阈值先作为**试运行创作门禁**，不是经验定律：

- 强传播结构：总分 ≥ 9.2，且所有 S ≥ 8.5
- 可发布：总分 ≥ 8.7，且所有 S ≥ 7.5
- 有条件发布：总分 8.3–8.69，或任一 S 为 7.0–7.49
- 不建议发布：总分 < 8.3，或任一 S < 7.0

12.3 仍是发布质量硬门禁：12.4 高分不能放行 12.3 未通过的作品；反过来，12.3 已通过但 12.4 判为“有条件/不建议”时，应先修传播结构再决定是否按当前版本发布。

校准机制：
- 累积 **5 篇**“完整9项发布前预测 + 48h平台实绩”后做第一次阈值校准；
- 累积 **10 篇**后再决定是否固化 9.2/8.7/8.3；
- 未满5篇之前，阈值只用于内部守门，不宣称已被数据验证。

## 三、四层发布后漏斗

### L1｜停留
记录划走率，以及后台若提供的曝光→进入正文/首屏停留。划走率只能作为首屏/前段代理，不能写成01→02留存或前三张到达率。

### L2｜深度消费
记录均浏览图、平均阅读深度占比，以及后台真实完读/末页到达/逐页留存（如有）。平均阅读深度占比 = 均浏览图 ÷ 总张数，**不等于完读率**。

### L3｜消费后动作
记录点赞、评论、收藏、分享，同时保留 raw count 与明确分母的率值。

### L4｜作者链
记录主页访问、吸粉、主页转粉率、播放吸粉率/曝光吸粉转化率、旧作带动/系列回访（有证据时）。

---

## 四、率值命名

曝光口径和播放口径永久分开：

- 曝光点赞/评论/收藏/分享/吸粉转化率 = 对应动作 ÷ 曝光
- 主页访问曝光率 = 主页访问 ÷ 曝光
- 播放点赞/评论/收藏/分享/吸粉率 = 对应动作 ÷ 播放
- 播放主页访问率 = 主页访问 ÷ 播放
- 主页转粉率 = 吸粉 ÷ 主页访问

不同分母的率值不得混排。后台若提供同名官方指标，必须标明“后台官方字段”。

## 五、可比样本

每篇与最近 **5–10 篇**可比作品比较，优先满足：

1. 同账号；
2. 相近发布时间龄；
3. 相近张数；
4. 尽量同题材/同形态。

不足 5 篇只记录，不判趋势强弱。历史“40%划走观察线”等只能标记为账号历史观察线，不是平台标准。

---

## 六、发布时间模型：场景变量，不是整点加权

发布时间只作为下列链路中的环境变量：

`发布时间 → 当时在线/愿意消费的用户 → 首批匹配与真实反馈 → 后续推荐机会`

禁止写成：

`20:30发布 → 作品权重自动增加`

当前账号数据只能支持“时段可能改变首批用户场景”，不能支持“某个整点是固定黄金档”。题材、实际标题、实际封面、前段兑现和消费深度仍优先于发布时间。

### 6.1 废止旧 19 点固定实验

从 V1.3 起，**停止把“连续3篇固定 19:00–19:15”作为下一阶段默认实验**。

现有 19:00–19:15 三个样本：

| 作品 | 时间 | 播放 | 均浏览图 | 划走率 |
|---|---:|---:|---:|---:|
| 会认人的蟋蟀 | 19:01 | 130 | 3.1 | 60.55% |
| 泥人2·送件 | 19:02 | 184 | 5.3 | 39.91% |
| 月背 | 19:10 | 218 | 7.3 | 41.57% |

三篇播放中位数 **184**，均浏览图均值约 **5.23**，划走率均值约 **47.34%**。这不能证明“19点差”，因为内容结构是混杂变量；但已不足以支持继续把新样本集中押在 19:00–19:15。

### 6.2 V1.3 四窗口轮换

剧情型“误入 / 旧物怪谈 / 民俗怪谈”优先轮换：

| 组 | 时间 | 定位 |
|---|---|---|
| A | **19:20–19:40** | 晚间较早对照；覆盖《流水席》强样本附近 |
| B | **20:40–21:00** | 当前默认窗口；已有《中元节最后一单》20:50 样本，可继续补密度 |
| C | **21:20–21:40** | 怪谈重点假设组；已有《泥人》21:22与《地下测线》21:31样本 |
| D | **22:40–23:00** | 深夜沉浸实验组，不默认长期使用 |

建议轮换而非机械按时间顺序：

`A → B → C → D → B → C → D → A ...`

目的：尽量打散星期、题材成熟度和账号自然增长造成的混杂。

### 6.3 样本门槛

- 第一轮 **12 篇**，四个窗口各至少 3 篇，只形成方向性判断；
- 某窗口不足 5 篇可比样本，只记录，不宣布稳定优劣；
- 16–20 篇后优先比较各窗口中位数、L1/L2 和 1h 冷启动，而不是用单篇最高播放决定胜负；
- 不同消费形态不硬混，优先比较误入/旧物怪谈/民俗怪谈等剧情结构相近作品。

### 6.4 控制变量

时间实验尽量控制：

- 正文 20–22 张；
- 制作门禁通过；
- 传播结构至少“可发布”；
- 实际标题和实际封面均已锁定；
- 同一天最多 1 篇，至少间隔 24 小时；
- 不把 PVZ 等明显不同消费形态与真实手机怪谈直接归入同一时间窗口结论。

## 七、1h 冷启动快照

主规范的正式验收窗口仍是 **6h / 24h / 48h / 7d**。

V1.3 新增一个**实验性 1h 快照**，只用于判断发布时间与首批反馈，不作为 `DATA_REVIEWED` 状态门禁，也不允许错过后用后续总览倒填。

建议记录：

- 曝光（如有）
- 播放
- 点赞 / 评论 / 收藏 / 分享
- 吸粉
- 主页访问（如有）
- 划走率
- 均浏览图
- 平均阅读深度占比
- 文案展开率（如有）
- `captured_at`

时间字段治理：

- `published_at` 已是发布时间事实源，不再重复增加 `publish_time`；
- `weekday` 从 `published_at` 自动派生，不在 manifest 重复手填；
- manifest 可记录 `timing_window`，使用 A/B/C/D 或 `organic`；
- `first_hour_metrics` 只存真实 1h 快照；未采集保持 `null`，不得用 6h/当前总览反推。

## 八、诊断矩阵

| 组合 | 结论 | 优先修复 |
|---|---|---|
| L1弱 + L2弱 | 首屏失败 | 标题/封面/图01/前三张 |
| L1强 + L2弱 | 封面强、承接弱 | 01–05兑现、06–10信息净增 |
| L1/L2强 + L3弱 | 阅读强、互动弱 | 双解释、回看证据、可转述规则 |
| L1/L2/L3强 + L4弱 | 作者链弱 | 系列承诺、主页识别、固定母题 |
| 四层均高于可比中位数 | 完整闭环 | 保留结构变量，只换情节与异常 |

当 L1/L2 明显失败时，不把低播放优先归因于发布时间。

## 十、资源排序

制作门禁通过后：

`L1首屏 → L2前15张信息净增 → 结尾兑现 → L3评论诱因 → L4作者链 → 发布时间实验 → 已合格单张的0.1~0.2分微调`

发布时间属于第二梯队变量：它可以影响本来合格作品的冷启动机会，但不能把结构失败的作品救成强样本。
