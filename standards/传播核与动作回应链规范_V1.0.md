# 传播核与动作回应链规范 V1.0

> Story OS V2.5 active subordinate standard。唯一创作权威仍是 `standards/制作规范_正式版.md`。
>
> 本规范把账号真实发布数据支持的“人物进场 + 事件扩池”经验变成 Story Lock 前后的机器门禁。
> 它约束的是传播结构，不要求复制任何已发布作品的表面题材。

## 一、核心原则

**人物负责进场，事件负责扩池。**

推荐默认公式：

> 真实人物让用户相信这事发生过；普通动作让用户代入；异常回应让用户产生转述/分享冲动。

除了“异常够不够大”，每个传播型故事还必须回答：

> **有没有一个能在 10 秒内讲给朋友听的动作 → 后果？**

## 二、Propagation Core

V2.5+ 新 Episode 的独立 Story Critic 必须在 `meta/story-semantic-review.json` 中输出：

```json
{
  "propagation_core": {
    "retell_sentence": "10 秒内可转述的一句话",
    "protagonist_action": "人物主动做了什么",
    "abnormal_response": "异常如何直接回应",
    "consequence": "回应造成了什么可见后果",
    "response_latency": "immediate",
    "visual_causality": "strong",
    "retellable_in_10s": true,
    "social_send_impulse": "strong",
    "trigger_frame": 9,
    "response_frame": 10,
    "payoff_frame": 14,
    "late_trigger_exception_reason": "",
    "surface_copy_guard": {
      "structural_reference_only": true,
      "copied_surface_elements": []
    }
  }
}
```

允许值：

- `response_latency`: `immediate | short | delayed_but_direct`
- `visual_causality`: `strong | medium | weak`
- `social_send_impulse`: `strong | medium | weak`

## 三、SHAREABILITY LOCK

进入 `STORYBOARD_LOCKED` 前必须同时满足：

1. **主动动作成立**：人物主动做一个普通人自然会做的动作，而不是只“看见更多异常”。
2. **异常直接回应**：异常世界对这个动作产生可辨认反馈。
3. **因果可画**：连续画面能说明“动作发生 → 对面回应 → 后果出现”。
4. **10 秒可转述**：无需先解释长世界观、三条规则或多个专有名词。
5. **触发位置健康**：默认 `trigger_frame / total_frames <= 0.5`；若更晚，必须给具体理由。
6. **不复制表皮**：Golden Episode 只继承结构，不允许把地点、道具、动作、高潮画面整体换皮复刻。

## 四、硬失败码

- `PROPAGATION_CORE_MISSING`
- `ACTION_RESPONSE_CHAIN_WEAK`
- `RETELLABILITY_FAILED`
- `VISUAL_CAUSALITY_WEAK`
- `ACTION_RESPONSE_ORDER_BROKEN`
- `TRIGGER_TOO_LATE_WITHOUT_REASON`
- `SURFACE_COPY_GUARD_FAILED`

任一硬失败均不得通过 Storyboard Lock。

## 五、Storyboard 图号约束

传播核必须明确：

- `trigger_frame`
- `response_frame`
- `payoff_frame`

且满足：

`1 <= trigger_frame <= response_frame <= payoff_frame <= total_frames`

标准 20 图作品建议 Trigger 约在 08–10 图。不是死规定；合理慢热可更晚，但必须填写
`late_trigger_exception_reason`。

## 六、Visual Narrative 责任

生产前后保持：

`setup → trigger → response → payoff`

其中 Trigger 图看得出人物动作；Response 图看得出环境/异常在回应；Payoff 图必须兑现新后果或现实残留。

## 七、Golden Episode：学结构，不学皮肤

`10_彼此的天上/01_不存在的夜行路` 可作为传播型结构参考，允许学习：

- ordinary_relationship_entry
- credible_daily_context
- low_cognitive_load
- active_human_trigger
- immediate_abnormal_response
- visually_readable_causality
- ten_second_retellability
- open_explanation
- normal_person_exit
- reality_recheck

禁止默认复刻：

- 川西 / 山路
- 远处灯队
- 远光灯互动
- 同款情侣自驾开局
- 同样的“灯依次熄灭”高潮

## 八、发布后验证

传播核最终由真实数据验证，不由预测分冒充。

发布后漏斗固定解释为：

`L1 进场 → L2 留存 → L3A 认可 → L3B 传播 → L4 作者链`

- L3A：点赞 / 评论 / 收藏
- L3B：分享
- L4：主页访问 / 关注 / 净增粉

报告默认采用：

**绝对数量 → 阶段增量 → 效率/比例**

不得只用百分比描述作品表现。
