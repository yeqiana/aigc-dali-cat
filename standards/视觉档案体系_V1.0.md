# Story OS 视觉档案体系 V1.0

## 核心原则

Story OS 不通过增加大量艺术画风扩展内容，而通过增加真实世界档案类型扩展生产能力。

唯一真实性母版：

```
M00 现实生活纪实母版
```

所有子视觉档案必须继承：

- 真实记录感
- 普通人物
- 非商业摄影
- 非电影海报
- 环境真实性

## 当前视觉体系

```
M00 现实生活纪实母版

├── M00_ANCIENT_DAILY_LIFE_V1
│   古代生活纪实档案
│
└── M00_HEAVEN_WORKER_DAILY_V1
    天界生活档案
```

## 古代生活纪实档案

用于：

- 江南生活
- 古代普通人日常
- 商贩
- 学徒
- 家庭生活

核心：

不是展示古装，而是记录一个古人的人生。

## 天界生活档案

用于：

- 天界普通工作人员
- 云务管理员
- 送信员
- 花园管理员

核心：

不是展示神仙世界，而是记录幻想世界中的普通生活。

## 禁止方向

所有视觉档案禁止默认走：

- 仙侠海报
- 游戏 CG
- 商业写真
- 概念设计图

## 扩展原则

新增视觉体系必须回答：

“这是一个什么世界中的真实记录？”

而不是：

“这是什么艺术风格？”
