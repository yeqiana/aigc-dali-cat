# 全系列最终字幕视觉规范 V1.0

> **状态：锁定。** 适用于本仓库所有系列今后新制作或重制的图文作品。
>
> **生效边界：** 本规范锁定的是字幕的视觉样式、排版与内容门禁；既有已验收/已发布成片、历史字幕脚本不追溯改造。各系列可保留自己的角色、叙事节奏和用语气质，但不得改变本规范的视觉参数。
>
> **与总规范的关系：** 本文是 `standards/制作规范_正式版.md` 第五章的唯一参数来源。反同质化铁律、静音可读、字幕不得遮挡剧情证据等总规范条款仍然有效；发生冲突时，以“剧情证据可读优先”为最高执行原则。

## 1. 最终字幕样式

| 项目 | 锁定设置 |
|---|---|
| 画布 | 1080 × 1920，9:16 |
| 字体 | Microsoft YaHei Bold / 微软雅黑 Bold |
| 字号 | **42 px** |
| 字重 | **700** |
| 文字颜色 | **#FFFFFF 纯白** |
| 背景气泡 | **无** |
| 描边 | **#000000 黑色，4 px** |
| 阴影 | 黑色 50% 透明度，X=1 px，Y=2 px，模糊约 2 px |
| 左/右安全边距 | **72 px / 72 px** |
| 最大文字宽度 | **936 px**（约画面宽度 86.7%） |
| 对齐方式 | **左对齐** |
| 行高 | **54 px** |
| 单张行数 | 优先 1 行，最多 2 行 |
| 推荐字数 | 单张 12–22 个汉字最佳，原则上不超过约 28 字 |
| 默认高度 | 字幕顶部位于画面高度 66%–72%（Y=1265–1380 px） |
| 动画/特效 | 无发光、无渐变、无跳字、无花哨动画 |

统一效果应是“真实手机照片，后期加上一句抖音原生字幕”，而不是 AI 故事卡片、黑色说明气泡或海报式字幕框。

## 2. 位置与避让

1. 默认使用画面下三分之一区域，字幕顶部位于 Y=1265–1380 px；每张必须独立定位，不要求全篇高度完全一致。
2. 字幕不得遮挡人物脸部、异常主体、手部关键动作、门槛，以及任何承担因果证据功能的实物、地址或后期叠字。
3. 下半部存在关键证据时，字幕移至画面 25%–35% 的低信息区；上半部存在脸部或异常主体时，保持在 65%–72%。
4. 全屏信息密集时，优先使用暗墙、天空、水面、门内阴影等低信息区域。位置可变，样式不得变。

## 3. 字幕内容门禁

1. 每张字幕只承担一个功能：交代动机、抛出异常、给出证据、推翻解释、升级威胁、记录即时判断或留下余波。
2. 使用第一人称、口语化、当事人即时记录的语气；避免小说式大段旁白、学术说明和完整异常机制讲解。
3. 不重复画面已经能直接看懂的信息。因果、物证、同源逻辑优先由画面完成。
4. 系列可因叙事语气使用更短的情绪 OS，但不得超过两行、不得牺牲静音可读；终局可使用回扣母题的短金句。

## 4. 战略性无字幕图

混合模式或 Zayn 模式可安排 2–4 张“证据图 / 静默图”。无字幕图必须在正式分镜中逐图标明，并同时满足：

- 画面自身能承载关键推论，不靠字幕解释；
- 相邻画面仍能让观众理解人物为何行动、下一张为何发生；
- 如发布前测试显示理解成本过高，只可补 10–12 字以内的极短句，仍按本规范样式绘制。

## 5. 禁止项

- 半透明黑色圆角气泡、任何大面积黑底字幕框；
- 28 px 小字号、居中字幕、三行及以上长字幕；
- 彩色渐变字、发光字、厚重投影、花哨动画；
- 遮挡人物、异常主体或关键剧情证据；
- 以 AI 生成的画面内乱码替代后期可控字幕；
- 用说明书式字幕一次解释完整异常规则。

## 6. 发布前字幕验收

每篇成片验收至少逐图确认：

1. 画布为 1080×1920 满屏，字体、字号、描边、阴影、左右边距与本文一致；
2. 无背景气泡，左对齐，单图最多两行；
3. 字幕没有遮挡人物、异常主体、手部或关键物证；
4. 每句只承担一个功能；删掉字幕后，异常与因果证据链仍基本可读；
5. 静默图的留白确有画面推论价值，而不是漏做字幕。

## 7. 一句话锁定版

> **1080×1920｜微软雅黑粗体 42px｜纯白字｜4px 黑描边｜无黑底｜左/右边距 72px｜默认画面下三分之一｜左对齐｜优先单行、最多两行。**
