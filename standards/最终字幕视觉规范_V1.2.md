# 全系列最终字幕视觉规范 V1.2

> **状态：锁定。** 适用于本仓库所有系列今后新制作或重制的图文作品。  
> **V1.2 变化：** 新增换行后孤立标点硬规则与 canonical renderer 审计。
> **继承 V1.1：** 支持 4:5 与 9:16 双画幅；**未指定画幅时默认 4:5 / 1080×1350**。历史已锁定 9:16 成片不追溯修改。

## 1. 画布选择

| 场景 | 比例 | 画布 |
|---|---|---:|
| **未指定 / 新篇默认** | **4:5** | **1080×1350** |
| 明确指定竖屏满屏版 | 9:16 | 1080×1920 |

画幅一旦在分镜 / `release-manifest.json` 锁定，全篇字幕渲染跟随该画布，不得擅自切换。

## 2. 最终字幕样式

| 项目 | 锁定设置 |
|---|---|
| 字体 | Microsoft YaHei Bold / 微软雅黑 Bold |
| 字号 | **42 px** |
| 字重 | **700** |
| 文字颜色 | **#FFFFFF 纯白** |
| 背景气泡 | **无** |
| 描边 | **#000000 黑色，4 px** |
| 阴影 | 黑色 50% 透明度，X=1 px，Y=2 px，模糊约 2 px |
| 左/右安全边距 | **72 px / 72 px** |
| 最大文字宽度 | **936 px** |
| 对齐方式 | **左对齐** |
| 行高 | **54 px** |
| 单张行数 | 优先 1 行，最多 2 行 |
| 推荐字数 | 单张 12–22 个汉字最佳，原则上不超过约 28 字 |
| 默认高度 | 画面高度 66%–72% |
| 动画/特效 | 无发光、无渐变、无跳字、无花哨动画 |

对应默认 Y：

- **4:5 / 1080×1350：Y≈890–970 px**；
- **9:16 / 1080×1920：Y≈1265–1380 px**。

统一效果应是“真实私人记录，后期加上一句平台原生字幕”，而不是 AI 故事卡片、黑色说明气泡或海报字幕框。

## 3. 位置与避让

1. 默认使用画面 66%–72% 区域；每张必须独立定位，不要求全篇 Y 完全一致。
2. 字幕不得遮挡人物脸部、异常主体、手部关键动作、门槛，以及任何承担因果证据功能的实物、地址或画面原生文字。
3. 下半部存在关键证据时，字幕可移至画面 25%–35% 的低信息区：
   - 4:5：Y≈338–473 px；
   - 9:16：Y≈480–672 px。
4. 全屏信息密集时优先选择暗墙、天空、水面、门内阴影等低信息区；位置可变，样式不变。
5. 用户明确要求“不要靠上 / 不要靠下 / 不要靠右”等单篇约束时，按最小改动原则在安全区内调整，不改字体与描边基线。

## 4. 字幕内容门禁

1. 每张字幕只承担一个功能：动机、异常、证据、推翻解释、威胁升级、即时判断或余波。
2. 第一人称、口语化、符合当时知识边界；避免小说式旁白、全知解释和大段说明。
3. 不重复画面已经能直接看懂的信息；字幕优先补时间、原因、声音、选择与画面外信息。
4. 终局可用短句回扣母题，但不得为了金句牺牲真实说话感。

## 5. 战略性无字幕图

混合模式或 Zayn 模式可安排 2–4 张证据图 / 静默图。必须在正式分镜标明，并满足：

- 画面自己能承载关键推论；
- 相邻画面仍能理解人物行动；
- 若理解成本过高，只补极短句，仍按本规范样式。

## 6. 禁止项

- 半透明黑色圆角气泡、大面积黑底字幕框；
- 28px 小字号、居中字幕、三行及以上；
- 彩色渐变、发光、厚重投影；
- 遮挡人物、异常主体、关键物证；
- 用 AI 画面乱码替代后期可控字幕；
- 为了从 9:16 改成 4:5 而直接拉伸画面或硬裁掉关键证据。

## 7. 发布前字幕验收

逐图确认：

1. 画布与 `release-manifest.json -> episode.aspect_ratio` 一致：4:5=1080×1350，9:16=1080×1920；
2. 字体、字号、描边、阴影、边距一致；
3. 无背景气泡、左对齐、最多两行；
4. 不遮挡关键证据；
5. 内容符合声音卡、连续三图、朗读和删字幕测试；
6. 锁定底图的 subtitle-only 编辑完成后 SHA-256 门禁仍能证明底图未被替换。


## 8. V1.2｜孤立标点第二行硬规则

字幕完成实际像素宽度换行后，如果第二行不含任何中文、英文或数字，只剩标点符号，则**整行直接舍弃**。

- 不把标点搬回第一行；
- 不保留 `。`、`，`、`！？`、`……”）`、`——` 等孤立标点行；
- 本规则在最终渲染阶段执行，不以原字幕字符串通过 `text_audit` 代替；
- V2.0.3.2 新篇 publish 字幕统一由 `episodes/_system/subtitle_layout.py render-all` 生成，并以 `meta/subtitle-layout-audit.json` 作为 Release evidence。
