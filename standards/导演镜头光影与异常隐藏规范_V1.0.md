# 导演镜头、光影与异常隐藏规范 V1.0

> 状态：active subordinate。服务于 Story OS 的导演质量增强，不新增 Episode Stage，不覆盖 `standards/制作规范_正式版.md`。
> 机器语法：`standards/directing_grammar_v1.json`。

## 1. 核心原则

Story OS 可以学习经典电影长期积累的**镜头信息组织、空间压迫、负空间、遮挡、反射和现实光源用法**，但必须翻译成故事内真实摄影者能够拍到的画面。

禁止：
- 复刻某部电影的具体镜头、演员、场景设计或标志性画面；
- 为了“像电影”增加无来源主光、轮廓光、烟机雾、青橙调色、海报构图；
- 让电影参考覆盖第一人称/私人相册/旧数码等真实采集物理。

允许且鼓励：
- 借“负空间”“深景异常”“框中框”“前景遮挡后揭露”“反射第二信息层”“明暗边界揭露”等结构；
- 把这些结构翻译为门框、窗框、车窗、镜子、水面、路灯、车灯、屏幕光、雾区、墙角等现实条件。

## 2. 景别与机位

新制作的 `meta/shot-progression-review.json` 使用 schema_version=3。

每帧必须声明：
- `shot_scale`：`extreme_wide / wide / medium / close / detail`；
- `scene_position_id`：本集唯一的精确拍摄位置 ID。

全篇硬规则：
- 至少 1 张 `extreme_wide/wide`，用于大场景、空间关系或尺度建立；
- 至少 1 张 `close/detail`，用于小场景、手部、关键物件、反射或异常证据；
- 至少覆盖 3 种不同景别；
- 同一景别连续最多 2 张；
- **同一个精确拍摄位置 `scene_position_id` 全篇不得重复。** 同一房间/道路可以再次出现，但摄影者必须移动到新的实际位置，并获得新的信息。

因此“地点可回访，机位不可复印”。

## 3. 经典镜头结构参考

每个 8 张以上的新故事至少选择 2 帧使用 `cinematic_reference.reference_id`，参考表来自 `directing_grammar_v1.json`。

每次参考必须填写：
- `reference_id`；
- `technique_translation`：说明如何翻译为本故事真实摄影行为；
- `exact_shot_recreation=false`。

参考的是结构，不是表面样子。例如：
- `NEGATIVE_SPACE_SUSPENSE`：主体偏位，把门口/走廊/窗边留成第二信息区；
- `DEEP_BACKGROUND_ANOMALY`：前景做普通动作，异常先出现在深景；
- `FRAME_WITHIN_FRAME`：门框、窗框、车窗、屏幕形成现实框中框；
- `OCCLUSION_REVEAL`：树、门、墙角、车门、雾等先遮住信息，再由动作揭露；
- `REFLECTION_SECOND_LAYER`：镜子、水面、玻璃、湿地反射与现实层出现不一致；
- `LIGHT_BOUNDARY_REVEAL`：异常只在车灯、路灯、门缝光、窗光、屏幕光等真实明暗边界上成立。

## 4. 光影不是滤镜，是叙事

每帧必须声明 `lighting_design`：
- `practical_source`：真实现场光源；
- `contrast_mode`：实际明暗关系；
- `suspense_function`：这束光在叙事上隐藏、揭露或引导什么；
- `physically_motivated=true`；
- `invented_cinematic_light=false`。

异常帧不能只写“阴森、电影感、压迫感”。需要回答：
- 光从哪里来？
- 哪部分被照亮？
- 哪部分仍看不清？
- 明暗边界是否改变异常可读性？
- 同场景前后光向是否连续？

可用的现实悬疑光影包括：门外亮/屋内暗、窗光剪影、日光灯缺灯、车灯扫过、手电只照到一部分、屏幕光、路灯断续、背光人物、阴影与实体不一致等。

## 5. 异常隐藏载体

`anomaly_concealment.carrier` 可使用：
- mirror
- water_reflection
- glass_reflection
- wet_surface_reflection
- fog_or_mist
- light_and_shadow
- screen_reflection
- foreground_occlusion
- doorway_or_window
- silhouette
- direct_visible / none

悬疑、怪谈、民俗、旅行异常、旧物异常等题材，至少安排 1 帧非直接隐藏载体。

每个隐藏载体必须：
- 有真实物理来源；
- 增加新信息，而不是装饰；
- 填写 `purpose` 与 `physical_anchor`；
- `adds_information=true`；
- 同一种非直接载体连续最多 2 张。

特别约束：
- 雾只能来自天气/环境条件，不能因为“恐怖”凭空加雾；
- 镜子、水面和玻璃反射必须符合相机位置与反射几何；
- 光影异常必须建立在真实光源上；
- 反射层可以先泄露异常，现实层随后验证，形成二次回看价值。

## 6. 生产与审核

以上字段会被编译进 Resolved Frame Contract，因此正式生图必须消费同一份合同。

最终实际像素审核额外检查：
- `shot_scale_fidelity`
- `scene_position_uniqueness_fidelity`
- `cinematic_structure_translation_fidelity`
- `practical_lighting_design_fidelity`
- `anomaly_concealment_fidelity`

任何一项失败都不得靠字幕解释通过。
