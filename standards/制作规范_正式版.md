# 制作规范 v2.4

> 基于 V3 实战沉淀及竞品复盘。以后每篇严格按此执行。
> 对标对象：鼠鼠脑洞批发（传播公式）+ Zayn（世界观深度）
> 账号：呱呱脑洞故事
> 这是永久创作标准。系列专属设定（角色、视觉母题、世界观具体内容）放在各系列的 episode docs 里。
> **当前形态锁定：冷启动阶段只做图文左滑，不做视频。** 依据是所分析竞品的图文互动明显高于其少量视频；这是本账号当前执行选择，不推断为整个平台的永久最优形态。
> **竞品结论边界：** v2.2 的“鼠鼠节奏”来自 `research/competitors/shushu/` 中两篇下载样本的逐张复盘，只作为样本观察，不表述为鼠鼠全部作品或平台算法的固定规律。
> **Zayn 样本边界：** v2.3 的“Zayn 节奏”来自 `research/competitors/zayn/` 中《海渊371》《神秘岛》《尤阁寨的羽化》三篇、共75张下载图片的逐张复盘，只描述这三篇呈现出的稳定方法，不推断为 Zayn 全部作品的固定模板。

## 零、反同质化铁律（最高优先级）

> 本铁律优先于本规范其余所有条款；与任何章节冲突时，以本节为准。

### 0.1 节奏 ≠ 情节

- 节奏是节拍骨架：第几张该发生什么。S1-S8（情感因果链）、Z1-Z8（视觉扩张链）是全账号统一的节拍，不随单篇变化。
- 情节是骨架上长什么肉：每个节拍上具体发生什么。情节必须逐篇差异化。
- 同质化的根因，是把节奏当成了情节模板，导致每篇都填成「长辈心结 + 材质复制 + 安全绳救援 + 认错 + 跟回家」。

### 0.2 四把锁（反换皮）

每篇新作在选题阶段必须与本系列已发布作品逐把对照以下四把锁，且至少 2 把不同：

| 锁 | 高发换皮形态（已出现） | 差异化的反例 |
|---|---|---|
| 越界者 | 长辈越界，主角旁观并救援 | 主角本人主动越界 |
| 关系人物 | 背负心结的长辈（父亲/导师/哥哥） | 同龄挚友、陌生人、对手，或无固定关系人物 |
| 母题逻辑 | 环境记录/复制/替换进入者 | 寄存、交换、索债、诱捕、预言、交易 |
| 闭环方式 | 安全绳救援 + 认错 + 异常跟回家 | 代价偿还、身份反转、主动选择、交易完成 |

### 0.3 一票否决

四把锁中 ≥3 把与同系列已发布作品相同，判定为「换皮」，选题阶段直接打回，不得进入分镜。

### 0.4 选题阶段强制自查

新篇选题卡必须逐项回答，任一项仍指向「与上一篇相同」，即回到 0.2 重新设计：

1. 本片的越界者，与本系列上一篇是同一类型吗？
2. 关系人物仍是「背负心结的长辈」吗？
3. 母题逻辑仍是「环境记录/复制/替换人」吗？
4. 结尾仍是「救援 + 认错 + 异常跟回家」吗？

（反面案例：K1 水库泥人、K4 溶洞脚印、K2 冰川冰体三篇共享上述四把锁，属典型换皮；K2 重构版以「主角主动越界 + 同龄挚友 + 寄存还债 + 身份反转」四把全换。）

## 一、核心公式

**鼠鼠传播机制（样本观察）：** 普通人的现实处境 + 一个能改变生活的愿望/任务 + 关系人物带路 + 空间逐层进入 + 规则或禁忌出现 + 异常变成现场事件 + 悬念余波。

**冷启动适配公式：** 标题/封面先泄露强异常 + 1~3张建立普通人动机 + 关系人物带路 + 主角触发规则 + 异常直接反击现实 + 现实任务与人物关系闭环 + 异常原因留白。

**我们的差异化：** 提炼鼠鼠的日常代入、关系引路与现场升级效率，压缩其样本中的长铺垫；再加入系列专属视觉母题、现实锚点与轻量世界观。

### 1.1 选题准入（先选题，后写分镜）

每篇必须同时通过以下四项：

1. **地点有陌生感：** 真实或让人听过的地域/职业场景（深山道班、旧厂房、海岛、返乡村落等）；不能只写抽象"某个诡异地方"。
2. **动机够日常且够痛：** 旅行、求职、考研失利散心、返乡、替人送东西、参加集体活动等——主角为什么在场，第一张就能说清。同时必须有一个一句话能让人共情的情绪锚点（失去、迷茫、愧疚、孤独），对标鼠鼠"考研失败散心"的瞬间代入力。
3. **异常够具体：** 必须能被单张画面一眼识别（墙里的腿、窗外巨脸、重复出现的人、会移动的考勤名字等）；不能只靠"感觉不对"。
4. **有可争论的真相：** 结尾至少留下两个彼此竞争的解释，而不是把设定全部讲完。

### 1.2 单篇传播闭环

每篇先确定节奏模式，再按以下顺序写出一句话答案：

`节奏模式 → 我是谁 → 我为什么来（含情绪锚点）→ 谁/什么让我进入 → 我直接看见什么异常 → 鼠鼠：规则如何被触发 / Zayn：母题如何同源复现 → 异常怎样作用于人物与现实 → 此次任务/事件如何结束 → 鼠鼠：人物关系如何结束 / Zayn：终局如何重读前文 → 威胁或未知是否仍在生效`

任何一项答不出来，先补故事，不进入生图。

闭环必须同时满足：

1. **任务/事件闭环：** 收网、送达、返乡、调查、逃生、仪式或接受等开篇目标必须得到明确结果，不能在异常出现后被遗忘。
2. **所选节奏闭环：** 鼠鼠或混合模式必须落地带路人的亏欠、告别、误解或选择；Zayn 模式必须让人物的进入、观察与最终行动形成结果。
3. **异常余波或终局重读：** 鼠鼠模式用现实残留证明异常仍在；Zayn 模式用最后一张改变前文含义。两者都不能用“未完待续”代替结局。

冷启动阶段禁止把关键因果、人物结局或现实任务留到下一篇。可以做同题材新故事，不以强制追更补全本篇。

### 1.3 标题抓力自评（选题阶段即完成）

写完标题后，用以下三项快速打分，总分低于 8.5 分返回重写：

| 维度 | 权重 | 满分标准 |
|---|---|---|
| 代入速度 | 3 | 第一句就知道"我是谁、我在哪、我怎么了"，不需脑补 |
| 异常具体度 | 3 | 异常能用 5 个字转述给别人且对方能想象画面 |
| 信息密度 | 4 | 三句话讲完动机+异常+触发后果/矛盾，没有一句是废话 |

## 二、图片技术规范

### 2.1 比例与尺寸

- **比例：** 9:16 原生，占满抖音屏幕
- **尺寸：** 1080×1920 px
- **无黑边、无白边、无留白**

### 2.2 画风标准

对标鼠鼠"随手拍的不完美"：

- 极端暗光，但主体必须有光源打亮
- 真实颗粒/噪点，非后期添加的滤镜
- 自然运动模糊（手抖、车行、走路的模糊）
- 构图故意不完美：倾斜、主体偏位、边缘切到物体
- 光线不均匀：过曝的窗、死黑角落、混合色温
- **绝对不能：** 居中构图、完美曝光、干净画面、对称、HDR、影楼质感

### 2.3 第一人称视角

- 必须是手持手机拍摄的视角
- 全篇应持续让读者感到"拍摄者在场"。建议约50%~70%的图片自然出现手、脚、方向盘、倒影或近景遮挡；不得为了凑比例强行露手，导致畸形手或重复构图。CRT、档案、远景图可通过手扶屏幕、玻璃反光、镜头高度和画外遮挡建立第一视角
- **不能出现：** 女主角正面清晰面部、第三人称旁观视角

### 2.4 角色一致性

**固定角色锁定规则（全系列通用）：**

- 每个系列的核心角色必须有参考图锁定，存放于该系列的 `assets/characters/` 目录
- 参考图要求：正面半身、环境光匹配该系列的暗光设定、分辨率不低于 512px
- 每次生图前将参考图作为角色锁定 prompt 注入
- 审核时逐张检查面容是否漂移

**每篇新角色锁定流程：**

- 第一张出现新角色时，必须额外生成 2-3 张该角色的特写/不同角度参考
- 从中选定一张作为该角色后续统一的锁定图
- 同一角色后续出图均以锁定图为基准

- **豁免：** 恐怖实体或只出现一次的功能性配角（如路人、一闪而过的窗外巨脸）可跳过特写锁定流程，避免破坏神秘感。但同一角色若跨篇重复出现，必须在第二次出现时补做锁定。

**第一视角主角规范：**

- 系列主角必须锁定：服装颜色+款式、发型颜色+长度、是否戴眼镜
- 第一视角只露手/脚/局部
- 不出现正面清晰面部
- 主角形象描述写入该系列的 episode doc

## 三、恐怖实体规范

### 3.1 实体必须可见

- 恐怖实体必须有轮廓光或局部高光
- 不能被暗光完全吞没
- 在手机屏幕上必须能看清"那是什么"
- 对标鼠鼠：龙/UFO/墙里的腿——读者一眼就能识别

### 3.2 实体类型

- 实体范围不做限制：超自然实体、类人实体、巨型生物、不可名状之物均可
- 不追求数量多，追求一次出现就留下记忆点
- 每次出现的实体需与当篇主题强关联，不为了恐怖而恐怖

### 3.3 实体递进

实体原则上按四级升级，具体张数可随故事调整，但不得第一次出现就把全部信息讲完：

1. **痕迹：** 抓痕、脚印、异常影子、被移动的物品，让读者先确认"有东西来过"。
2. **局部：** 手、眼睛、轮廓、反光中的身体局部，推翻普通解释。
3. **全貌：** 最迟 Act4 给出一次可辨认的实体全貌或完整轮廓，形成视觉记忆点。
4. **现实入侵：** 终局让实体影响手机、门窗、人物身体或现代证据，证明威胁仍在发生。

同一级别不得连续重复超过2张；每次再次出现必须增加距离、清晰度、规模或现实影响中的至少一项。

## 四、视觉母题方法论

> 视觉母题是系列辨识符号。每个系列定义 1-2 个核心母题，写入该系列的 episode doc。以下为定义母题的规范，不限定具体母题内容。

### 4.1 母题定义规范

每个系列在 episode doc 中定义核心视觉母题时，必须覆盖：

1. **母题名称与视觉特征：** 清晰的视觉描述，生成 prompt 可直接引用
2. **剧情承载规则：** 母题不是装饰，至少在一处关键节点（异常初现/证据推翻/终局威胁）承担剧情信息
3. **出场频率控制：** 不强制每张出现，避免视觉重复和设定硬塞
4. **第一视角接入方式：** 主角如何与该母题互动（手扶、玻璃反光、画外遮挡等）

### 4.2 辅助场景

每个系列可定义 1-2 个辅助场景，同样写入 episode doc：
- 场景建筑/环境特征
- 内部关键道具清单
- 时代锚点（具体年代+视觉特征）

## 五、字幕规范

### 5.1 样式

- 圆角气泡，半透明黑底（alpha 150/255）
- 白色文字，微软雅黑，28px
- 气泡宽度不超过画面75%
- 气泡内左右 padding 28px，上下 20px
- 圆角半径 20px

### 5.2 位置

- 逐张微调，不挡画面主体；优先使用背景暗区（暗墙、天空、水面、门内阴影等）
- **主规则（K1 验证）**：气泡靠左对齐为主（x 0.03~0.30），宽度上限 ≤55% 画面宽，尽量避免贴右边缘（x_end > 0.80）、贴顶边（y < 0.12）和贴底边（y > 0.85）；人物、实体、关键道具与手势不可被遮挡
- 当主体偏左的构图（如主体占左半幅），气泡改用居中对齐或轻微偏左（x 0.20~0.35），纵向落在远离主体的对面暗区
- 屏幕类场景（电视/监控/手机屏）→ 上方暗区（pos 0.05）或靠左中暗区
- 户外天空 → 顶部（pos 0.08~0.12）或靠左中暗区
- 车内/暗区 → 中下部（pos 0.50~0.62）或靠左中暗区
- 桌面/地面 → 底部（pos 0.78~0.80）或靠左中暗区

### 5.3 内容

- 每图以1句为主，关键转折最多2句；单张20~32字，最长不超过40字
- 第一人称叙述，口语化
- 每句只承担一个功能：交代动机、抛异常、给证据、推翻解释、升级威胁或留下问题；不写小说式说明文
- 最后一张字幕可以简略，避免与画面内文字重复
- **Zayn/混合模式例外：** 可按 6A.4 安排2~4张无字幕关键图，以画面完成推论；其他图片仍遵守上述字数和功能规则

### 5.4 系列例外：古籍志怪字幕标准（S2《种梨》定稿标准）

适用 `episodes/08_古籍志怪/` 下全部篇目；与 5.3 冲突时本节优先。

- 字幕以主角第一人称短句情绪 OS 为主：单图 1~18 字，关键转折最多 2 句；不写叙事旁白和背景交代
- 每句只演一个即时情绪或反应（慌张、吐槽、自嘲、醒悟），不承担剧情总结
- 因果、物证、同源逻辑全部交给画面完成，字幕不解释原理；如"断了的梨树变成车把了吗"只做疑问，不下结论
- 允许语气词、省略号、感叹号强化情绪，不追求书面完整句
- 终局必须用一句玩梗或金句收尾，回扣本集母题物证并制造评论区钩子；不直接宣布异常结论
- 静音可读仍是底线：删掉全部字幕，读者仍能看懂异常直见与物证链

## 六、叙事结构

### 6.1 鼠鼠节奏定义与标注

#### 鼠鼠原版样本节奏（仅作观察）

下载样本呈现出以下稳定推进方式：

`普通人生活 → 个人愿望/现实困境 → 关系人物带路 → 空间逐层进入 → 规则或禁忌 → 异常现场爆发 → 悬念余波/追更`

样本允许用较多画面建立生活、关系和新地点，甚至采用约30张及“未完待续”。这不是本账号冷启动阶段的默认篇幅，也不能据此推断鼠鼠所有作品都采用同一节奏。

#### 鼠鼠节奏·冷启动适配版（选择鼠鼠或混合模式时强制执行）

选择鼠鼠或混合模式的作品，其选题卡、故事大纲和分镜文档必须标注以下节奏标签；同一标签可覆盖多张，但八项不得缺失：

| 标签 | 名称 | 必须回答的问题 |
|---|---|---|
| `鼠鼠节奏-S1` | 日常代入 | 主角是谁，正面临什么普通但具体的现实任务？ |
| `鼠鼠节奏-S2` | 关系引路 | 谁把主角带到异常现场，他与主角有什么未完成的关系？ |
| `鼠鼠节奏-S3` | 异常直见 | 主角和读者直接看见了什么一眼能懂的异常？ |
| `鼠鼠节奏-S4` | 规则建立 | 哪个动作不能做，或带路人用什么异常行为提醒危险？ |
| `鼠鼠节奏-S5` | 越界触发 | 主角为何主动或被迫触发规则？ |
| `鼠鼠节奏-S6` | 可见对抗 | 异常如何直接影响船、门、绳索、人物或空间？ |
| `鼠鼠节奏-S7` | 人情闭环 | 开篇任务与人物秘密分别怎样结束？ |
| `鼠鼠节奏-S8` | 异常余波 | 哪个现实残留证明异常仍在，但不要求下一篇补完？ |

分镜文档的每个 Act 标题后至少标注一个对应标签；关键转折图在“功能”栏再次标注，例如：`功能：鼠鼠节奏-S5 越界触发`。

**《舟山·水下的船》标注示例：**

`S1 帮舅舅收最后一网 → S2 舅舅带路并隐瞒父辈旧事 → S3 直接看见水下同船 → S4 舅舅要求不要照水下的人 → S5 主角开灯 → S6 水下船上升并拉扯渔网 → S7 收网/卖船完成且舅舅说出亏欠 → S8 割断的网返回，水下甲板多出第二个人`

### 6.2 节拍分配（默认20张，最多25张）

> 该上限用于 v2.2 后的新作品；已发布或已完成作品不倒推返工。

| 阶段 | 建议张数 | 鼠鼠节奏标签 | 功能 |
|------|:--:|------|------|
| Act1 日常裂缝 | 1-3 | S1 + S3 | 1张交代现实任务；标题/封面先泄露异常；最迟第3张让读者直接看见异常 |
| Act2 关系引路 | 4-7 | S2 + S4 | 带路人把主角留在现场，并通过一句话或一个反常动作建立规则 |
| Act3 越界触发 | 8-11 | S5 | 主角因现实目标而触发规则；异常必须立即做出可见回应 |
| Act4 可见对抗 | 12-16 | S6 | 异常持续影响现实，实体或完整异常最迟在本段清晰可辨；主角做出不可逆选择 |
| Act5 人情闭环 | 17-20 | S7 | 完成开篇现实任务，揭开人物隐瞒的旧事或选择，但不解释超自然机制 |
| Act6 异常余波 | 21-25（可选） | S8 | 用返回的物件、新照片、异常来电或新目击完成余波；不得重新开启一条必须追更才能结束的主线 |

20张已经完成 S1~S8 时直接结束，不为凑满25张增加档案、赶路或重复惊吓。

### 6.3 关键规则

- **标题/封面先给异常，正文快速补日常。** 前3张必须同时完成现实动机和异常直见；不得连续超过2张只铺环境、人物履历或世界观。
- **异常优先直接看见。** 仪器、监控、档案和记录只能作为第二层矛盾，不能替代主角现场目击，也不能连续承担主要推进。
- **每3~4张必须发生一次信息变化：** 新地点、关系变化、规则出现、规则触发、现实受影响、人物秘密、异常余波七选一；禁止连续多张只换角度。
- **规则必须被触发并产生后果。** 不能只说“不要回头/不要开灯”，随后规则与剧情无关；主角触发规则必须来自现实目标、情感冲动或被迫选择。
- **带路人负责关系，不负责讲完设定。** 他可以知道旧事、禁忌或自己的亏欠，但不应准确解释异常来源、运行原理和全部历史。
- **中段稳步升级，不跳级。** 每次异常重现必须增加距离、清晰度、规模、主动性或现实影响中的至少一项。
- **实体不得拖到结尾才首次可见。** 最迟 Act4 让读者看清它是什么；终局提高威胁或改变关系，不重复第一次亮相。
- **人物先闭环，原因可留白。** 现实任务和人物秘密必须有结果；异常为何出现、究竟是什么可以无人知道。
- **三个终局连击收尾：** 现实任务结果 → 人情秘密/选择 → 异常余波。
- **冷启动阶段禁用“未完待续”代替结局。** 同世界观下一篇必须是新的自治故事；上一页留下的核心冲突不得要求下一篇补完。
- **结尾必须双层留白。** 事实层留一个时间/人物/物品矛盾，解释层保留至少两种成立可能；不在字幕中直接提问。

## 六-A、Zayn节奏（独立章节）

> 本章与“鼠鼠节奏”并列，不覆盖 S1~S8。每篇在选题卡先写明：`节奏模式：鼠鼠 / Zayn / 混合`。鼠鼠适合现实关系与规则对抗；Zayn 适合探索、异变、未知生态和世界尺度翻转；混合模式用鼠鼠完成人物行动，用 Zayn 完成视觉规律与终局扩张。

### 6A.1 三篇样本呈现出的稳定方法

1. **画面先于解释：** 主要信息由物体、身体、空间变化传递，不靠日志、术语或旁白把异常讲明白。
2. **一篇只养一个异常母题：** 面具、透明膜、粉色菌丝等只是样本中的载体；真正可复用的是让同一种形态、材质、颜色或运动规律跨物体复现。
3. **重复不是复制：** 母题每次再出现都换载体并增加含义，从“一个东西不对”推进到“整套系统遵守同一规律”。
4. **人物从观察者变成参与者：** 前段可以目击，中段必须接触、跟随、逃离、破坏、接受或被改变，不能全篇站着看奇观。
5. **尺度不断外扩：** 手持物/局部生物 → 人体/舱室/物种 → 建筑/生态/地貌，终局用更大尺度重新解释前文。
6. **事件闭合，原因留白：** 人物此次进入、调查、逃生或仪式必须有结果；异常来源可以没有人知道。

| 样本 | 画面推进链 | 终局作用 |
|---|---|---|
| 《海渊371》 | 潜艇工作现场 → 异常物件 → 舱内系统与物理状态失常 → 海底建筑 | 把一次舱内事故重读为人物正在接近更大结构 |
| 《神秘岛》 | 登岛 → 单体异常生物 → 同源特征跨物种复现 → 异常生态群落 | 把“岛上有怪物”重读为“整座岛属于同一生命结构” |
| 《尤阁寨的羽化》 | 外来者进村 → 面具/粉色生长物 → 身体与群体仪式同源变化 → 全村结果 | 把“村民遭遇异常”重读为他们主动完成并接受一次集体转化 |

### 6A.2 Zayn节奏定义与标注

选择 Zayn 或混合模式时，必须在大纲和分镜中标注以下八项：

| 标签 | 名称 | 必须回答的问题 |
|---|---|---|
| `Zayn节奏-Z1` | 可信进入 | 人物通过什么具体职业、旅程、任务或地方行为进入现场？ |
| `Zayn节奏-Z2` | 母题直见 | 前3张直接看见哪个一眼能认出的异常母题？ |
| `Zayn节奏-Z3` | 同源复现 | 同一视觉规律怎样出现在第二种载体上？ |
| `Zayn节奏-Z4` | 规律确认 | 第三次复现增加了什么信息，使它从偶发怪物变成系统规律？ |
| `Zayn节奏-Z5` | 人物卷入 | 人物做了什么不可撤回的动作，或身体、工具、退路怎样被影响？ |
| `Zayn节奏-Z6` | 尺度扩张 | 异常怎样从局部扩展到舱室、群体、生态、建筑或地貌？ |
| `Zayn节奏-Z7` | 事件闭合 | 此次进入、调查、逃生、献祭或接受最终得到什么明确结果？ |
| `Zayn节奏-Z8` | 终局重读 | 最后一张怎样改变至少两张前图的含义，同时不解释异常来源？ |

同一标签可覆盖多张，但 Z1~Z8 不得缺失。混合模式必须分别标注 S1~S8 与 Z1~Z8，不能用同一句空泛说明同时代替两套因果。

### 6A.3 节拍分配（默认20张，最多25张）

| 阶段 | 建议张数 | Zayn节奏标签 | 功能 |
|---|:--:|---|---|
| Act1 可信裂缝 | 1-3 | Z1 + Z2 | 用具体人物行动建立现场，最迟第3张直接亮出核心母题；禁止先讲长背景 |
| Act2 同源复现 | 4-7 | Z3 | 母题进入第二种载体，画面仍可被误解，但不能只是换角度重复 |
| Act3 规律确认 | 8-12 | Z4 | 第三种载体出现，确认异常有稳定形态或行为规律，并推翻普通解释 |
| Act4 人物卷入 | 13-17 | Z5 | 异常影响身体、工具、退路或选择，人物必须采取不可撤回的行动 |
| Act5 尺度扩张 | 18-21 | Z6 | 从单体上升到群体、系统、生态、建筑或地貌，形成一次明确尺度跃迁 |
| Act6 闭合重读 | 22-25 | Z7 + Z8 | 给出人物/事件结果，再用终局画面重释至少两处前文线索；不解释根因 |

20张已经完成 Z1~Z8 时直接结束。不得为了等“大场面”而在前半连续陈列环境、器材、档案或不同怪物。

### 6A.4 异常母题扩散规则

每篇 Zayn 或混合模式作品，必须先在 episode doc 写一行：

`异常母题 = [核心形态] + [材质/颜色] + [运动或生长规律]`

并满足：

1. **至少三个不同载体：** 例如物件 → 人体 → 地貌，或单体生物 → 多物种 → 整体生态；同一物件换三个角度不算三个载体。
2. **至少三级尺度：** 细节/手持物、人物/房间/单体、群体/建筑/环境各出现一次。
3. **每次复现新增推论：** 第二次证明可传播或同源，第三次证明范围或目的；只增加体积和数量不算有效升级。
4. **视觉先完成信息：** 字幕只写人物行动、即时判断或现实后果，不替画面命名原理，不出现“这是一种会感染全岛的某某物质”式讲解。
5. **允许战略性静默：** Zayn 或混合模式全篇可安排2~4张无字幕关键图，但相邻画面必须让读者读懂人物为何来到这里、下一步为何发生。

### 6A.5 终局重读与闭环验收

发布前逐项回答，任一项为“否”则返回大纲：

- 第3张前是否已经直接看见异常，而不是只看仪表、日志或人物表情？
- 同一母题是否在至少三个不同载体上复现，并且每次增加新含义？
- 人物是否从观察转为行动，且这个动作改变了结果？
- 人物此次任务或事件是否已经结束，而不是用未知原因代替未写结局？
- 最后一张是否让读者重读至少两张前图？删掉最后一张后理解完全不变，视为终局失败。
- 结尾是否只确认“发生了什么/人物去了哪里”，仍没有权威人物讲明“它为什么存在”？

### 6A.6 两套节奏的选择边界

| 维度 | 鼠鼠节奏 | Zayn节奏 |
|---|---|---|
| 主要驱动力 | 现实任务、人物关系、禁忌触发 | 异常母题、同源复现、尺度扩张 |
| 人物功能 | 带路、隐瞒、选择、情感闭环 | 进入、观察、接触、被卷入或接受 |
| 中段升级 | 规则被触发后直接对抗现实 | 同一规律跨载体扩散并改变环境 |
| 高潮 | 主角作出不可逆选择 | 局部异常显露为更大的系统或世界结构 |
| 结尾 | 人情结果 + 异常余波 | 事件结果 + 终局重读 |

### 6A.7 Zayn标题钩子

Zayn 模式仍然禁止学术式开场。标题用三句完成“可信进入 + 母题直见 + 同源矛盾”：

```text
句1：我因什么具体任务进入什么地方
句2：我直接看见了什么核心异常母题
句3：哪个不同载体出现了同一特征，并造成什么可见后果
```

模板：`我因[具体任务]进入[地点]。我直接看见[核心异常]。后来，[第二载体]也出现同一特征，而[人物/环境]开始发生[可见后果]。`

第三句只能扩大矛盾，不能直接宣布异常的名称、来源、目的或科学原理。

禁止照搬样本中的青铜面具、眼状岛屿、粉色肉质生长物、具体人物造型或连续镜头。只提炼“同源复现、尺度扩张、终局重读”的组织方法，所有实体、母题与事件必须原创。

### 6-B 混合模式执行法

> 混合模式不是第三套独立节奏，而是用鼠鼠节奏推动人物行动，用 Zayn 节奏组织异常母题的复现、扩张与终局重读。适用于既需要现实关系代入，又需要形成视觉系统升级的作品。

#### 6B.1 核心分工

| 叙事职责 | 采用的节奏 | 必须完成的内容 |
|---|---|---|
| 进入与行动 | 鼠鼠 S1-S5 | 现实任务、情绪锚点、关系引路、异常直见、规则建立与越界触发 |
| 异常升级 | Zayn Z3-Z6 | 同一母题跨至少三个载体复现，逐步从局部扩展到人物、空间、群体或环境 |
| 对抗与选择 | 鼠鼠 S6-S7 | 异常直接作用于现实，主角或关系人物作出不可逆选择，任务与人物关系得到结果 |
| 余波与重读 | 鼠鼠 S8 + Zayn Z7-Z8 | 现实残留证明异常仍在；事件闭合；最后一张改变至少两张前图的含义 |

混合模式的主线应遵循：

`现实任务进入 → 关系人物带路 → 异常母题直见 → 规则或规律触发 → 母题跨载体升级 → 异常作用于人物与现实 → 人物作出选择并完成任务 → 现实余波与终局重读`

#### 6B.2 默认节拍

| 阶段 | 建议张数 | 鼠鼠标签 | Zayn标签 | 执行要求 |
|---|:--:|---|---|---|
| Act1 现实裂缝 | 1-3 | S1 + S3 | Z1 + Z2 | 第1张交代现实任务或情绪锚点；第3张前直接看见可辨认异常 |
| Act2 关系与规则 | 4-7 | S2 + S4 | Z3 | 关系人物建立规则；异常在第二种载体上复现，不得只换角度重复 |
| Act3 越界与规律确认 | 8-11 | S5 | Z4 | 主角因任务、情感或被迫选择越界；第三种载体确认异常具有稳定规律 |
| Act4 可见对抗与卷入 | 12-16 | S6 | Z5 + Z6 | 异常直接影响人物、工具、退路或空间，并完成一次尺度跃迁 |
| Act5 人情闭环 | 17-19 | S7 | Z7 | 关系人物完成告别、亏欠、误解或选择；现实任务得到明确结果 |
| Act6 余波重读 | 20（可选至25） | S8 | Z8 | 用返回物件、新目击或现实残留证明异常仍在；终局重读前文，不解释根因 |

默认 20 张已经完成两套标签时直接结束，最多扩展至 25 张。扩展只能增加新的因果、人物选择或终局信息，不得增加赶路、档案、环境陈列或重复惊吓。

#### 6B.3 强制标注与验收

每篇混合模式作品的选题卡、大纲和分镜开头必须写明：

`节奏模式：混合模式（鼠鼠主行动 + Zayn视觉扩张）`

并分别列出 `鼠鼠节奏-S1~S8` 与 `Zayn节奏-Z1~Z8` 的具体落点。每个 Act 标题至少标注一套对应标签，关键转折图在“功能”栏再次标注；不能用“兼具鼠鼠和 Zayn 风格”一句话代替双套标签。

发布前必须全部回答“是”：

- 第3张前已经同时具备现实任务/情绪锚点和直接可见异常；
- 关系人物的规则或隐瞒真正推动了越界，而不是只负责讲设定；
- 同一异常母题至少在三个不同载体上复现，每次复现都新增推论；
- 人物从观察转为行动，且行动改变了人物关系或事件结果；
- 现实任务、人物关系和此次进入事件均已闭合，不用“未完待续”代替结局；
- 结尾同时具备现实残留与终局重读，异常来源仍然可以留白；
- 全篇默认 20 张、最多 25 张，字幕和画面没有遮挡关键线索。

混合模式一票否决：缺少任意一套 S1-S8 或 Z1-Z8；异常只存在于仪器、日志、档案或聊天记录中而未被现场看见；母题只有三个角度没有三个载体；人物关系没有结果；最后一张删除后不改变前文含义。

## 七、标题规范

### 7.1 鼠鼠三句式

```
句1：我是谁 + 我正在完成什么普通任务
句2：我直接看见了什么具体异常
句3：我做了什么或发生了什么，使异常开始影响现实
```

### 7.2 模板

```
我叫XX，XX岁，因为[日常理由/现实任务]来到XX。我直接看见了[具体异常]。当我[触发动作]后，[可见后果/现实矛盾]。
```

“我原以为……直到……”可作为备选推翻结构，但不是强制句式；若使用，最后仍需落到可见后果，不能只靠仪器读数或档案文字完成钩子。

### 7.3 字数

不超过70字，手机端3行以内显示完整；禁用"诡异、恐怖、惊人"等空泛形容词代替具体异常。

## 八、发布规范

### 8.1 标签策略

- 每篇5~8个，避免堆砌。
- 场景标签：1~2个（与该篇地域/场景直接相关）
- 类型标签：2~3个（#都市传说 #细思极恐 #中式恐怖）
- 内容标签：1~2个（#AI故事 #抖音图文）
- 活动标签：0~1个（#RunNOW；仅活动有效时使用）

### 8.2 声明

每篇标注：**作者声明：内容由AI生成**

### 8.3 BGM

- 优先选择抖音发布页当时可用、授权状态明确的曲库音源；发布前再次确认音源未下架、未限用。
- 风格以中式民俗恐怖、低频氛围、节奏缓慢为主。纸嫁衣原声/择天记-Malic仅作为风格参考，不作为永久指定曲目。
- 连续3篇不得机械使用同一首BGM；应按故事的地域、年代和情绪选择，避免账号听觉同质化。

### 8.4 数据验收

- 基础线（冷启动参考）：48h 300赞；良好线：48h 1000赞。该线仅用于同账号、相近发布时间的横向比较，不代表平台通用标准。
- 每篇记录：6h/24h/48h 点赞、评论、收藏、转发、主页访问、涨粉；可取得时追加曝光、图文完读/翻页完成。
- 复盘优先看"前3张是否让人停下、评论是否围绕未解钩子、收藏/转发是否高于账号中位数"，不只总点赞。

**统一计算口径（能取得曝光数据时必须计算）：**

- 点赞率 = 点赞 ÷ 曝光
- 评论率 = 评论 ÷ 曝光
- 收藏率 = 收藏 ÷ 曝光
- 转发率 = 转发 ÷ 曝光
- 主页访问率 = 主页访问 ÷ 曝光
- 转粉率 = 涨粉 ÷ 主页访问；若无主页访问数据，则记录为涨粉 ÷ 曝光并明确口径
- 完读率/翻页完成率直接采用抖音后台口径，不与点赞率混算

每篇只与"同账号、相近发布时间、相近画面数量"的最近5~10篇中位数比较。样本不足5篇时只记录，不下趋势结论。

**数据异常后的动作：**

| 信号 | 优先诊断 | 下一篇动作 |
|---|---|---|
| 曝光低，但互动率不低 | 发布时间、标签、账号起步波动 | 保留内容结构，换时段做至少3篇测试 |
| 曝光正常，前段流失高/完读低 | 标题、首图、前3张异常不够强 | 把异常和可见后果前移，删减纯环境铺垫 |
| 完读尚可，点赞/收藏低 | 实体或证据没有记忆点 | 强化独一无二的实体全貌与实物证据 |
| 评论低 | 结尾矛盾被解释完或钩子不可争论 | 重做事实层+解释层双钩子 |
| 主页访问高，转粉低 | 账号标签与系列承诺不清楚 | 强化系列名、重复母题与主页置顶入口 |
| 收藏/转发高，转粉低 | 单篇有用但账号连续性弱 | 下一篇延续一个已验证元素，不强接前作剧情 |

---


### 8.5 发布频率与持续性

- **发布频率：每周 2-3 篇。** 这是根据竞品更新节奏形成的冷启动执行假设，不表述为平台算法规则。若连续生产导致质量评分低于8.5，应优先降频保质。
- **时间选择：** 初始测试晚间 19:00-22:00；连续发布至少3篇后，再与其他时段的同类内容比较。不得仅凭单篇表现认定某时段优劣。
- **内容储备：** 冷启动前至少储备 3-5 篇完整内容（含图+文案），避免断更。
- **持续性与质量同时守门：** 竞品数据显示鼠鼠早期作品互动较低、后期起步互动更高，但只能说明相关性，不能证明由发布频率单独造成。保持稳定更新，同时执行发布前8.5分门槛。
- **阶段目标（冷启动）：** 3 个月内粉丝过 5 万。达到后进入成长阶段，频率可调整为每周 1-2 篇，单篇质量要求提高。
- **追踪指标：** 除单篇数据外，每月追踪赞粉比（对标鼠鼠 17:1）、篇均赞增长曲线、新发作品 24h 起步曝光。


## 九、世界观系统

### 9.1 核心原则

世界观定义写入各系列的 episode doc。以下为所有系列必须遵守的原则：

- **冷启动阶段（账号未形成稳定受众）：** 单篇必须自治，不要求读者补课；每篇只允许 1 个无需前作也能理解的暗线
- **成长阶段（已有稳定系列受众后）：** 用重复细节（特定道具、时间戳格式、同一连接者角色）建立跨篇连接；暗线必须奖励老读者，而非阻碍新读者
- **世界观上限：** 作为创作地图，不是每篇都要讲完的数字。避免在早期作品中做长段设定说明

### 9.2 跨篇连接机制

每个系列在 episode doc 中定义以下连接机制：

1. **连接者角色：** 一个跨篇出现的固定角色，每次出现只推进一个新信息，新读者不需要认识他也能理解当篇。老读者认出他是奖励。
2. **重复道具/符号：** 一个在系列中反复出现的物品或符号（如特定食物、特定格式的时间标记），出现时不解释，让连续观看的读者自行发现。
3. **连接强度控制：** 每篇的暗线连接不超过 1 个道具/符号 + 1 个连接者出场。禁止要求读者先看前作才能理解基本冲突。


### 9.3 自身标签进化

从模仿鼠鼠到建立自己的辨识度，按以下路径推进：

**第一阶段：结构学习期（0-3 个月，冷启动）**

- 提炼鼠鼠标题中的身份、动机、异常、推翻结构，并使用原创人物、事件与视觉表达
- 差异化抓手：比鼠鼠画面更稳定（角色锁定能力），比 Zayn 节奏更快
- 不做世界观说明，不要求读者补课

**第二阶段：辨识期（3-6 个月，5 万粉后）**

- 从已发布作品中提取 3 个被验证的独特元素（点赞和评论围绕哪些画面/设定集中），作为自身标签的种子
- 引入轻量跨篇连接（连接者角色 + 1 个重复符号），但不改变单篇自治原则
- 每 5 篇做一次自身标签复盘：哪些元素形成了读者期待？

**第三阶段：定型期（6 个月后，10 万粉以上）**

- 自身标签固化为账号简介和置顶作品的统一入口
- 可选择性引入 Zayn 式"伪档案/伪机构"世界观包装
- 内容方向可扩展到竞品未覆盖的细分领域（如特定地域系列、特定时代系列）
- 但始终保留鼠鼠的短平快传播公式为前提

**自身标签判断标准（每 5 篇复盘一次）：**

| 信号 | 含义 |
|---|---|
| 评论区反复提到某个元素/设定 | 该元素已形成记忆点，可强化 |
| 收藏/转发显著高于篇均 | 读者想"留着以后看"或"发给别人"，传播力好 |
| 连续 3 篇互动持平或下降 | 公式疲劳，需要新裂缝（场景/职业/异常类型） |

## 十、现实锚点与证据链模板

每篇必须包含至少3个现实锚点，其中至少1个是异常对现实造成的直接影响，至少1个是终局残留。锚点之间应互相验证或形成矛盾：

1. **日常实物：** 渔网、钥匙、旧衣服、车票、工具、饭盒等，先证明主角的现实任务存在。
2. **直接物理反应：** 绳索绷紧、船体倾斜、门被推回、地面积水、人物受伤等，证明异常不是只存在于屏幕或记录里。
3. **关系行为：** 带路人突然关灯、要求割断物品、喊出旧称呼或违背常识做选择，用动作暴露其隐瞒。
4. **终局残留：** 被割断的物件返回、旧物重新出现、新目击照片或陌生来电，把异常带回现实。
5. **辅助记录（可选）：** 照片、档案、监控、探测器、聊天记录等，每篇原则上不超过1组主要记录推进；只能加强已经直接看见的异常。

禁止为了满足数量机械加入日志、邮件、考勤、编号和旧档案。证据链服务于行动，不替代行动。

## 十一、评论区分裂设计

每篇结尾留至少 2 个未解释完的钩子：

1. **事实层钩子：** 围绕时间是否真实、人物是否真实、物品是否真实——让评论区争论"这件事到底有没有发生"
2. **解释层钩子：** 围绕超自然/循环/精神问题/阴谋论哪一种成立——让评论区分裂成不同派系

两个钩子均不在字幕中直接提问，交给读者自行发现矛盾。钩子检查标准：不追前作也能争论（事实层），追了前作能发现更多线索（解释层）。

## 十二、生成与发布前验收

### 12.1 每10张审核一次

1. 先生成10张，按分镜检查剧情因果、角色锁定、第一视角、实体可读性与字幕避让。
2. 不合格图单独重出；通过后再进入下一批，禁止把"以后再修"的图混入最终目录。
3. 最终发布前按排序连看一遍：静音状态下也应看懂"为什么下一张会发生"。

### 12.2 一票否决

- 非9:16满屏，存在黑边、白边或上下留白。
- 主体、实体或关键证据被暗光吞没，手机端无法辨认。
- 畸形手指、错误手机屏幕、明显AI文字。
- 角色面容漂移（同一角色前后两张图脸不一样）。
- 角色服装漂移（同一角色换装或颜色变化）。
- 第三人称旁观镜头、精致居中构图、棚拍/HDR质感。
- 前3张没有同时交代现实动机和直接可见异常，或任何一张字幕遮挡关键线索。
- 异常首次出现只存在于仪器、监控、档案或聊天记录，主角没有现场目击。
- 缺少当篇所选节奏的完整标签：鼠鼠模式缺 S1~S8、Zayn 模式缺 Z1~Z8、混合模式缺任意一套；或关键规律/规则出现后没有作用于人物与现实。
- 开篇任务/进入事件没有结果；或鼠鼠、混合模式的核心人物关系没有结果，只用“未完待续”结束。
- 单篇需要读者先看前作才能看懂基本冲突。

### 12.3 发布总评分

通过一票否决后，再按以下8项各打0~10分。总分为八项平均分，**低于8.5不得发布**；任何单项低于7.5，必须定向修复后重评。

| 维度 | 10分标准 |
|---|---|
| 标题抓力 | 三句讲完身份/进入理由、直接异常，以及触发后果或同源矛盾，手机端无需展开即可理解 |
| 前段抓力 | 前3张出现强异常，前4~6张给出可见证据或后果 |
| 剧情因果 | 所选节奏标签完整，静音连续翻页时每一张都能解释下一张的动机；混合模式两套标签均完整 |
| 随手拍真实度 | 暗光、手抖、偏构图自然存在，无棚拍、HDR和AI摆拍感 |
| 角色与场景一致性 | 核心角色面容、服装、时间、天气、空间关系连续 |
| 恐怖实体与现实锚点 | 实体可辨认且递进，至少3个现实锚点，含直接物理影响与终局残留 |
| 字幕有效性 | 每句只承担一个功能，位置避开主体和关键线索 |
| 原创性与账号辨识度 | 借鉴结构但不复刻表达，至少有1个属于本系列的视觉母题或证据设计 |

评分表必须保存在当篇 episode docs 中。评分人不能只写总分，低于9分的项目必须写一句扣分原因。

## 十三、原创、民俗与发布合规

### 13.1 借鉴边界

- 可以学习竞品的第一人称结构、节奏和信息组织方式；不得复刻其人物关系、异常组合、标志性画面、标题措辞或连续情节。
- 正式文档统一使用"提炼鼠鼠的传播机制"，不把"复制竞品"作为对外表达或成片目标。
- 每篇至少加入一个无法用竞品标题直接替换的自有元素：系列视觉母题、地域实物证据、人物情感关系或独特规则四选一。
- 使用现成小说、影视、动漫、游戏角色或怪物设定前，必须确认授权或改为原创、IP中性的表达；不得用知名IP名称为作品导流。

### 13.2 民俗与现实地点

- 民俗内容应标注为虚构演绎，不把杜撰仪式、禁忌或伤亡事件表述为现实事实。
- 使用真实地点、民族、宗教、职业或历史事件时，避免污名化、猎奇化指控和无法证实的灾难叙述。
- 不使用真实普通人的肖像作为固定角色参考；角色参考应为本人授权素材、明确可用素材或原创生成形象。

### 13.3 发布前合规检查

- 保留"内容由AI生成"声明，并按发布时平台实际要求更新措辞。
- 检查音乐、字体、图片参考和画面内商标的可用范围；无法确认时替换为可授权或原创素材。
- 不使用血腥肢解、未成年人受害细节、自残诱导或仿真违法教程作为抓力来源。
- 标题、字幕和简介不得把虚构故事包装成已被官方证实的真实案件；可以使用伪纪录片叙事，但必须保留虚构声明。
