# Auto Production Orchestrator V2.0

## 流程

`locked source → auto plan → 3 calibration frames → 4 visual admission frames → remaining frames → visual review → one repair max → captions → checksum → delivery ZIP`

默认图片后端 OpenAI API，图片模型 `gpt-image-2`；规划与视觉审核默认 `gpt-5.6-terra`。也支持 `STORY_OS_OPENAI_BASE_URL` 或 `--provider command`。

4:5 强制输出 1080×1350，9:16 强制输出 1080×1920。字幕放在中下偏左，不靠上、不贴底、不靠右。approved 底图与 publish 字幕图分离。

如果第二次内容审核仍失败，系统停止并且不生成假 FINAL ZIP。已 APPROVED 且 SHA 未漂移的帧会在断点续跑时复用。

最终 ZIP：`<episode>/deliveries/<episode_id>_V2_AUTO_FINAL.zip`。

注意：ChatGPT 网页会员不是 OpenAI API 额度；V2.0 不通过浏览器自动化控制 ChatGPT 网页。
