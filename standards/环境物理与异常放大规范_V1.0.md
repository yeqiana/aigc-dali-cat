# 环境物理与异常放大规范 V1.0

> Story OS V2.1 Phase 3 active subordinate standard。唯一创作权威仍是 `standards/制作规范_正式版.md`。

## 1. 总原则

**Weather 是物理条件，不是滤镜。**  
**异常可以比现实大很多，但尺度、空气、光线、地面、材质和拍摄设备必须让它像真的被拍到。**

Environment Contract 嵌入 `meta/story-gates.json -> visual.environment_contract`，不得再创建独立天气权威文件。

## 2. Environment Contract

必须支持：

- `baseline`：整篇默认环境；
- `segments`：时间/天气阶段变化；
- `frame_overrides`：单帧例外。

环境不仅写“晴/雨”，还要写能够落到像素的物理结果：

- ground_state
- visibility
- wind
- precipitation
- temperature_feel
- physical_cues
- conditional_effects

### 条件效应

例如热浪只应在满足“室外 + 长视距 + 被加热地表”时出现；雨天不代表室内每张图都必须有镜头水滴。

## 3. Frame Directive

每帧必须具有：

- `narrative_role`
- `frame_mode`
- `impact_level`
- `required_visual_cues`
- `scale_reference`
- `escalation_from`

Narrative Role：

`setup / evidence / transition / escalation / reveal / climax / payoff / residue`

Frame Mode：

`normal_record / anomaly_reveal / anomaly_amplified / climax_impact / payoff`

## 4. Impact Level

- 0 normal
- 1 subtle
- 2 clear
- 3 dominant
- 4 overwhelming

`anomaly_amplified` 与 `climax_impact` 必须达到 3–4，并提供现实尺度参照，例如人物、车辆、楼体、山脊、道路、电线杆、门窗等。

高冲击不等于电影海报。应保持合理站位、焦段、曝光、空气透视、遮挡关系和拍摄失误。

## 5. 异常升级

高冲击帧必须回答：

1. 它比哪一张更大/更严重？
2. 现实中什么东西能证明它的尺寸？
3. 不看字幕能否看出升级？
4. 拍摄者为什么还能拍到这一张？

`escalation_from` 用于绑定前一阶段证据。

## 6. 机器审核

V2.1 新篇在 `VISUAL_CALIBRATED` 前必须通过：

`python episodes/_system/environment_contract.py verify <episode>`

最终实际帧语义审核新增：

- `environment_physics_fidelity`
- `anomaly_escalation_fidelity`
- `scale_reference_fidelity`

新增失败码：

- `WEATHER_PHYSICS_MISMATCH`
- `WEATHER_CONTINUITY_BROKEN`
- `ANOMALY_SCALE_UNDERDELIVERED`
- `SCALE_REFERENCE_MISSING`

旧 2.0.x Episode 不追溯要求。
