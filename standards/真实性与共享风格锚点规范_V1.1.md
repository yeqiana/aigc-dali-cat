# 真实性与共享风格锚点规范 V1.1

> 身份：主规范 §2.2 / §2.5 / §12.2–12.3 的执行细则，不建立第二权威。  
> 目标：把“真实私人记录感”从审美感觉升级为可复查的生产门禁。

---

## 0. 唯一归属

本文件唯一维护：

- 普通相册四问；
- 七项摄影红旗；
- 剧情预登记豁免；
- 结构化逐图审查字段；
- 缺陷因果判断。

本文件**不重复定义**：

- 三张校准的数量和角色；
- 每图返修次数；
- 发布张数；
- 字幕视觉参数；
- 传播评分。

三图校准和返修上限始终由主规范 §2.5 唯一维护。

---

## 1. 项目级真实性卡

每篇在正式分镜前登记：

```text
故事年代：
地点/地域：
拍摄者：
为什么拍：
主采集设备：
辅助采集设备（最多2种）：
画幅与方向：
稳定状态：
受限状态：
失控状态：
人物能否入镜：
当前设备能否入镜：
第二拍摄源如何成立：
共享风格：M00 / 不适用
主子风格（仅M00）：F01 / F02 / F03 / 自定义
锚点图片（如有）：
```

规则：

- 主采集设备应承担全篇**主要叙事**；
- 若辅助采集源合计超过主采集源，必须说明剧情必要性与连续性方案；
- 辅助设备必须有剧情来源；
- 未采用 M00 时，不强制填写子风格。

三张正式校准仍按主规范 §2.5 执行。校准失败时优先调整：

`拍摄行为 → 机位 → 光源 → 设备质感 → 共享提示词`

不要先加滤镜。

---

## 2. 普通相册四问

每张候选先问：

1. 去掉异常后还像私人相册 / 工作记录吗？
2. 拍摄者能真实站在此处吗？
3. 画面是在记录事件还是展示设计？
4. 异常是否被拍得太完整、太漂亮、太配合镜头？

任一明确失败 = `must_regenerate`。

---

## 3. 七项摄影红旗

```text
centered_subject
direct_gaze
perfect_face_light
clean_edges
everything_fully_shown
commercial_sharpness
cinematic_or_promo
```

默认：

- 有效红旗 0–1：pass
- 有效红旗 2：warning
- **有效红旗 ≥3：fail**

### 3.1 剧情预登记豁免

以下视觉行为有时本身就是剧情证据：

- 群体突然直视镜头；
- 仪式性正中构图；
- 证件/名单/屏幕为手机端可读而临时正置；
- 终局为了验证“现实对拍摄者作出反应”而出现异常凝视。

可以豁免，但必须同时满足：

1. 正式分镜在生图前已写明该行为是剧情证据；
2. 只豁免对应红旗，不豁免电影感、机位物理、角色漂移等硬失败；
3. 不能生成后为了救图补理由；
4. 终审记录 `reason`。

豁免后：

`red_flag_count_effective = detected - approved_exemptions`

### 3.2 单项硬失败

以下不进入红旗计数，单项即 fail：

```text
impossible_viewpoint
unexplained_camera_visible
identity_drift
key_prop_drift
location_structure_drift
sudden_cinematic_shift
critical_text_error
unexplained_third_person
```

## 5. 缺陷必须有因果

允许：

- 低照 → 噪点/慢快门；
- 奔跑 → 方向拖影；
- 屏幕翻拍 → 摩尔纹/反光；
- 雨 → 水滴/对比下降；
- 车内外 → 大光比；
- 旧设备 → 压缩/边缘软。

禁止：

- 每张同样噪点；
- 无原因色散；
- 无原因重暗角；
- 为“真实”故意把关键证据糊到看不懂。

---

## 6. 记录型异常的特殊准入

以下题材允许把**屏幕、旧录像、档案、聊天记录、照片**作为首次异常载体：

- 旧物怪谈；
- 影像预言；
- 档案自改写；
- 时间戳 / 名单 / 地图型异常；
- 记录本身就是母题的故事。

但必须满足：

1. 后续至少有一处现实层交叉验证或物理后果；
2. 不能从头到尾只在屏幕里自说自话；
3. 记录载体本身必须是现实生活中的普通物件，不拍成 UI mockup；
4. 非记录型题材原则上仍应尽快给现场可见异常。

---

## 7. 与传播评分关系

真实性是制作质量前置门禁：

- 真实性失败不能靠 12.4 传播高分放行；
- 传播低分也不代表真实性低；
- 发布后平台表现不能反向修改历史真实性结论。

`制作真实性 / 制作完成度 ≠ 发布前传播结构 ≠ 发布后L1–L4实绩`
