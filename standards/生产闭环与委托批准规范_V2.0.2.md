# Story OS Production Closure V2.0.2

V2.0.2 只修生产闭环，不新增故事规范、不新增 episode stage。

## 1. 图片闭环

`subscription image raw → canvas normalize → exact candidate → production ledger`

raw 永久与正式候选分离。4:5 正式画布 1080×1350；9:16 正式画布 1080×1920。大幅不匹配画幅拒绝强裁。

## 2. Full-Auto 完成语义

Codex worker `returncode=0` 只表示 worker 正常返回，不表示完成。parent orchestrator 必须 postflight：

- production ledger `--require-passed`
- publish 资产完整
- text audit PASS
- delegated delivery build + verify
- delegated release approval
- evidence gate 到 PUBLISH_READY

最后只允许 COMPLETE / PAUSED / BLOCKED。

## 3. Delegated approval

人工路径不变。用户已明确 full-auto 时，允许 `delegated_auto_review` 作为第二合法证据路径，但必须：

- runtime checkpoint 记录 continuous_execution_authorized=true
- user_approved=false
- delegated_auto_review=true
- 锁定同样的 story/visual/release 文件 SHA

不得把代理自审写成 direct user review。

## 4. Delegated delivery

禁止 `publish/` 缺失时回退 `approved/` 冒充最终成片。完整包必须包含：publish body、cover、captions、publish copy、propagation card、release manifest、text audit、checksums、delegated report；存在 production review 时一并包含。
