### 2.2 爆款公式提炼

鼠鼠的每篇标题可以解构为一个固定模板：

```text
我是谁（身份、年龄、地点）
→ 我为什么去那里（普通且可信的理由）
→ 我看见一条具体的异常
→ 给出一个貌似合理的解释
→ 再推翻这个解释
→ 最后一页留下未解除的威胁
```

**关键要素：**

1. **标题即钩子。** 鼠鼠从不用抽象标题。每一条都是第一人称："我叫XX，今年XX岁，在XX做XX，那天我……" 读者直接代入，不觉得在看小说。

2. **"普通场景 + 一条裂缝"模型。** 裂缝必须是日常生活中可能碰到的事——旅游、留学、考研失败散心、暑假回老家。读者会觉得"万一我也碰到呢"。

3. **评论区可争论。** 每篇结尾留一个"没解释完"的东西。评论区自然分裂成不同解读派系，争论直接拉高推荐权重。

4. **标签策略。** 每篇5-8个标签，覆盖三个维度：场景标签（#哀牢山 #西藏）、类型标签（#悬疑 #恐怖故事 #未解之谜）、活动标签（#RunNOW #RunNOW创作者跃迁计划）。

5. **账号在滚雪球。** 早期作品互动基数低（<1万），但持续发布后权重积累。近期新发作品起步曝光远高于早期。赞粉比17:1说明每篇都出圈，不只粉丝在点赞。

### 2.3 视频 vs 图文

鼠鼠少数几个视频内容（CineART共创、凌晨散步视频）互动显著低于图文。抖音AI悬疑赛道当前最优形态是**图文左滑**，不是视频。

### 3.2 Zayn 的优势

1. **世界观闭环。** 构建了虚构机构"A.E.A."（异态实体与超常规物理局），所有作品都是该机构的"档案记录"。世界观一致性带来粉丝粘性，置顶三篇就是世界观入口。

2. **文字密度和质量。** 每篇描述相当于一篇中篇小说。画面风格统一（伪纪录片色调、档案质感），形成强烈视觉识别。

3. **中国民俗+克苏鲁融合。** "夏至水仙祭""槐阴村""尤阁寨羽化"等，把中国地域民俗和西方怪谈体系融合，创造了一种独特的中式心理恐怖。

4. **"相机拍不出东西"母题。** 尤阁寨篇的核心反转——相机的快门和镜头都坏了，底片不是感光材料而是真菌生物膜——这种"你以为在记录现实，其实在记录疯狂"的设定，是Zayn最独特的创作标签。

### 3.3 Zayn 的短板

1. **产量低。** 32篇，建设世界观的成本极高。
2. **赞数两极分化。** 置顶7.7万 vs 天漏496。高概念不一定高传播。
3. **文字量过大。** 抖音用户平均注意力有限，Zayn的文案长度远超平台最优区间。
4. **"夏至水仙祭"在自身作品里属中下游（1412赞），但审美质量极高——说明好内容不等于好传播。**

## 五、我们的策略

### 第一阶段：鼠鼠模型冷启动（当前）

- 公式：第一人称 + 日常裂缝 + 民俗恐怖 + 评论区留白
- 目标：3个月内粉丝过5万
- 频率：每周2-3篇
- 差异化：比鼠鼠画面更稳定（角色锁定能力），比Zayn节奏更快

### 第二阶段：引入Zayn元素（5万粉后）

- 建立轻量级世界观（如"林老师的都市怪谈记录"系列）
- 单篇画面风格统一（调色、构图规范）
- 保留鼠鼠的高频发布和第一人称代入

### 第三阶段：找到自己的标签

- 当前首篇已验证的独特元素："墙角蹲着说话的人""三碗竖筷米饭""日常裂缝中的民俗恐惧"
- 围绕这些元素建立辨识度，不与任何竞品直接对撞
