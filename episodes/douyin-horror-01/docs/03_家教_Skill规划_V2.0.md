## 【视觉摘要】

主题：日常裂缝中的民俗恐怖——大学生家教发现雇主家存在不可解释的祭祀仪式，最终发现自己也是仪式的一部分
情绪核心：日常安心→不安→怀疑→恐惧→存在性震颤
关系状态：女主与奶奶从"正常雇主家人"变为"不确定对方是否活着/自己是否活着"
关键动作：端碗→蹲墙角→回头→奔跑→读短信→发现纸条
感官锚点：白米饭的黏湿质感、竖插筷子的不祥、黄色裸灯泡的晃动、旧瓷砖的冰凉、声控灯逐盏明灭、手机冷白屏
关键道具：白米饭碗×3、竖插筷子、碎花衬衫（浅蓝底小白花）、旧藤椅、小明纸条、手机微信消息、米色帆布包
场景：老小区楼道、学生家客厅、狭长厨房、厨房走廊、地铁车厢、大学宿舍
画面风险：图15三碗饭和图16沙发上的人容易被模型渲染成明显的鬼怪形象——需严格约束为"日常物品的异常摆放"和"远景模糊人形"

## 【角色卡】

### Character A — 女主（叙述者/家教老师）

- 年龄段：22岁左右
- 外貌连续性：黑色长直发中分、细框金属眼镜（椭圆框）、素颜、普通大学生长相、肤色自然偏白
- 服装：白色圆领短袖T恤（纯白无图案）、浅蓝直筒牛仔裤、米色帆布鞋、左手腕一根黑色发圈
- 随身物品：米色帆布单肩包（长带、无Logo）
- 气质：普通、不张扬、有点谨慎、不是美女也不是弱者——"就是你身边的人"
- 常见姿态：低头看手机、扶门框侧身探头、蹲着喘气、快步走、蜷缩在被子里
- **禁止变化**：发型（必须中分长直黑发）、眼镜框形（必须细框椭圆）、服装颜色和款式、体型（瘦但不骨感）

### Character B — 奶奶

- 年龄段：70岁左右
- 外貌连续性：花白头发向后盘成低发髻、瘦小身材、脸上有老年斑和细纹、双手关节微凸
- 服装：碎花短袖衬衫（浅蓝底+细碎白色小花，必须锁定此花色）、深灰色长裤、黑色布鞋
- 气质：表面慈祥和蔼、但眼神偶尔"太安静了"——像在看一个不在场的人
- 常见姿态：双手端白瓷碗、蹲在墙角背对镜头、端正坐在沙发双手放膝上
- **禁止变化**：发型盘法、碎花衬衫花色、体型（瘦小）

### Character C — 小明（学生）

- 年龄段：10岁左右
- 外貌连续性：普通中国小男孩、黑色短发、微瘦、单眼皮
- 服装：白色校服短袖Polo衫、深蓝色校服短裤
- 气质：安静、不多话、写字时很专注
- 常见姿态：低头写作业、偶尔抬头看人
- **禁止变化**：年龄感、体型、校服款式

## 【场景卡】

### Scene 1 — 老小区楼道

- 场景类型：老式居民楼公共楼道
- 时间/天气：下午、晴天、自然光
- 空间布局：狭窄走廊、一侧是窗户、一侧是墙和入户门
- 关键道具：暗红色木质楼梯扶手（表面磨得发亮）、声控灯泡（白炽灯）、电表箱
- 材质细节：墙面灰漆斑驳脱落、水泥地面有裂纹、扶手漆面有磨损
- 光线：下午阳光从窗户斜射、声控灯暖黄
- 色彩：灰+暗红+暖黄
- 情绪氛围：日常、正常（前期）/ 孤立、压抑（后期）

### Scene 2 — 学生家客厅

- 场景类型：老式小区两室一厅客厅
- 时间/天气：下午
- 空间布局：玄关→客厅→走廊→厨房（一条直线纵深）
- 关键道具：暗红色旧木地板、米黄色墙面、棕色旧布艺沙发（三人座+单人座）、深色木茶几、小学生作业本和铅笔、旧藤椅（靠墙角落）
- 材质细节：木地板有磨损痕迹和划痕、沙发面料轻微起毛、茶几上有水杯印
- 光线：室内暖黄吊灯光+窗外自然光混合
- 色彩：暗红+米黄+棕色+暖黄
- 情绪氛围：表面温馨、底层有被注视的不安

### Scene 3 — 学生家厨房

- 场景类型：老式狭长厨房
- 时间/天气：下午到傍晚
- 空间布局：狭长形、入口左侧是灶台和水槽、深处是墙角（关键区域）
- 关键道具：白色旧瓷砖（发黄有裂纹）、灶台上煮了一半的粥、黄色裸灯泡（无灯罩）、三碗白米饭+竖插筷子、墙角颜色比周围深一个色号
- 材质细节：瓷砖缝隙发黑、灶台不锈钢有划痕和水垢、地面瓷砖冰凉
- 光线：单一黄色裸灯泡、轻微晃动产生移动阴影
- 色彩：白+黄+深灰+不锈钢银
- 情绪氛围：压抑、仪式感、禁忌空间

### Scene 4 — 厨房走廊

- 场景类型：连接客厅和厨房的短走廊（约3米）
- 空间布局：窄通道、两侧墙面、尽头是厨房门（发光方框）
- 关键道具：墙上挂旧日历（停在农历七月十五）、褪色年画、墙面有细裂纹
- 材质细节：墙面有潮湿痕迹
- 光线：从厨房门口投射出的暖黄光在走廊地面形成长方形光斑
- 色彩：灰+暖黄
- 情绪氛围：过渡空间、越来越不安

### Scene 5 — 地铁车厢

- 场景类型：城市地铁车厢内部
- 时间：傍晚
- 光线：车厢内白色LED灯光+窗外隧道灯光快速掠过
- 情绪氛围：日常安全空间——认知上"回到正常世界"

### Scene 6 — 大学女生宿舍

- 场景类型：大学女生宿舍（上床下桌）
- 时间：深夜
- 空间布局：上铺床、下铺书桌、床帘
- 光线：手机屏幕冷白光照亮人脸——唯一光源
- 情绪氛围：私密、不安、孤立

2. **每张图配有专项负面约束**：V1.0只有全篇通用负面，现在每张图有针对性的"不能出现什么"
3. **场景卡独立提取**：V1.0场景描述混在分镜里，现在独立为6个场景卡可跨图复用
4. **English Prompt 双语输出**：imagegen 对英文prompt响应更稳定，同时保留中文供人工审阅
5. **质检报告**：V1.0没有质检环节，现在有8项检查
