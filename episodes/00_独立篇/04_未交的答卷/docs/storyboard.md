# 《未交的答卷》Storyboard — 20 Frames

| 帧 | 场景与动作 | 叙事功能 |
|---|---|---|
| 01 | 铅灰傍晚，高三男生伏在狭窄书桌前，复习资料堆成半米高，日光灯嗡鸣。 | 建立现实压力与人物身份。 |
| 02 | 特写红圈名次、解析几何草稿、纸页凹痕与握紧的铅笔。 | 把“达标”压力具象化。 |
| 03 | 铅笔芯骤断，半截铅芯弹落；视野倾斜，桌面光线拉成白线。 | 首次异常与转场钩子。 |
| 04 | 男生站在乳白无缝大道中央，浅蓝无太阳天空、建筑极度对称。 | “净域”第一次完整显现。 |
| 05 | 引导者从大片留白中走近，温和介绍没有竞争、指标和分数的生活。 | 乌托邦诱惑成立。 |
| 06 | 极简房间、22℃、无时钟；人工湖涟漪异常迅速恢复平整。 | 舒适中埋入第一层不自然。 |
| 07 | 第七天广场，环形喷泉每次水花高度完全一致，主角停步观察。 | 规律开始从舒适转为可疑。 |
| 08 | 长椅旁淡黄色指示灯，在主角画出不规则线条时闪两次。 | 系统开始响应个人表达。 |
| 09 | 主角偏置画面一侧；空旷广场里，指示灯微光映在光洁表面。 | 负空间制造被监视感。 |
| 10 | 对面女性重复同样微笑与翻页节奏；主角隔着喷泉确认动作循环。 | 打开“居民是否被标准化”的新问题。 |
| 11 | 主角追上引导者，直接问“如果想哭或大喊会怎样”。 | 从观察转为验证。 |
| 12 | 引导者平静说明“系统扰动”“恢复标准状态”，主角神情收紧。 | 异常机制被明确确认。 |
| 13 | 主角看向整齐街道，人群步调一致；玻璃反射中连表情都近乎同步。 | 主题反转：无压力也是更深的达标。 |
| 14 | 傍晚，主角独自向街区边缘走，白色秩序逐渐让位于昏暗荒原。 | 主动行动开始。 |
| 15 | 门框般边界中，主角伸手触碰半透明屏障，淡蓝波纹扩散。 | 边界成为选择的实体。 |
| 16 | 三四名引导者整齐抵达，劝他留下；主角与他们保持距离。 | “安全”成为最后诱惑。 |
| 17 | 主角回望净域，又想起现实书桌、断铅笔、眼泪与解题后的欣喜。 | 做出价值选择。 |
| 18 | 主角用力撞向屏障；纯白、浅蓝和直线像水彩一样扭曲融化。 | 视觉高潮与主动逃离。 |
| 19 | “咚”——主角从木桌上猛抬头，日光灯、纸张、咖啡与油墨重新出现。 | 回归现实，异常解除。 |
| 20 | 卷笔刀削出新笔尖，木屑落下；手重新把笔尖落在未解几何题上。 | 以触觉与行动完成主题闭环。 |
