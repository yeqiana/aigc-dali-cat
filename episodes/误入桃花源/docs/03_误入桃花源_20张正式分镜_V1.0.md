# 误入桃花源 — 20 张正式分镜 V1.0

> 4:5 写实照片感；第一人称手机随手记录；本集没有任何超自然机制；只做镜头与结构整理，不改剧情。

1. **交卷冲出教室**（近景）：重修考交卷铃砸在头顶，林舟推开写满潦草算式的答卷、低头冲出阶梯教室，手机攥在胸前不停弹出消息；走廊是湿热的汗味和暴雨前的土腥气。
2. **荒坡铁丝网缺口**（远景）：他没回宿舍也没去食堂，一路拐到后勤处背后的荒坡；齐腰杂草里，被前几天暴雨冲垮的绿色铁丝网豁开一个半人高的口子，他钻了进去。
3. **野桃林与石缝口**（中景）：水泥碎渣变成松软红土，人工湿地松被杂乱阔叶林吞没；转过被雨水冲刷发白的石灰岩梁，气味变了——成片野桃林、粉白残瓣，石渠尽头是被铁线蕨遮住的狭窄石缝。他想起“初极狭，才通人”，打开手机电筒钻进去。
4. **石缝里的一线白光**（近景）：两侧湿冷岩壁像要把他夹碎，尖锐钟乳石刮蹭书包拉链；他摸着岩壁爬了百十来步，眼前的岩缝突然裂开一道毫无预兆的惨白光线。
5. **绝壁下的盆地**（远景）：他从乱石堆里跌撞爬出，抬手挡光，整个人僵在原地——不是仙境，是四面环形绝壁死死扣在深渊底部的三四百亩洼地：棋盘状农田、几十栋黑夯土墙茅草屋、笔直的青石板路，没有半块红砖、看不见一片塑料瓦。
6. **整个山谷定格**（远景）：破球鞋带下一块碎石，“咚”一声砸进溪水；田埂上汉子直起腰、屋檐下妇人停下梭子、泥地里幼童僵在原地——几十双眼睛同时转过来，眼神里没有敌意也没有惊恐，只有被漫长岁月磨平一切的温吞。
7. **秦叔开口**（中景）：汉子把短锄插进泥里走过来，口音古怪、舌根发硬；他看了看那双开胶的球鞋，语气平静得像问候常客：“外头来的？天快黑了，湿气重，先进屋吃碗热食。”
8. **土灶旁的一顿饭**（近景）：土屋里没有一根电线，找不到一片塑料，只有松木青蓝烟气；粗陶碗里是碎麦饭、盐渍野葱、发苦的竹笋和半瓦罐浑浊米酒。秦家五口默默围坐，秦叔就着瓦罐喝了一口酒，淡淡问：“外头，还争吗？”
9. **山谷里的三天**（远景）：清晨公鸡打鸣后，乳白色晨雾在绝壁间像幕布一样拉开；午后他躺在穿堂风吹过的粗竹席上睡到夕阳斜照，傍晚坐在溪边听老人讲对不上年号的旧事。三年焦虑症好像突然自愈，心跳第一次缓得像这潭死水。
10. **小石盯着那块黑玻璃**（特写）：第三天傍晚，他在老水井旁帮秦叔削竹篾；十五岁的小石蹲在旁边，眼睛一眨不眨盯着石台上那台电量耗尽、屏幕漆黑的手机。
11. **一粒工厂薄荷糖**（近景）：他从书包侧兜摸出最后半管润喉薄荷糖，剥出一粒绿色的递过去；小石怯生生看了父亲一眼，见秦叔背对着在理竹条，飞快把糖塞进嘴里。
12. **少年眼里的火**（近景）：工业提纯的浓烈薄荷脑直冲天灵盖，小石眼珠猛地暴凸、整个人像被电击一样僵住，声音发抖地问“这是什么果子”；听到“一万公里外的大海、天上飞的铁鸟”之后，他瞳孔深处烧起一簇火——那是贪婪、狂热，是他想撕碎眼前这一切的焦灼。
13. **他晃了晃那台黑屏手机**（中景）：他笑了笑，拿起那台没电的手机晃了晃，说在外面这东西想要多少有多少，要是它有电，能看见大海、看见铁鸟，看见月亮其实就是个坑坑洼洼的大石头。
14. **一刀劈碎的厚竹**（中景）：一声极脆的裂响刺破黄昏，秦叔手里的柴刀偏了半寸，把一根厚竹劈得粉碎；他没有抬头，手死死按在颤抖的刀柄上，声音平得像结了冰的深潭：“小石，后山的羊圈该关了。去。”
15. **油灯、糖纸与湿纸巾**（近景）：那夜没有一丝风。门轴吱呀一声，秦叔端着菜籽油灯进来，把一张揉烂的绿色糖纸和半包湿纸巾放在床头，说天亮前出山去——这山谷从来不是什么仙境，它是一口枯井；人要活命，就只能把这口井当成天地。人心一野，这地方就不是避难所，是牢房。
16. **拂晓石缝前的告别**（远景）：浓重寒雾把山谷浸成一片惨白，冰冷水珠从洞顶滴落；秦叔把他送到石缝前，塞给他两个用晒干荷叶包着的硬麦饼：“顺着暗水流的方向爬，别回头。别再来。等夏至山洪下来，这道石缝就会被滚石彻底填死。”
17. **最后回头一眼**（远景）：钻进石缝的最后一瞬，他回过头——炊烟照常升起直直插向灰白天空，公鸡在篱笆上啼叫，田垄间已经有弯腰下地的人影。可他眼里再也没有那种诗意，只看见一群难民的后代用世世代代的封闭给自己修的千年墓穴。
18. **山脚下的轰鸣**（远景）：他拨开洞口湿烂的藤蔓滚出后山，上午刺眼的白昼晃得眼睛生疼；山下绕城高速上重型货车的轰鸣像海啸撞进耳膜，工地打桩机的震动顺着地表传上来，震得脚踝发麻。
19. **手机上压回来的现实**（特写）：口袋里的手机突然疯狂震动，未接来电和提示音连成一片；辅导员的消息挂在最上面——“下周一早上九点前必须交实习证明，否则直接取消评优资格”；母亲说表哥已经帮他约好下周二的面试，让他把衣服穿整齐点。
20. **咬碎麦饼，走下山**（中景）：他站在风口里，把混着尾气和沥青味的浊气大口吸进肺里，掏出干荷叶把冷硬干涩的麦饼咬碎咽下；先回复老师“收到，我周一上午当面交您”，再按下母亲的回拨键，然后踩着满是泥的破球鞋，迎着山下的喧嚣大步走下去。

## 分镜硬约束

- 全程四人以下；固定人物锚点只有 P01 林舟，秦叔、小石等只在剧情中段出现，不是同行同伴。
- 所有光源必须是现场光：天光、阳光、手机电筒、手机屏幕、灶火/油灯明火、走廊灯管；禁止无来源轮廓光和电影主光。
- 山谷内不允许出现任何电器、电线、塑料制品、现代建材；秦家唯一的“现代物”是主角带进去又被退回来的糖纸与湿纸巾。
- 村民不喊不叫、不表演惊恐；山谷的恐怖来自全体同时定格与“被漫长岁月磨平的温吞”，不是怪物。
- 手机在整集里始终是黑屏或只有消息提示，从没给少年展示过任何真实画面。
- 禁止改写结尾：主角必须主动回到现实、回复老师并回拨母亲。
