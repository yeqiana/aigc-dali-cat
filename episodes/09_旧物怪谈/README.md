# 09 旧物怪谈

## 系列定位

中国 1990s–2000s 普通生活现场 + 旧数码/家用相机记录感 + 克制、可见、无法解释的异常。

统一的是影像质感，不锁死剧情机制：可以是网吧、校园、县城、农村、单位、交通、家庭旧事、职业记录等。

## 视觉原则

1. 生活照片优先，不把每张都做成悬疑剧照。
2. 人物像普通中国人，不网红、不模特化，不频繁看镜头。
3. 允许歪、挡、糊、灰、动态范围差等“受控不完美”。
4. 异常尽量通过现实物件、人数、时间、位置、照片、记录发生，不用鬼脸和怪物替代叙事。
5. 结尾留下现实残留或证据反咬，但不解释世界观。
