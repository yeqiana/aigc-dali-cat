01｜中元节前夜，舅舅让我 / 替他守半晚上店。
02｜他说晚点可能还有人来取货， / 让我别关太早。
03｜门口一共七个， / 我还专门数了一遍。
04｜不知道为什么， / 我一直觉得最左边那个有点别扭。
05｜快十二点时， / 我发现它好像离墙远了一点。
06｜我过去看了半天， / 就是个普通纸人。
07｜我回去以后， / 就一直盯着左边那个。
08｜没过多久， / 我总觉得过道比刚才窄了。
09｜我重新数了一遍。 / 还是七个。
10｜我翻出刚才的照片， / 这才确定——它们站的位置变了。
11｜我这才发现， / 不只是最左边那个。
12｜店里明明没多东西， / 可已经快没地方走了。
13｜我不想再等了， / 准备直接关门。
14｜拿钥匙的时候， / 我手一滑。
15｜钥匙掉到了 / 它们中间。
