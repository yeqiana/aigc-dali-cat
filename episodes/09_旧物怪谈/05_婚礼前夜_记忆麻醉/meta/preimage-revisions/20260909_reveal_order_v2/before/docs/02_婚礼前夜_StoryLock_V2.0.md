## 2. Story Contract

- 主角：23 岁普通年轻女性，第一人称记录者；本应出嫁的新娘，只露手、绣鞋、步态和必要局部，不展示正面清晰脸。
- 到场原因：被以"成亲"名义带到这间备好的"婚房"，本应在婚礼前夜完成布置、彩排与喂药，第二天作为新娘被接走。
- 个人代价：她必须弄清楚"恋爱六年"的剧本是谁写的、自己究竟是谁；若不逃，明天就会和货车里的女孩一样被当成货带走；若逃，她将失去唯一被安排好的"身份"，只剩一个连自己都叫不出来的名字。
- 唯一核心异常：记忆被药物与角色扮演替换。
- 规则：那瓶没有标签的药被盯着吃会替换记忆，灌下去会把人变成"听话的新娘"；婚鞋、金镯、土房是锁住这场表演的物理道具；货车上同款嫁衣的女孩证明这不是第一次"婚礼"。
- 有意义的触发：主角含药不咽、趁他转身吐进花盆，然后自己撕开喜字、翻转婚鞋、检查金镯，主动用"你送我镯子说过能锁住一辈子"逼问对方。
- 直接后果：他愣住的一瞬，后门被一个女孩撞开，场面失控，主角趁乱撞开后门逃进田里。
- 中点重构：婚鞋底部焊着铁环、金镯带锁孔、喜字下露出土坯、窗户从外焊死——把"布置成婚房"重读为"囚室被伪装成要出嫁的样子"。
- 高潮选择：主角没有接那瓶药，而是摘下金镯递到他面前，逼问他是不是来锁她；随后趁乱逃出，赤脚在田里跑向省道检查站。
- 结果：她在检查站被救，做笔录时却背得出"恋爱六年"每个细节、想不起自己名字；一个花白头发的女人喊出了她想不起来的名字。
- 余波：最后她梦见没有铁链、没有药、镜子里自己笑着试婚鞋的明亮房间，醒来盯着天花板想——如果那个梦才"真实"，那她此刻是醒在哪一层？
