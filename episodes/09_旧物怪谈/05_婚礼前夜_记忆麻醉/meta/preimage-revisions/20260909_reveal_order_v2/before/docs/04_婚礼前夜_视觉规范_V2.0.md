# 《婚礼前夜》视觉规范 V2.0

## 解析结果

- `visual_profile=M00`，用户未指定覆盖风格，必须真实注入每张请求。
- `capture_profile=CP03`，2007 年前后廉价卡片数码相机的设备物理优先于 M00 质感。
- 画布 `4:5 / 1080×1350`。

## Compact Visual Contract

2007 年前后中国西北农村；新娘第一人称手持旧数码相机，给老人看嫁妆/留个纪念，也顺手把看到的不对劲拍下来；土房婚房室内白炽灯与窗洞天光、室外深夜手电与车灯；构图偏位、临时抓拍、不清场；CP03 低动态范围、弱光小传感器噪点、对焦犹豫、轻微旧 JPEG 边缘软必须有因果；异常嵌在现实中，不做奇幻海报。

## 关键排除

- 不要电影灯、青橙调、强 HDR、商业锐化、统一浅景深。
- 不要魔法发光、光门、巨手首屏、鬼脸、怪物。
- 不要无解释第三人称、新娘清晰正脸肖像、群演式站位。
- 不要生成任何字幕、编号、logo、水印、边框和乱码招牌。
- 不要把土房婚房拍成干净样板间；它应像真实西北农村旧婚房被随手记录。

## 四图准入判据

- 01：去掉药瓶异常后仍像普通婚房布置相册；新娘手、男方侧身、亲友都不表演。
- 03：脚踝铁环与门缝外眼无需字幕可读；不拍成产品展示。
- 11：手电割裂土墙、窗从外焊死有因果；不能变灾难电影剧照。
- 15：金镯内侧合缝小锁孔与对峙张力仍保持随手拍；不能变概念美术。
