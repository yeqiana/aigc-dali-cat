日期：2026-09-10
剧集：episodes/09_旧物怪谈/05_婚礼前夜_记忆麻醉
性质：说明文档（telemetry 解释），不是门禁证据，不参与 validate / release 判定。

## 1. 为什么要单独说明

`meta/episode-performance-ledger.json` 里的 `performance_slo.active_wall_seconds = 42045.243`（约 11.68 h）实际是
**端到端墙钟**（`started_at` 2026-09-08T23:30:13 → `finalized_at` 2026-09-09T11:10:58），
中间包含跨夜停机与等待，不等于真实活跃工时。用户反馈"计算不准"属实，本文件按可复核的事件流重新统计。

## 2. 统计方法

数据源（全部为本集现有证据，不新增埋点）：

1. `meta/runtime/trace-events.jsonl`：164 条 SPAN_START / SPAN_END，覆盖图片生成与运行时事件；
2. `meta/episode-performance-ledger.json` 的 `state_transitions`（阶段推进时刻）；
3. 同一文件的 `named_spans`（各次评审 run 的 started_at / ended_at）。

合并三类时间戳（共 215 个点），按时间排序后累加相邻间隔；**相邻间隔超过阈值的部分不计入工时**（视为暂停）。

## 4. 与用户口述的核对

用户回忆"昨晚跑一阵子，今天早上九点、快十点跑到十一点多"：
与第 1 段（09-08 23:44–23:59）和第 2 段（09-09 09:33–11:10）吻合，
但 09-09 下午、傍晚、夜间和 09-10 上午另有 8 段在生产与返修，用户口述有遗漏。
