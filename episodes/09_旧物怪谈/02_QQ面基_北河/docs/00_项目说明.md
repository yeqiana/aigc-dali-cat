# 00｜项目说明

## 项目名

《2004年，QQ网友约我哥去村里面基》

## 定位

旧日现实怪谈 / QQ 面基 / 县城网吧 / 普通农村 / 摄影异常。

不是“误入不存在的村子”，村子从头到尾真实存在；异常核心是 **北河是谁、照片为什么提前发生、被“照全”以后为什么开始轮到主角引下一个人**。

## 时代与人物

- 时间：2004 年前后
- 主角：20 岁出头普通中国青年，县城网吧夜班网管
- 网友昵称：北河
- 场景：县城旧网吧、县乡中巴、普通村庄、小卖部、农村酒席、村西老磨坊

## 核心规则

1. 北河约主角去村里面基，但始终不正面出现。
2. 北河发来的照片会先于现实发生。
3. 每一张照片都把主角拍得更完整。
4. 老人提醒：“别让人把你照全了。”
5. 主角故意躲避，现实仍以很普通的因果补齐照片。
6. 村西老磨坊里有一台无电、锈死电池仓的旧数码相机。
7. 相机旁出现 17:42 的完整全身照，而当时只有 17:26。
8. 17:42，中巴到村口时，那一幕还是发生。
9. 第二天，陌生人拿着主角 QQ 号来网吧找“北河”。

## 20 图结构

01–04：网吧生活与 QQ 网友建立。  
05–08：正常坐中巴赴约，确认村子真实且普通。  
09–12：第一次偷拍 → 未来照片 → 汽水事件兑现。  
13–16：酒席照片 → 主动规避 → 现实补齐 → 不可能高机位。  
17–19：老磨坊坏相机 → 未来完整照 → 17:42 正常兑现。  
20：QQ 身份“交替”闭环。
