# 03｜画风锁定

## 总体

参考《误入》系列最好的真实感：**旧年代中国生活现场 + 廉价家用数码相机 / 早期手机记录感 + 受控不完美**。

不要电影感、商业摄影、概念图、恐怖海报。

## 村庄

- 普通中国北方/中西部农村，不照搬任何一张参考图。
- 水泥路、土边、白瓷砖自建房、裸红砖墙、灰抹墙、二层房与老瓦房混杂。
- 有电线杆、柴堆、灌木、院门、生活杂物，空间结构真实但不“景区化”。
- 场景轮换：村口宽路 / 小巷 / 小卖部门口 / 酒席院 / 村西老磨坊 / 中巴停靠公路。
- 不能每张都是“一条路+两边房+远处一个人”。

## 网吧

- 参考用户提供的网吧空间：低天花板、长纵深、密集电脑、窄过道。
- 设备以 CRT 为主，桌椅新旧混杂，不做整齐电竞椅。
- 前台旧木柜/贴皮柜台，零钱、登记本、烟灰缸、泡面、矿泉水、抹布、电线。
- 价格体系：临时约 2 元/小时、会员约 1 元/小时、包夜约 8 元，避免明显现代网咖价。
- 普通日光灯 + CRT 冷光；不做黑红电竞氛围光。

## 人物

- 普通中国青年，不网红、不模特脸。
- 大多数低头、侧脸、背影、做自己的事情。
- 不要连续对镜头；不需要靠完整正脸维持角色存在。
- 村庄段主服装：深色普通外套 + 牛仔裤 + 普通旧鞋。

## 成像

- 轻微虚焦、压缩、偏灰白平衡、动态范围差、偶尔运动模糊。
- 允许遮挡、歪构图、边缘裁切、玻璃反光。
- 不统一调成“漂亮复古滤镜”；真实来源不同可略有差异，但同一来源段必须稳定。

## 异常

- 不用鬼脸、黑影、怪物、血腥、发光物。
- 恐怖来自照片时间、拍摄位置、人物完整度、现实补齐照片。
- 图16必须像真的有人在树上拿廉价相机拍，不要航拍/无人机感。
- 图18的坏相机不能亮屏：照片必须通过实体冲印照/打印照承载。
