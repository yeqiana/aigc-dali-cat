## 一句话钩子

2004 年，我哥在县城网吧上夜班。一个聊了一个多月的 QQ 网友“北河”约他去村里面基，可人一直没出现，只不断发来一些还没发生的照片。

## 核心怪谈

照片里，我哥每次都比上一张“更完整”。村里老人只提醒了一句：**“别让人把你照全了。”**

最终他还是在 17:42 被完整拍下。第二天，一个陌生年轻人拿着我哥的 QQ 号来到网吧，问：**“哥，你是不是北河？”**
