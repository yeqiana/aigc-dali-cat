# 06｜字幕规范（V1.3）

## 当前资产状态

- 现存01–20图片均为 V1.2 烧录版本。
- 01–10、13–18字幕内容不变。
- 11、12底图内容可沿用，但仓库中没有无字幕原图；必须先按 `09_V1.3_四图媒体更新与网页GPT交接单.md` 只移除旧字幕，再按 V1.3 文案重新烧录。
- 19、20需要先按新版分镜重出，再烧录 V1.3 字幕。
- 在上述四张更新完成前，不得写“01–20已全部烧录最终字幕”。

## 锁定样式

- 字体：Noto Sans CJK Bold
- 样式：白色粗体 + 黑色描边 + 轻阴影
- 对齐：左对齐
- 位置：统一使用**中左区域**，不靠上、不靠下、不靠右；在画面中部略偏左，避免压到底部UI区，也避免遮挡右侧关键证据
- 原则：接近真实短视频/抖音图文字幕，不使用大面积黑底，不破坏旧手机随手拍质感
- 比例：1080×1350，4:5
- 文案来源：`01_最终发布文案.md`
