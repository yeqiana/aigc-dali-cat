# 《瓶中世界》视觉规范 V2.0

## 解析结果

- `visual_profile=M00`，用户未指定覆盖风格，必须真实注入每张请求。
- `capture_profile=CP03`，2000 年代卡片数码相机的设备物理优先于 M00 质感。
- 画布 `4:5 / 1080×1350`。

## Compact Visual Contract

2008 年中国县城私人旧数码相册；普通老玻璃厂办公室与真实生活杂物；只用窗光、日光灯、手电等现场光；构图偏位、临时抓拍、不清场；CP03 低动态范围、弱光小传感器噪点、对焦犹豫、轻微旧 JPEG 边缘软必须有因果；异常嵌在现实中，不做奇幻微缩景观海报。

## 关键排除

- 不要电影灯、青橙调、强 HDR、商业锐化、统一浅景深。
- 不要魔法发光、光门、巨手首屏、鬼脸、怪物。
- 不要无解释第三人称、人物正脸肖像、群演式站位。
- 不要生成任何字幕、编号、logo、水印、边框和乱码招牌。
- 不把瓶内县城做成干净玩具模型；它应像真实县城被缩小后装入厚玻璃。

## 四图准入判据

- 01：去掉瓶子异常后仍像普通清厂相册；父亲和办公室不表演。
- 03：照片与瓶内地标的对应无需字幕可读；不拍成产品展示。
- 10：手忙脚乱与弱光缺陷有因果，核心倾斜仍清楚；不能变灾难电影剧照。
- 20：世界尺度扩张仍保持县城随手拍，玻璃边界克制物理；不能变概念美术。
