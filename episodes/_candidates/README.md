## 规则

1. 文件头必须写明：DRAFT、日期、`user_seed` 重写版本、是否初始化 Episode。
2. 两篇同属“拐卖+婚”题材但机制错开；若进同一账号排期，按制作规范反同质化铁律建议中间间隔 ≥2 篇并错开封面/标题。
3. 现实罪案议题发布前必须做虚构声明（制作规范 13.3），正文不写可被仿效的药名、剂量、锁具解法。
4. 定稿后由人工决定归属；迁移时用 `git mv`，不复制后删旧。
