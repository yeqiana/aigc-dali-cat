# 壹·五环外的浓雾 — Story Lock V1.1

**时间**：2010年11月17日冬夜
**地点**：北京五环外，昌平/小汤山交界一片烂尾度假村式仿古建筑群
**第一人称**：玄奘（P01）
**可见同行者**：悟空（P02）、八戒（P03）；悟净仅作为后段画外同行者存在，不承担本集可见身份连续性。
**核心现实基线**：旧桑塔纳、天语手机、银色卡片数码相机、军大衣、煤烟、柴油热风炮、玻化砖、烂尾别墅。

## Story Lock

大雾让旧桑塔纳的导航彻底失灵。玄奘、悟空和八戒在北京北郊绕路，车灯穿过浓雾，照出一座立在烂尾别墅群后的仿古牌坊——“小雷音寺”。

玄奘把这当成漫长西行终于出现的答案；悟空却先闻到生漆和柴油。三人进殿后，所谓金身罗汉露出玻璃纤维，金漆还没干，取暖靠柴油热风炮，照明靠廉价射灯和发电机。更无法解释的是，一名低头沙弥的宽袖滑开时，露出黑毛手背和尖长指甲。

高台上的“弥勒”手压两面包红布的黄铜铙，台阶正中摆着一只磨得发亮的圆形跪垫，旁边沙弥只做了一个请他跪下的手势。玄奘虽然已经看到一路假造痕迹，仍想用最熟悉的礼节确认自己是不是到了终点。他把念珠绕到手腕，膝盖落上跪垫。就在膝盖压实的一瞬，两面无人触碰的铜铙同时发出低鸣，红布下面的边缘向外撑开。悟空这才把包着蛇皮袋的钢管砸在玻化砖上，喊出“黄眉老儿”。高台人物的慈悲脸瞬间垮掉，非人的凶相暴露；两面铜铙继续离台，在大殿上空膨胀成金属巨幕。

铜铙合拢，顶灯碎裂、发电机熄火。玄奘被封进黑暗金属空间，手摸到的不是神话纹饰，而是冰冷的机床切削纹。墙外传来八戒和悟净的叫骂、砸门声，以及行李被拖走的声音。

悟空在黑暗里点着打火机。橘光只够照亮他的脸、暗金窄箍和那根钢管。他告诉玄奘：这里根本没有他们想象的雷音寺；五环里面建的是高楼，留给他们走的只剩荒草地。但这不是终点。

玄奘握紧磨亮的酸枝念珠。悟空把钢管塞进铜壁接缝，玄奘替他照明。缝隙被一点点撬开，一线冷灰色天光漏进来。两人还没有脱困，却已经重新决定继续向前。

**传播核**：玄奘在五环外的假雷音寺仍选择按熟悉礼节下跪；膝盖刚压实跪垫，两面无人触碰的铜铙就同时低鸣、撑开并最终把他扣进黑暗。悟空的点名只是识破陷阱，不再承担触发因果；结尾两人用一根旧钢管撬出继续走的缝。

**结尾状态**：不确认灵山存在，不解决黄眉，不假装彻底逃脱；只兑现“继续走”的人物选择，并留下金铙接缝与工业刀纹作为现实残留。
