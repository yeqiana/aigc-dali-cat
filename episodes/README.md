## 目录规则

- `docs/` 只放创意、分镜、评审、发布清单和篇章说明。
- `images/` 或版本目录只放图像资产；中间稿、发布稿和带字幕稿按目录区分。
- `scripts/` 只放该篇章实际使用的处理脚本。
- 竞品和账号采集样本放在项目根目录 `research/`，不放进剧集目录。
