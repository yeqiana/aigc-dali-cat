## 一、完整故事闭环

林澈随"第七科考队"执行最后一次东海勘探，带着人类技术发展到现在、我们到底能发现什么的好奇下水。潜航器灯光扫过海底，撞见一片规整的古老建筑群，石柱上刻着鳞状纹路，纹路在灯光下发光。她以为发现了上古遗址，靠近后才发现那不是废墟——是一座完整的龙宫，宫门缓缓打开，里面透出不属于深海的光。然后她看见了龙：一条盘踞在宫殿上、鳞片发光的活龙，它睁开眼，朝潜航器转过来。队伍被发现了。龙没有攻击，只是看着他们，用一次缓慢的摆尾表达"你们不该在这里，但可以离开"。林澈在震撼中关闭灯光、缓慢后退，潜航器撤出海沟。返航后，母船甲板上留下一道潮痕，形状与龙鳞一致。

**任务闭环：** 勘探任务中止，队伍全员撤出，龙宫坐标封存。
**关系闭环：** 阿叔承认年轻时上报过"异常灯光"却被压下，隐瞒落地。
**异常留白：** 龙宫是谁建的、龙是人是物、它为什么放他们走，无人知道。

## 三、异常母题

`异常母题 = 发光鳞状纹路 + 海水/甲板潮痕 + 呼吸般的亮暗`

三个载体：海底石柱鳞纹 → 龙真身鳞片 → 母船甲板潮痕。
三级尺度：石柱鳞纹 → 宫门与龙 → 整片海沟是龙的领地。

**龙尺度硬指标：** 眼睛半径不小于 1.5 米；潜航器（约 3 米长）在龙首旁如同一只甲虫；出图必须有比例参照物，禁止无参照的孤立龙图。

**龙形态规范（参考图基准）：** 东方龙形态，深蓝黑到蓝绿色的重叠装甲鳞片、表面湿润反光；鹿角状黑色长角向上弯曲；长须与鬃毛在水中飘动；眼睛为发光的琥珀/金色，瞳孔竖直，目光沉静不狰狞；蛇形长身盘绕。禁止西方龙、翅膀、火焰、獠牙外露的狰狞嘴脸。

### 5.2 后期文字

- 所有手机屏幕文字均先留空，再后期叠字；不出现纸质档案、记录板、坐标纸。
- 字幕使用制作规范 5.1 至 5.3 样式；图07、图11 可作为战略性无字幕候选，但发布版全篇无字幕图不得超过 4 张。

### 5.3 龙形生成控制

- 必须是中国龙：角、须、鳞、四爪；禁止西方龙、蛇、海怪。
- 出图必须有人或物做比例参照（潜航器、观察窗、宫门、石柱），禁止无参照的孤立龙图。
- 龙眼半径小于 1.5 米视为比例失败返图。
