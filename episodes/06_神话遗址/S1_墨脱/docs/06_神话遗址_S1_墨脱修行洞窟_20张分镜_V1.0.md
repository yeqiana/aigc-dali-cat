## 一、完整故事闭环

科考队队员林澈随队进墨脱雨林采样，雨季即将封山，这是最后一次进谷窗口。研究道教"羽化"传说的导师次仁随行，想用实地证据补全论文。峡谷深处的石窟里，盘坐着一具尸解后留下的遗蜕，石壁上刻满发光的经络纹路。遗蜕身后，三处凹痕里各镇着一具干枯的小尸。向导达瓦年轻时进过石窟，他的父亲就是当年进洞后"留下来"的人。导师认出纹路与道藏羽化经一致，伸手触碰——纹路被惊醒，导师手臂开始发光，羽化在他身上被触发。林澈把导师拖出石窟时，遗蜕身后第三具小尸动了一下，石壁的光跟着他们涌到洞口。返回县城后，导师手臂的光没有消失，他不再说话，只是看着自己的手；带回的石片在密封袋里仍亮着，像在呼吸。

**任务闭环：** 峡谷记载验证完成，导师被带出石窟，位置封存。
**关系闭环：** 达瓦承认父亲是洞里的第三具尸，隐瞒落地。
**异常留白：** 遗蜕是谁、他羽化去了哪里、三尸为什么还镇在洞里。羽化成仙是真的——但没人能解释它。

**系列开场宣言（图20 结尾字幕）：** 从那天开始，我发现这个世界的另一面。
**引出下一期（图20 后）：** 石片在密封袋里亮着，纹路与林澈手机里存过的一张老地图标记重合——指向下一个坐标。

## 三、异常母题

`异常母题 = 发光经络纹路 + 流动的光 + 呼吸般的亮暗`

三个载体：石窟石壁经络 → 导师手臂经络 → 密封袋石片。
三级尺度：石壁纹路/导师手臂 → 遗蜕与三尸 → 整座峡谷都是羽化的痕迹。

**修仙体系（本集世界观拼图）：** 斩三尸 → 尸解 → 羽化。触碰纹路会触发同样的羽化过程，这就是"不能碰"的原因。
