# 神话遗址系列 · 系列总案与选题池 V1.3

> 制作依据：`standards/制作规范_正式版.md` v2.3
> 本系列与科考队系列（04）独立立项，复用第七科考队母题与林澈角色，不继承哀牢山/红外相机机制。

## 一、系列概念

每一集：科考队进入一个特殊地点（墨脱、雅鲁藏布江、冰岛、南极、太平洋、罗布泊、埃及、秦岭、海底），意外发现神秘遗址。遗址是古神、上古文明或外星文明留下的生活痕迹，可以印证一个神话传说、成仙、修炼、龙凤等超现实现象。痕迹不做科学解释——它是什么，就是什么。

全系列通过逐集拼图，最终拼出一个完整世界观：地球上存在过、并且仍存在多个古老文明。人类神话不是编造，是它们留下的痕迹。有些文明已经消亡或沉睡，有些仍然活跃——活跃的文明还在运转、还有人住在里面。

发现它们之后，接触方式不只有一种：有的遗址用禁忌保护自己，越界就会被卷入；有的文明真实存在、可以交流。科考队先带着人类自己的好奇与骄傲深入——技术发展到这个程度，我们到底能发现什么——然后才明白，被发现的是我们自己。

## 〇、叙事借鉴（借什么，不借什么）

> 借鉴对象只用于提炼结构与世界观张力，不搬运具体物件、人名、剧情或机制。

| 对象 | 借 | 不借 |
|---|---|---|
| 《鬼吹灯》 | 一卷一地点 + 民间传说钩子 + 主角找东西/救亲人的动机 + 系列暗线逐卷加深（献王 → 鬼洞诅咒式） | 盗墓合法性、摸金校尉人设、具体机关 |
| 《盗墓笔记》 | 青铜文明 + 尸解 + 上古遗痕的设定质感："文明不是怪物，是另一套秩序" | 青铜树、蛇眉铜鱼、张起灵等具体物件 |
| 《三体》 | 文明层级张力："它放我们走，不是善意，只是我们太小""接触有代价" | 黑暗森林理论本身、三体人名与剧情 |
| 《凡人修仙传》等 | 境界感而非境界表（斩三尸 → 尸解 → 羽化已够用；可挂地仙/洞天/瑶池质感） | 修炼等级数字、灵根、法宝体系 |
| 《山海经》 | 给古神线一个可复用的神系目录（西王母、烛龙、应龙），每集解释对象有出处 | 原文条目式介绍 |

纪律：

- 每集借鉴点写进选题卡"叙事借鉴"栏，发布前逐条核对"是否只借了结构、没搬具体物件"。
- 禁止把借鉴对象的名字、人名、地名、专有名词写进成片字幕。
- 借鉴目的是让世界观有厚度，不是让读者认出"这是哪本书"。

### 1.1 三类文明

- **古神：** 曾被当作神明膜拜的存在，埃及、冰岛等地留下它们的痕迹。
- **上古文明：** 早于人类史记载的文明，墨脱修行者、秦岭居所、南极冰下城市、沉没大陆属于这一类。
- **外星文明：** 不属于这颗星球的文明，罗布泊之门、海底深渊指向这一类。

三类文明不互斥：罗布泊之门与墨脱修行者使用同一符号，暗示它们同源或曾来往，但不解释。

### 2.2 同源符号：经络发光纹路

- 每集遗址上出现同一视觉符号：类似人体经络的发光纹路。
- 跨集出现时不解释，作为世界观拼图的"咬合点"。
- 每集只允许出现 1 次同源符号，承担 1 次剧情信息（通常是证据推翻或终局重读）。
- **生成规范（硬性）：** 同源符号统一为"青白微光、沿表面纹路流动、明暗如呼吸"，出现在遗址表面、遗物表面或人类皮肤上；禁止生成成电路、霓虹灯管、科幻全息或纹身。
- **同源判断标准：** 观众应能仅凭"青白光 + 呼吸式明暗 + 类经络走向"认出它与前几集是同一符号，即使载体不同（石壁、鳞纹、青铜器）。

### 2.6 视觉基调（硬性）：iPhone 6 随手拍真实感

- **全系列唯一视觉基调：** 所有画面都是 iPhone 6 随手拍的质感——竖构图 9:16、暗光高噪点、轻微手抖、自动对焦失焦、构图歪斜、边缘裁切、手指或袖口偶尔入镜。
- **禁止档案视觉：** 画面中不得出现档案封面、编号排版、红印章、坐标纸、记录板、盖章文件、封条等任何"机构档案"元素。
- **禁止屏幕 UI：** 卫星图、雷达、文件管理窗口、数据表格等屏幕界面不作为画面主体；若必须出现，仅作背景且不可读。
- **道具替代：** 需要用"记录/证据"承载信息时，一律用手机拍摄的照片、视频回放、语音消息、口头转述；禁止用纸质档案或电子档案界面。
- **场景统一：** 无论遗址在深海、冰川还是地下，都是"林澈举着手机拍到的画面"，画面来源始终是手机镜头。

### 2.3 拼图纪律

- 单篇自治：新读者不追前作也能理解当集"科考队发现了什么、怎么收场"。
- 每集只推进 1 块拼图：只确认"这处遗址对应哪个传说、它现在是死是活"。
- 禁止单集内出现：文明名称与完整历史、机制说明书、科学解释、多块拼图同时落地。
- 活跃文明不可解释：它为什么还活着、怎么运转、要去哪里，全部留白。

### 2.4 接触模式

每集在选题卡写明接触模式：

| 模式 | 科考队与文明的关系 | 情绪弧线 | 代表集 |
|---|---|---|---|
| **模式A 禁忌越界** | 遗址用禁忌保护自己，人类越界被卷入 | 正常进入 → 禁忌出现 → 越界 → 对抗 → 逃出/余波 | S1 墨脱、S2 罗布泊、S3 雅鲁藏布江、S4 秦岭、S7 埃及、S8 冰岛 |
| **模式B 发现交流** | 文明真实存在，可以简单交流；也可能发现对方有恶意 | 正常好奇 → 发现遗址 → 震惊 → 震撼 → 被发现 → 简单交流或遭遇敌意 → 有惊无险逃出 | S5 南极、S6 东海龙宫、S9 海底深渊、S10 昆仑、S11 长白山、S12 三星堆、S13 地心 |

#### 模式B 交流纪律

- 交流允许，但只到"你是谁/我们在哪/你们在做什么"级别，不解释文明机制与历史。
- 交流内容必须是观众能听懂的只言片语或画面语言，不写成文明说明文。
- 可以是善意（龙宫允许你离开），也可以是恶意（对方想留下你），但不能被"制服""消灭"。
- 情绪弧线必须走完：正常 → 好奇 → 震惊 → 震撼 → 被发现 → 交流/敌意 → 有惊无险逃出。
- **争议钩子（硬性）：** 每集必须埋一个评论区吵不完的问题——它为什么放我们走？使者为什么报平安？深渊为什么说"别再下来"？终局必须让这个问题悬着，不解释、不解答。
- **禁止温和收尾：** 交流结束不等于悬念结束；"有惊无险逃出"后必须留一个让人反复回看的事实层矛盾（照片、潮痕、一句带话）。

### 2.5 系列钩子与引出下一期

- **每集都带着秘密：** 科考队每集都会找到未知的东西，其中携带着巨大的秘密；解析这个秘密后，引出下一期。
- **引出下一期（硬性）：** 每集在事件闭环、争议钩子之后，必须再留一个"系列预告钩子"——通常是同源符号的新线索、一份未解记录、一句指向下一地点的台词。它不能是"未完待续"，只能是指向下一块的拼图线索。
- **第一集开场宣言：** S1 结尾必须出现系列宣言句："从那天开始，我发现这个世界的另一面。"之后每集余波都围绕"这个世界的另一面"展开。
- **预告形式限制：** 引出下一期只能用物件/符号/一句台词，禁止用字幕直接宣布"下一集去XX"。

## 三、系列治理

### 3.1 人物

- 主角林澈（第一人称）是第七科考队队长/核心队员，每集跟随科考队执行真实科考任务（水文、考古、地质、深海、极地等）。
- 每集 1 名主要关系人物 + 0 至 1 名功能性队友；关系人物是科考队成员或任务相关者。
- **动机模型：** 对未知的好奇与兴趣 + 职业使然为主，偶尔带一点功利名利（首发发现、论文、晋升）；禁止纯好奇作死，也禁止把关系写成纯亲情煽情。
- **现在正在发生（硬性）：** 每集必须有一个"现在正在发生"的紧迫驱动——窗口期、倒计时、正在恶化的事件、正在逼近的天气/水位/沙暴，让科考队此刻必须进入现场。过去的事（年轻时见过、父亲当年）只能作背景，不能代替当下的动机。
- 关系人物必须承担隐瞒、选择或告别，不能只负责讲知识。
- 新关系人物必须先补参考图锁定。

### 3.2 科技

- 每集最多一组主要技术，只承担抵达、确认范围或辅助行动。
- 禁止连续两张展示仪器界面；卫星图、档案、文献原则上不承担主要推进。

### 3.3 节奏模式

- 默认混合模式（鼠鼠完成人物行动 + Zayn 完成遗址扩张与终局重读）。
- 每集必须同时标注 S1~S8 与 Z1~Z8，两套标签都完整。

### 3.4 发布纪律

- 标题可选：不写标题或写 ≤20 字标题；超过 20 字必须重写，禁止长标题当简介。
- 话题标签最多 5 个：场景 1-2 + 类型 1-2 + 内容 1（如 `#AI故事`），不堆砌。
- 标签必须与当集地点、遗址直接相关，禁止跨集复用同一组标签制造话题重叠。
- **每集小标题（硬性）：** 每集必须有系列内小标题，格式 `《第七科考队 No.N｜小标题》`，N 为集序号，小标题 ≤8 字、点出当集核心异常。小标题用于系列索引与预告，与可选的发布标题（≤20字）互不替代。

## 五、试点锁定

试点先做 S1 墨脱、S2 罗布泊，理由：

1. 墨脱对应"成仙/修炼"，罗布泊对应"楼兰/外星"，覆盖上古文明与外星文明两类，且两集都是活跃文明，能先验证"它还在"的呈现方式。
2. 两地地域借势强（#墨脱 #西藏 / #罗布泊 #楼兰），贴近现有民俗恐怖受众。
3. S1 与 S2 通过"经络发光纹路"同源符号直接咬合，能验证拼图机制是否成立。

## 六、淘汰规则

以下任一情况不得进入分镜：

- 前 3 张只能看到卫星图、屏幕、报告或队员表情。
- 删除地点名后，故事可原样替换到任何地点。
- 关系人物没有隐瞒与选择，只提供专业知识。
- 规则与遗址母题无关，主角因好奇故意触发。
- 中段连续展示三个以上证据，却没有人物动作或环境变化。
- 单集解释超过 1 块世界观拼图，或把整套文明来历、机制讲完。
- 用科学原理（能量、技术、改造、编码）解释痕迹。
- 活跃文明被"制服""消灭"或解释清楚。
- 模式B 中交流变成文明说明文，或把对方写成可以被战胜的敌人。
- 再次使用哀牢山、红外相机、蹲着的人、未来时间戳或1985年档案。
