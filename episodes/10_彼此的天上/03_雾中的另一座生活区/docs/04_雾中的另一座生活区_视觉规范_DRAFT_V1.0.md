# 《雾中的另一座生活区》视觉规范 DRAFT V1.0

## 1. Profile

M-ROAD-2020｜2020s 川西自驾手机相册纪实

## 2. 本集主视觉

- 类型：普通旅行航拍 / 偶然设备越界
- 核心问题：那边到底是不是一个完整社会？
- 核心异常：男女主按原计划凌晨上山看日出、拍云海；前夜雨停降温后的低云仍压在山谷，消费级无人机偶然穿云后看到一个仍在正常运转的完整前工业文明，并因男主多停几秒发生设备越界。
- 本集视觉职责：允许成为全季视觉规模峰值，但世界观答案仍留给 EP05。

## 3. 本集专项硬要求

普通旅行计划必须先成立；无人机不得作为调查设备。每个文明展示帧必须承担一个新的社会推论，并按“家庭生活 → 农业/水利 → 生产交换 → 公共工程 → 成片城区”逐级放大。文明可以壮观，但必须仍在被普通人使用，不得仙侠化、遗迹旅游化或对应可辨识唐宋明清。

## 4. 通用
