## 文明展示硬约束

1. **允许大展示，不允许遗迹旅游。** Frame 05–09 可以连续完成尺度升级，但每张必须新增一种社会信息：农业 / 水利 / 生产交换 / 公共工程 / 城区规模 / 跨集道路回收，禁止同一古城只换景别。
2. **必须是活着的文明。** 大型工程、道路、桥梁、市场、公共建筑都必须有人实际使用；禁止荒废遗迹、祭坛巡礼、神秘仪式作为主要视觉消费。
3. **不得对应现实中国具体朝代。** 禁止可辨识唐宋明清服饰、宫殿、牌坊、中文匾额、长安式城市复刻；允许形成“古老但不可归类”的前工业社会。
4. **奇观不能覆盖普通人。** Frame 07–09 即使尺度最大，也要保留挑水、搬货、牲畜、人流、修屋等生活尺度参照。
5. **EP003 是全季视觉规模峰值，不是世界观答案峰值。** 不解释文明来源、年代、为何重合，也不证明它属于过去/未来/平行世界。

## 跨集接力锁

- 浅色头巾年轻女人：Frame 14 首次形成明确人物视觉锚，只表现普通人的保护和好奇；EP04 才承担救援动作。
- 失联无人机：Frame 17–20 必须真实丢失；EP04 回收实体，EP05 回收存储卡记录。
- 模糊亮区：Frame 18 只能达到“像我们的车”；EP05 才允许看清现代柏油路、护栏、停车带、车辆与车旁两人。
- EP001 回收：Frame 09 只通过道路/运输形态让观众产生联想，不用字幕直接宣布“就是第一集那条路”。
- EP002 回收：Frame 12/14 的“拉孩子、避亮物”形成行为同源，但不解释为硬性超自然规则。

## Storyboard 硬检查

- Frame 01 必须是男女主自拍/正脸旅行照，并自然带出本集现实任务；不得拿无人机画面代替人物进入。
- Frame 03 前必须完成异常直见：雾缝中的屋顶 + 正在修屋的人必须清楚可辨。
- Frame 05–09 是文明尺度升级段，每帧都要新增社会层级，不得只换远近。
- Frame 11–16 是“观察者变成被观察者”的核心反转，群体反应必须逐步传播，禁止全员同步逃跑。
- Frame 15 必须让“多停几秒”成为可见的主动选择，而不是字幕硬说男主犹豫。
- Frame 18 禁止清晰现代车/道路/人物，任何能直接证明“我们在他们天上”的像素都应退回模糊。
- Frame 19 必须完成情侣关系冲突，不能把无人机失联当作纯设备事故。
- Frame 20 不新增异常、不追加续集钩子，用正常日出与缺席的无人机结束本集。
- 任意连续 4 张至少发生一次新证据 / 认知升级 / 人物选择 / 可见后果。
- 字幕不得替像素制造核心异常；第一人称/无人机/手机拍摄源必须物理合法。
