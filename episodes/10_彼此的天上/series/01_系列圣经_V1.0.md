# 《彼此的天上》系列 Bible V1.0

## 1. 一句话系列

2020年代前半段，一对普通情侣兑现拖了很久的川藏自驾旅行，在少数山区与特殊天气的重合中，偶然窥见一个仍处于前工业阶段、与我们无法正常互见的人类社会；随着接触加深，他们发现双方都曾把对方的普通生活误读成神话与禁忌。

## 2. 现实人物锚点

- 第一人称叙述者：男友，普通上班族，偏理性，主要手机拍摄者。
- 女友：刚结束一份干了几年的工作，新工作已经确定，中间有一段空档。
- 旅行原因：两个人很早就约好去川藏一带，一直因为工作拖着没去；这次终于兑现。
- 情绪锚点：不是疗伤或大悲剧，而是“终于把一直拖着的生活愿望补上”。

## 3. 世界规则

### R1｜平时互不可见
两个社会平时正常生活，彼此不存在稳定通道，也不会主动寻找对方。

### R2｜重合需要地点与天气共同成立
只在极少数山区“薄处”出现短暂重合。

两个社会并非随时能够彼此看见，也不存在可以被主动开启或稳定复现的固定入口。本季所有接触都只发生在少数山区的特殊地点，并同时伴随一组相近的自然条件：

`连续降雨 → 雨势停止 → 气温快速下降 → 低云、大雾或湿冷水汽压入山谷 → 短暂空间重合`

夜晚并不是必要条件。黑夜、雨幕、湿玻璃、山雾、清晨云海等，只是不同场景下对这一短暂重合窗口的具体表现。真正反复出现的共同特征，是山地、强湿度变化、低云和有限能见度共同形成的短时自然环境。

- EP01：夜间远距灯火，是低照度与山地薄雾中的第一次远距离目击；
- EP02：雨夜民宿，是降雨停止后低温、湿玻璃与低云共同形成的局部接触；
- EP03：清晨云海证明重合并不依赖黑夜——前夜持续降雨，凌晨雨停降温，低云仍压在山谷，无人机穿过云层后第一次进入另一侧完整社会的可见范围；
- EP04：贴地雾再次形成更深程度的局部重合，使接触从设备尺度升级到人体尺度；
- EP05：不再创造新的观测条件，而是通过既有记录重新理解此前数次重合。

角色只能逐渐观察到这些事件之间存在相关性，不能据此总结出精确公式，更不能主动预测、制造或控制下一次重合。

系列始终保留一种可能：也许不是某种“门”被打开了，只是在极少数时候，两个原本各自正常存在的地方，离得比平时稍微近了一点。

### R3｜接触有深度
本季按以下顺序升级：

`看见 → 局部响应 → 设备越界 → 人体短暂越界 → 记录回看`

### R4｜无火之光不是物理规则
汽车灯、无人机灯、手机亮屏不会打开通道、关闭通道或伤害任何人。
“无火之光”只是对面社会长期形成的文化避让习惯。

### R5｜不做人体异化
人体回来后没有：
- 同化；
- 幻听；
- 世界裂缝；
- 被召回；
- 特殊血统；
- 天选；
- 身体异变。

## 4. 对面社会

- 不是中国古代朝代；
- 不是时间穿越；
- 不使用可辨识的唐宋明清服饰；
- 不允许主角轻易读懂文字；
- 不允许双方流畅语言交流；
- 技术阶段：前工业社会；
- 有普通家庭、交易、牲畜、修屋、争吵、垃圾、泥水与生活秩序；
- “普通生活密度”必须高于“神秘景观密度”。

## 5. 折多山软连接

《折多山守夜人》只作为旧作品彩蛋与旅行现实锚点：

- EP01 经过时最多 1–2 张 / 一句轻提示；
- 不重讲旧剧情；
- 不宣布折多山就是入口；
- 不把新异常绑定到真实折多山具体点位；
- 老观众可以怀疑旧作是否属于同类现象，但作者不确认。

## 6. 六个跨集彩蛋

1. 不存在的路：EP01 → EP03
2. 粗织布：EP01 → EP02 → EP03 → EP04
3. 小孩：EP02 → EP03/EP05（身份不确认）
4. 年轻女人：EP03背景 → EP04帮助 → EP05回看
5. 无火之光：EP01 → EP03 → EP04轻动作 → EP05历史重读
6. 钟：仅作为 EP03/EP04现实警戒声，不做女主越界副作用

## 7. 双向误读

我们：
- EP01 以为夜行队伍是异常仪式；
- EP03 才发现那可能只是另一社会的正常运输/赶路。

他们：
- 无法理解汽车灯、手机、无人机；
- 把“雾中无火之光”与危险异常联系起来。

系列内核不是“他们把我们当神”，而是：

> 两个文明都会把对方的普通生活误读成神秘事件。
