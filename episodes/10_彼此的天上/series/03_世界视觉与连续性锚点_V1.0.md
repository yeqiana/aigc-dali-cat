# 《彼此的天上》世界视觉与连续性锚点 V1.0

## 1. 对面社会视觉语言

### 建筑
- 石基 + 木结构
- 不追求宏伟、规整、洁净
- 屋顶有维修痕迹、补丁、湿痕
- 不采用一眼可识别的中国古代宫殿制式

### 道路
- 湿泥土路 + 局部碎石
- EP01 夜行路与 EP03聚落外围道路走向必须能互相对应
- EP04女友脚下异世界道路必须继承同一材质

### 粗织布
- 浅灰米色为主
- 植物纤维感、织纹粗、不整齐
- 用途：盖货、包裹、遮雨、临时遮手机
- EP01远景只能读到“浅色盖布”，不应夜间长焦看清织纹

### 灯具
- 火把 / 简单油灯
- 不做漂浮光球、不做仙侠灯笼海

### 牲畜
- 固定 1–2 类常驻，不随机牛马羊全上
- 夜行运输以驮畜为主

### 大型石质遗迹
- 全季唯一宏大遗迹
- 位于聚落较远端
- EP03远观；EP05无人机坠落前掠过其墙面
- 禁止仙宫化

## 2. 年轻女人连续性

- 发型、衣服剪裁、外套/围布锚点固定
- EP03、EP04、EP05必须是同一人
- 不使用明显朝代服饰
- 服装材质与社会整体一致

## 3. 无人机空间路径

EP03：
`男女主所在现代山坡`
→ `穿入低云`
→ `聚落上空`
→ `大型石质遗迹方向`
→ `年轻女人院落/聚落外围`
→ `失控坠落`

EP04：
- 女友误入区域必须位于同一聚落外围
- 年轻女人能合理拿到此前坠落的无人机

EP05：
- 恢复素材中的最后路径必须和 EP03/04一致

## 4. POV合法拍摄源

允许：
- 男主手持手机
- 女友手机（必须在 Storyboard 明确）
- 车内/行车记录类固定视角（若正式启用需记录）
- 无人机
- EP04高潮：男主把手机扔地后，掉落手机继续录像

禁止：
- 没有第三拍摄源却突然出现完整情侣同框
- 男主双手都在拉人时仍出现稳定手持第一视角
- 对面居民“电影机位”无来源

## 5. 真实地点治理

真实地点只承担旅行锚点。
真正异常停车带、山谷、民宿、聚落对应点全部虚构，不能指向具体真实商户或村庄。
