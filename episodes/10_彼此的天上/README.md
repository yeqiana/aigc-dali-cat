## 系列内核

两个完全不了解彼此的人类社会，因为少数偶然接触，把对方的普通生活误读成各自无法解释的怪事。

人物弧：

`偶遇 → 接触 → 主动求证 → 为求证付代价 → 回到普通生活`

最终不是“守护世界秘密”，而是：

> 我们年轻的时候真的遇到过一件没人会相信的事。后来生活忙起来，就越来越少研究；只是偶尔看到旧照片，还会想起那条不存在的路。
