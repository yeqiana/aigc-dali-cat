- 第一人称：男友为主记录者；女友/无人机/掉地手机仅在分镜明确时作为合法第二拍摄源。
- 现实情绪锚点：女友换工作空档，两人终于兑现拖了很久的川藏旅行。
- 本集类型：回看 / 生活余波
- 本集核心阅读问题：当证据终于够了，我们还要不要继续证明？
- 唯一核心异常：回到普通生活后恢复无人机素材，两人第一次看到对面社会的日常与古老图像；男主最终没有把整理好的路线证据发出去，之后生活逐渐盖过这件事。
- 有意义触发：回西安恢复工作与新工作准备，男主抽空修复无人机存储。
- 直接后果：录像回收前四集证据，证明对面也只是普通社会，并让“雾中无火之光”呈现为可能延续很久的文化习惯。
