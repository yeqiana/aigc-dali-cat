# 《无人机里的旧记录》视觉规范 DRAFT V1.0

## 1. Profile

M-ROAD-2020｜2020s 川西自驾手机相册纪实

## 2. 本集主视觉

- 类型：回看 / 生活余波
- 核心问题：当证据终于够了，我们还要不要继续证明？
- 核心异常：回到普通生活后恢复无人机素材，两人第一次看到对面社会的日常与古老图像；男主最终没有把整理好的路线证据发出去，之后生活逐渐盖过这件事。

## 3. 本集专项硬要求

古图只做到“像现代东西”而非清晰手机/无人机；出租屋和忙碌生活必须普通、克制。

## 4. 通用
