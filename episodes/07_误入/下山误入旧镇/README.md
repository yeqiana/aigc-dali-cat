## V1.1 核心调整

- 前半段删除“当地人提前警告 / 禁忌提醒”，改为纯现实链路：拍云海 → 暴雨 → 塌方 → 误走旧县道 → 进入旧镇。
- 后半段删除“镇民敌意 / 规则逃生”解释，改为：镇里的人早已接受自己的生活；确认三人来自“外面”后，善意把他们送回仍在继续向前的时间。
- 核心立意：**一个已经停下来的地方，把还要继续往前的人送了回去。**
