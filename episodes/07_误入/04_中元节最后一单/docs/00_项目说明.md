# 00｜项目说明

## 项目名

《中元节最后一单》

发布标题建议：**今晚最后一单**

## 定位

都市现实侵入式伪纪录片 / 第一人称外卖骑手经历体。

不是规则怪谈，也不是开场直接说明“404闹鬼”。前段必须像普通夜班记录，中元节只作为日期背景；异常从户型、电话、订单、人物、物证、空间、系统记录逐级升级。

## 基本设定

- 时间：农历七月十五深夜
- 主角：夜班外卖骑手，第一人称
- 地点：普通有人居住的中国老小区
- 任务：送完当天最后一单
- 核心空间：四楼 403 与 405 之间是一整面旧墙
- 核心异常：订单地址后续变为 404，而现实中不存在 404
- 重复实体：普通女人 + 大号暗红塑料编织袋
- 终局证据：平台出现一张主角站在 404 门前的配送照片；客服确认照片来自主角骑手端，但主角本人就在照片里

## 结构

1. 01–03：完全日常
2. 04–06：现实出现轻微错误，404 首次曝光
3. 07–12：人物 / 水迹 / 定位 / 正常住户 / 外卖袋逐步积累不安
4. 13：中段第一次明确危险爆点
5. 14–18：空间错误、旧物证、实体身份线索、现实人物否认
6. 19：白天现实再次否认 404
7. 20：系统记录反向确认异常，开放式结尾
