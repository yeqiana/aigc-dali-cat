故事表面是《桃花源记》的现代翻写：一个重修考砸、被实习证明和家里催促围住的大三男生，从学校后山的铁丝网缺口钻进一处四面绝壁的封闭盆地村落。但故事真正要说的不是桃花源多美，而是：这处被时间封住的村子不是仙境，是一口枯井，是难民后代用世世代代的无知与恐惧给自己修的千年墓穴。

主题落点：外面的世界很累，但它是一条一直往前滚的大河；山谷很静，但它是一潭死水。主角最后选择回到那条吵闹的河里。

## 一句话故事

重修考交卷后躲进学校后山的普通大学生，误打误撞走进一个被绝壁封了几百年的桃花源；因为给村里的少年一颗工厂薄荷糖、又讲了几句外面的世界，天亮前被村里的长辈亲手送出了石缝。

## 人物

- **P01 林舟**：23 岁，男，第一人称“我”。普通理工科本科生，普通黑色自然短发，洗得发白的灰色连帽卫衣＋深灰休闲长裤＋磨平防滑纹的开胶旧球鞋，随身一台普通智能手机。没有任何专业异常处理职能；他的身份与技能都不能成为解开这个村子的捷径。
- **秦叔**：中年，男，村头土屋主人。手掌被泥土浸得发黑、指纹磨得模糊，说话舌根发硬。他不是反派，他是这个村子的守门人：他要保的不是秘密，是几百口人活命的方式。
- **小石**：15 岁，男，秦叔独子。只尝过茅草根和野蜂蜜的舌头，从没见过玻璃屏和工厂糖果。
- **其他村民**：田埂上直起腰的汉子、屋檐下停梭的妇人、泥地里赤脚的幼童——只在群体定格和零散日常里出现，不给单独戏份。

## 空间与时间线

学校阶梯教室走廊 → 后勤处背后荒坡（被暴雨冲垮的绿色铁丝网缺口）→ 红土与阔叶林 → 野桃林 → 干涸石渠 → 铁线蕨后的狭窄石缝（“初极狭，才通人”）→ 四面环形绝壁下的封闭盆地村落 → 秦家土屋 → 老水井旁 → 石缝 → 学校后山 → 绕城高速与工地。

本集时间跨度约三天多：第一天下午进山、傍晚被秦叔领进屋；中间三天在山谷里；第三天傍晚发生薄荷糖事件；当夜被逐客；第四天拂晓出山。

## 故事推进（20 张）

1. **01–04 逃离学校、钻进后山**：重修考交卷铃响，他推开答卷冲出教室，手机上辅导员在两百多人大群点名催实习证明、母亲发来五十九秒语音。他没回宿舍也没去食堂，一路拐进后勤处背后的荒坡，从被暴雨冲垮的铁丝网缺口钻进去，最后钻进铁线蕨后的石缝。
2. **05–07 撞见那个山谷**：跌出石缝，他看见绝壁下那块被扣在深渊底部的三四百亩洼地；一声碎石落水，整个山谷的动作同时定格；秦叔插下短锄走过来，平静地邀他进屋吃碗热食。
3. **08–09 一顿饭与三天**：土屋里没有一根电线、找不到一片塑料，只有松木烟气、碎麦饭、盐渍野葱和发苦的竹笋；秦叔只问了一句“外头，还争吗？”。接下来的三天，他跟着公鸡醒来、睡竹席、听老人讲对不上年号的旧事，三年焦虑症好像突然自愈。
4. **10–13 那颗薄荷糖**：第三天傍晚他在水井边削竹篾，发现小石三天来一直盯着那台没电的黑屏手机；他剥出最后一粒润喉薄荷糖递过去，少年被工业甜味和“外头”的描述同时击中，眼里烧起他在自习室和招聘会上见过的那簇火。
5. **14–15 反制与真相**：秦叔一刀劈碎厚竹，头也不抬地支开儿子；当夜他提着菜籽油灯进来，把揉烂的糖纸和湿纸巾放在床头，说天亮前出山去，并说这山谷从来不是仙境，是一口枯井，人要活命就只能把这口井当成天地。
6. **16–20 回到那条河**：拂晓寒雾里，秦叔把他送到石缝前，塞给他两个荷叶包的硬麦饼，让他顺着暗水流爬、别回头。他最后回头看了一眼照常升起的炊烟，爬出后山，迎头撞上高速货车的轰鸣和打桩机的震动，手机上辅导员和母亲的消息原封不动地压回来。他咬碎冷硬的麦饼，回复老师、回拨母亲，走下山。

## 母题与闭环

- “不足为外人道也”被重新解释：不是避世的高洁，是对被外界发现的极度战栗。
- 山谷＝一口枯井/一潭死水；外面＝一条一直往前滚的大河。秦叔的整套逻辑就是“人心一野，这地方就不是避难所，是牢房”。
- 闭环物件：荷叶包的硬麦饼（他带出来的，也是他咽下去的）、绿色塑料糖纸（他带进去的，被退回来的）、湿纸巾（被塞回书包的现代物）、没电的黑屏手机（他给少年看的东西，从没真正亮过）。

## 生活感与真实性原则

- 本集所有画面都必须像当事人用一台普通智能手机随手拍到的，不像剧情剧照或宣传海报。
- 山谷里没有电，只有天光、晨雾、油灯和灶火；出山后的白昼强光、尾气与工地泥尘也必须真实。
- 村落的克制必须靠像素成立：没有红砖、没有塑料瓦、没有电线；房子和农田整齐到不自然，本身就是信息。
- 画面不靠“更大的光”升级冲击力，升级来自空间矛盾与人的后果。
