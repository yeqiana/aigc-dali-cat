# 误入系列｜生产入口

> 系列定位：旅行探险者误入小众地点的异常空间，穿过入口后短暂进入另一个时代或文明，在当地生活规则中寻找出口，再被现实物理性地弹回。
> 节奏模式：纯 Zayn（异常母题、同源复现、人物卷入、尺度扩张、事件闭合、终局重读）。
> 情绪边界：同行者是探险同伴，不设置亏欠、隐瞒、寻亲、悔恨或情感债务；叙事驱动力来自探索、判断和撤离。
> 系列连接道具：饭桌上偶尔多出一副没人动的碗筷，仅作为跨篇探索线索，不解释来源，不承担欠债含义。

## 当前篇目

### A《古镇茶馆·还席》

- 地点/时代：民国时期苏南水乡，一座不在旅游地图上的临河茶馆。
- 进入方式：旅行者为寻找小众景点“旧水关”沿废弃石桥行走，雨雾中穿过茶馆后门帘。
- 异常母题：茶馆里所有东西都保持着“刚刚被使用过”的状态：茶仍有余温，饭菜仍冒热气，空碗筷刚被挪过，窗内侧不断起雾，旧物上留着新鲜触碰痕迹。它没有固定形状，不发光，不组成符号，也不替人物选择方向。
- 事件闭合：主角因好奇反复检查这些生活痕迹，被地方巡查人发现后拖凳撞破旧窗，摔回现实；现实中只剩一枚民国铜钱和一张仍像刚拍下的空席位照片。
- 异常留白：茶馆究竟在招待谁、为何所有物件像刚有人离开、半枚铜钱是谁留下、为何允许主角返回，均不解释。
