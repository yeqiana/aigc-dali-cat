# 《中元节误入流水席》关键帧提示词

## 统一风格底座

2000年代末至2010年代初普通消费级数码相机 / 早期智能手机随手拍质感，中国普通农村真实生活记录照片，低清晰度，轻微失焦，轻微运动模糊，JPEG压缩痕迹，有限动态范围，局部高光过曝，暗部细节不足，白平衡略有偏差，低饱和灰黄土色调，不精致构图，主体可以被树枝、桌沿或前景遮挡，真实偶然抓拍感，没有商业摄影感，没有电影灯光，没有恐怖片海报感。

## 04｜老人提醒

第一人称视角，傍晚中国山区乡道，车窗边一个简陋水果摊，一位六七十岁的普通中国老大爷站在果筐旁，神情认真但动作自然，像买完水果时顺口提醒一件当地忌讳；背景有停靠的普通轿车和两个轻松的年轻同行者，车窗、水瓶等前景遮挡部分画面。不要做成老人拦路或恐怖片NPC。

## 11｜第一次看见流水席

第一人称手机随手拍，深夜中国山里树林，刚从树林穿出来，前景树枝草叶遮挡，前方小空地只有3–5桌真实乡村流水席，桌上是扣肉、蒸碗、热汤、凉菜，老人、小孩、妇女、中年人穿普通现代衣服正常吃席，简易暖黄裸灯泡局部过曝，四周树林死黑。重点是“原来真的有人办席”，不能提前恐怖化。

## 19｜红纸名单

第一人称俯拍近景，夜间乡村流水席桌面，一张起皱、带油点和菜汁痕迹的红纸压在桌子中间，上面手写多列中文姓名，每个姓名后面清楚带“故”字；周围有吃剩的菜盘、旧瓷碗、筷子和油污，像吃饭过程中偶然低头发现，而不是剧情道具摆拍。

## 21｜几十桌集体回头

第一人称手机随手拍，深夜山中空地，乡村流水席已经扩张成几十桌，延伸到树林深处，前景是主角刚吃过的碗、筷子和残菜；全场老人、中年人、妇女、小孩突然停止动作，同时安静看向镜头。所有人仍是正常人脸，没有鬼脸，没有扑向镜头，恐怖来自普通人的集体注视与数量压迫。
