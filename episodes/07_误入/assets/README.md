# 《古镇茶馆·还席》资产锁定

## 主角（第一视角）

- 仅出现手、鞋、袖口、倒影或被遮挡的肩部，不出现正面清晰脸。
- 现代服装锁定：深墨绿色防水冲锋衣，黑色帆布背包，灰色运动鞋，左手黑色运动手表；进入异时代后只在画面中出现被当地粗布外套覆盖的袖口，回现实后恢复冲锋衣。
- 手部连续性：成年东亚女性，自然偏浅暖调肤色，短圆指甲，无戒指、无手链，左腕黑色运动手表；旧时代服装只遮住手表，不改变手部外观。

## 同伴

- 只作为探索行动参照，成年男性，深棕雨衣、黑色折叠伞、米色斜挎包；不承担秘密、解释或情绪闭环。
- 可在远景、背影、局部手臂中出现；不要求固定面部资产。

## 时代人物

- 原创民国地方巡查服：深灰蓝粗呢短外套、窄肩、圆帽无徽章、铜色素面纽扣、黑布鞋；手持木柄短手电或油纸记录夹，禁止现代警棍、枪械、警徽、军装肩章、清晰官方标识。
- 只作为追逐压力，不是权威解释者；不说出异常来源。

## 场景锁定

- 苏南水乡旧茶馆：黑木梁柱、灰砖墙、临水木窗、竹帘、粗陶茶壶、白瓷茶盏、深色方桌、油纸灯；潮湿雨雾，低饱和灰绿与木褐。
- 现实入口：废弃石桥、芦苇、积水青石、现代背包和手机手电。
- 异时代层：同一茶馆但无现代物件，桌上摆着粗粮饭、腌菜、河鲜汤和一副多出来的空碗筷。

## 异常母题锁定

`异常母题 = 被保留下来的“刚刚使用过”状态：余温、热气、内侧凝露、轻微位移和新鲜触碰痕迹`

- 异常只呈现生活痕迹，不主动指路、不召唤人物、不组成符号、不替人物做决定。
- 主角因好奇挪杯、摸桌面、查看袖口、检查空席和木窗；真正的移动由人物判断、追逐压力和物理碰撞推动。
- 所有异常必须有真实材质和来源感：蒸汽来自饭菜，凝露来自温差，位移来自刚有人用过，痕迹来自接触；禁止发光、几何图案、漂浮线条和“传送门”。

- 载体一：茶盏、饭菜、桌面余温，细节/手持尺度。
- 载体二：粗布袖口、空席、碗筷和窗内侧凝露，人物/房间尺度。
- 载体三：后门泥地、旧木窗、水巷里刚被使用过的船绳与灯具，建筑/环境尺度。
- 颜色规则：低饱和灰绿、木褐、米白蒸汽和潮湿反光；异常不使用高亮色、不使用规则轮廓。
