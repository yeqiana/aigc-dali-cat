## 一、完整故事闭环

2026年雨季封山前，墨脱一处山地监测点因滑坡暴露出未记录的石窟，附近设备也反复故障。曾经的第七科考队外勤调查员林澈从现场照片里认出，石壁上的纹路与父亲林远川死后留下的缺页《实测图补记》相同。林澈带着曾经的同事沈青岚，以及只负责维修设备的发小魏川进入现场。

洞窟内部没有想象中的阴冷，反而干燥、温暖、安静。遗蜕完整得像只是睡着，石壁上的青白经络纹缓慢呼吸。林澈开始怀疑羽化成仙是否真实存在。当地研究者次仁和向导达瓦提醒他们不要靠近遗蜕和三具小尸，也不要碰发光石壁。林澈为了取回监测标志、确认父亲来过的证据，主动触碰纹路。

温场让林澈的判断力下降，粉色的虚幻羽毛在洞中出现。羽毛后面站着一个模糊的人影，站姿像林澈父亲林远川。林澈因此不愿撤离，川儿和沈青岚将他强行带出。林澈带出一截发热的墨脱石片，设备调查任务完成，但他的手腕仍残留微光。

回到临时住处后，石片与父亲《实测图补记》上的断纹接上，指向山外一片像没有水的海。墨脱不是孤立异常，父亲死前调查的路线仍在继续。

**系列接力：** 石片来自当下的墨脱现场，图册来自父亲过去的调查；两者第一次咬合后，才引出下一处遗址。

## 二、异常母题

### 2.1 母题定义

`羽化温场 = 青白呼吸式经络光 + 不符合外界的温暖 + 浅粉色虚幻羽毛对记忆的诱导`

- 青白经络光：沿石壁、人体和石片表面流动，明暗像呼吸。
- 温暖：洞内干燥、安静、没有腐臭，让人警惕下降并产生留恋。
- 粉色羽毛：温场作用于林澈感知后的视觉表现，不能生成成翅膀、天使或独立生物。
- 父亲幻象：只在粉色羽毛后出现模糊身形，不露清晰脸，不确认是真实父亲。

### 2.2 三个载体与尺度

| 层级 | 载体 | 新增信息 |
|---|---|---|
| 局部 | 石壁上的青白经络纹 | 遗址不是普通刻痕，温度和光线有规律 |
| 人体/感知 | 林澈手腕、粉色羽毛和父亲模糊身影 | 温场会作用于人体和记忆，诱导人物主动靠近 |
| 物件/空间 | 发热石片、整座石窟和撤离路线 | 异常能被带出现场，遗址与父亲路线相连 |

### 图01｜峡谷尽头的暖光【封面/关键帧】

- **功能：** 先见异常，同时交代林澈曾经离开第七科考队。
- **画面：** 林澈第一人称举手机拍摄墨脱雨林和湿滑峡谷，远处低矮石窟入口透出不合环境的柔和暖光，外面雨雾冷绿，洞口内部干燥温暖；深蓝灰袖口和红色背包边缘入镜。
- **第一人称方式：** 手机持握视角，手指和袖口在左下角，镜头刚从车窗或山路转向石窟。
- **人物/道具：** 林澈手、旧背包、湿滑山路、石窟入口。
- **字幕：** `我曾是第七科考队的人。那次任务后，我离开了。`
- **字幕功能：** 身份背景，不解释旧事件。
- **母题载体/尺度：** 石窟洞口的暖光；地貌尺度。
- **因果：** 先给出异常地点，后续解释为什么林澈会再次进入类似现场。
- **提示词增量：** 墨脱雨林峡谷尽头的低矮石窟，洞口内部透出克制的暖白光，外部阴雨冷绿、湿叶和泥路，手机随手拍，画面边缘有男性深蓝灰袖口和旧红色背包，主体偏右，洞内光不夸张但明显比外界温暖。
- **负向提示词：** 电影海报，第三人称远景，HDR，体积光，金色圣光，仙侠洞府，科幻入口，文字水印，清晰正脸，夸张光效。
- **连续性风险：** 暖光必须来自洞内，不生成独立光源或现代灯具。

- **人物/道具：** 男性手、缺页野外图册、手机、损坏的监测设备零件。
- **字幕：** `父亲死后，只留下一本缺页地图。墨脱这一处，他标了三次。`
- **字幕功能：** 长期动机和本集地点接入。
- **母题载体/尺度：** 图册边角断纹；物件近景。
- **因果：** 林澈从照片中的石壁纹路认出父亲图册标记。
- **提示词增量：** 旧野外测绘册放在维修车内的金属台面，纸张破损、页角缺失、手写地形线和三次重复的断裂纹标记，旁边有手机中模糊的滑坡现场照片和拆开的监测设备，男性手按住纸页，暖灰车内光，非档案陈列。
- **负向提示词：** 官方档案室，红章，坐标纸，文件排版，清晰可读大段文字，电脑界面，电影感，整洁书桌，第三人称。

### 图03｜设备坏了，洞里却是暖的【关键帧】
