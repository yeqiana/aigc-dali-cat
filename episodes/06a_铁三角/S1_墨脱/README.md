## 本集定位

林澈、沈青岚和修理工魏川因一处滑坡暴露的监测点故障进入墨脱。林澈从现场照片中认出父亲林远川缺页地图上的同源标记，在石窟里看见温暖的羽化遗蜕，并在判断力下降后于粉色羽毛后看见了模糊的父亲身影。

## 本集闭环

- 现实任务：雨季封山前完成监测设备调查与临时修复。
- 异常事件：发现温暖的羽化洞窟，林澈主动靠近并被温场诱导。
- 人物结果：川儿和沈青岚把不愿撤离的林澈带出石窟。
- 跨集物证：林澈带出一截仍在发热的墨脱石片。
- 长期接力：父亲当年只见光、抄下断纹，没有带走石片；林澈带出的石片补上父亲地图没画完的断纹，指向山外下一处遗址。

## 视觉边界

- 青白经络光是遗址母题；浅粉色羽毛是温场对林澈感知的诱导层，不是独立怪物。
- 父亲只以模糊身形、旧外套、站姿或局部手势出现，不露清晰脸，不确认是真人。
- 父亲线当前闭环为“见光但不取物 → 抄下断纹 → 断纹未完成且人失踪 → 缺页地图被留下 → 林澈带石片补完断纹 → 指向山外”。
- 全篇第一人称手机随手拍，不出现第三人称电影式全知镜头。
