## 2. 神职与失守

`神职 = 嫦娥：维持月相、潮汐与地月间隔 + 正常时阻止“两地之间的孤绝被实体化”`  
`失守 = 月背裂谷出现冷白镜面反光带，镜中地球形状不对；地月通信延迟异常增大（正常约1.3秒，异常数秒）`  
`规则 = 不要看反光超过三秒，不要数自己的倒影`  
`变异 = 认知（把最亲的人感知为隔了几万公里的陌生人，孤绝感被指数放大）+ 身体（皮肤出现冷白反光薄层，声音动作延迟数秒）+ 环境（月面镜面扩张，地球影像在镜中远离）`
