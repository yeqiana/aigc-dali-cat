# 06A｜铁三角

> 系列归属：神话遗址
> 
> 故事主时间：2026年
> 
> 定位：林澈、魏川、沈青岚三人组的人物背景与长期主线设定，不是现役科考队分支。

## 一句话设定

三个曾经接触过不可解释事件的人，在2026年因为林澈父亲林远川留下的线索重新聚到一起：林澈和沈青岚曾是第七科考队成员，魏川只是修理工人，也是林澈从小一起长大的发小，因为林澈才进入这条调查线。

## 当前有效文档

## 目录用途

- `docs/`：系列背景、人物卡、关系规则与父亲长期线。
- `assets/characters/`：三人及林远川的角色参考图，后续锁定。
- `images/`：后续铁三角相关关键视觉或独立故事素材。
- `scripts/`：后续字幕、排版或辅助脚本。

## 关键边界

- 林澈、沈青岚是曾经的第七科考队成员，不是2026年的现役队员。
- 魏川不是科考队员，只是野外设备修理工和林澈发小。
- 三人不是固定官方组织，而是因旧事件和新线索临时组成的民间调查小组。
- 父亲线是跨篇长期暗线，不要求每一集都讲家庭情感。
- 每个地点故事仍需独立闭环，长期线通过地图、照片、设备和现场痕迹少量推进。
- S1 墨脱的发光石片是第一件跨集物证：它来自当下遗址，与父亲《实测图补记》在结尾咬合，用于引出墨脱之后的路线。
