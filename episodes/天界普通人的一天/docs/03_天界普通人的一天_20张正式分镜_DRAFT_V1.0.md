- 动作—回应—兑现链：04（扫帚压下）→ 05（局部熄灭）→ 14（最后选择）→ 15（最后亮点熄灭、试岗完成）。

## 资产锁

- P01：25 岁天界基层清扫员（男），普通黑色日常短发，朴素耐磨的米白灰蓝基层工作服，随身携带上岗记录牌；唯一主要人物与第一人称拍摄者。
- 人物现实处境：过去两个月为机动跟班；本集是第一次独立试岗；通过后获得固定“落星街早班”。
- 主场景：云海基层工作站、落星街石阶、早市区域、基层清运点、工作站排班板、白天天街维护点。
- 星砂：铺地时微亮，被扫拢/离地/装袋即熄灭；天亮后剩余部分自然熄灭；熄灭后作为普通灰白路面回填材料回收再利用。
- 禁止：星砂意识化、神谕化、许愿化、可保存发光物证、秘密机构、仙官英雄叙事、结尾新增异常。
