# 《神隐记录》系列规划方案 V1.4

> Story OS Adaptation Plan  
> 类型：伪纪录片 / 胶片影像叙事 / 东方幻想异常事件  
> 核心改编方向：将《千与千寻》的世界观转化为"如果这件事在1990年代日本真实发生，一段胶片拍摄的影像记录"。  
> V1.1：依据《千与千寻》（2001）电影剧情校准，修正与电影不一致的情节节点。  
> V1.2：新增人物 / 地点 / 物品设备设定，支撑分镜一致性与图像生成锚点。  
> V1.3：画风质感锁定 Visual Profile ID `SPIRITED_AWAY_LIVE_ACTION_V1`（1990年代日本真人奇幻电影 / 35mm胶片质感，替代原手机记录质感）。  
> V1.4：叙事装置年代化升级——手机相册 / 导航 / 身份证替换为1990年代胶片体系（纸质地图 / 学生证 / 胶片底片），与新画风自洽。

# 一、项目定位

## 系列名称

《神隐记录》

## 副标题

一个女孩搬家途中，进入了一座不存在地图上的小镇。

---

# 二、核心创作原则

## 不做

- 不做电影剧情复述；
- 不做角色介绍式解说；
- 不直接复制电影镜头；
- 不按照电影时间平均切割。

## 做

转换为：

> "一个普通人在现实世界中遭遇异常事件，并留下影像记录。"

核心体验：

- 胶片影像感；
- 第一视角记录；
- 普通人的真实反应；
- 异常逐步升级；
- 最后形成完整神隐事件。

# 四、世界观设定（人物 / 地点 / 物品设备）

> 全部沿用匿名化风格（不出现电影原名）；括号内为电影对应，仅创作者参考。  
> 描述兼顾"伪纪录片真实感"与"图像生成一致性锚点"，供分镜与提示词统一使用。

## 人物

**女孩（记录者）**
- 主角，约十岁，1990年代日本中学生模样；
- 普通人的真实反应：先害怕、再记录、最后选择面对；
- 全程以胶片影像为叙事视角，她是唯一"看见真相"的人。
（参考：千寻）

**父母**
- 中年夫妻，搬家途中误入小镇；
- 在无人餐馆贪吃停不下来，变成猪，后被关进猪圈；
- 走出神隐后，什么都不记得。
（参考：千寻的父母）

**少年**
- 神秘少年，与小镇格格不入；
- 给药丸救女孩、提醒她不能忘记名字；
- 真实身份是女孩童年落水的那条河。
（参考：白龙 / 琥珀川）

**管理者（浴场女主人）**
- 浴场的实际控制者，气场强大、喜怒无常；
- 靠"签约收走名字"控制所有员工；
- EP06 最终考验（猪群认亲）的提出者。
（参考：汤婆婆）

**黑影（无脸人）**
- 没有脸的黑色身影，孤独、渴望被接纳；
- 被欲望喂大后暴走吞噬一切，被药丸治愈后回归安静；
- 最后留在婆婆身边，没有跟女孩回去。
（参考：无脸男）

**婆婆**
- 住在水边小屋的老人，宽容、慈祥；
- 收下归还的印章、原谅少年；
- 与大家为女孩编了一根发绳。
（参考：钱婆婆）

**被变成老鼠的婴儿**
- 管理者的孩子，被纸人变成老鼠；
- 以老鼠形态随女孩同行全程，是旅途中的"意外同伴"。
（参考：坊）

**浑身恶臭的客人（河神）**
- 被垃圾污染的河神，浑身污泥与垃圾；
- 女孩独自为他洗净，他留下药丸后离开；
- 出场即视觉奇观：满池污水与拖出的成堆垃圾。
（参考：腐烂神 / 河神）

**浴场员工（群像）**
- 形形色色的怪异生物员工，白天勤恳、夜晚围观混乱；
- 功能：提供"普通世界被异化"的背景感，与女孩形成对照。
（参考：油屋众员工）

---

## 地点

**废弃隧道**
- 现实与神隐的边界：现实一侧是荒废山路，另一端是陌生街区；
- 入夜后返回的路被河水隔断，洞口不再出现；
- 结尾女孩与父母从这里走回现实。
（参考：石砌隧道）

**不存在的小镇（美食街）**
- 白天空无一人、店铺摆满热腾腾的食物；
- 入夜后灯火亮起、众神现身，小镇"活"过来；
- 父母在此变成猪，是异常的第一现场。
（参考：美食街 / 众神之街）

**浴场（巨大建筑群）**
- 河对岸的巨型浴场，夜晚灯火通明；
- 核心场景：员工区、走廊、大浴池、长廊；
- 女孩工作、黑影暴走、少年受伤，一切混乱都发生在这里。
（参考：油屋）

**猪圈**
- 父母与其他猪被关押的地方；
- 女孩在栅栏外呼喊，得不到任何回应；
- 也是 EP06 最终考验（猪群认亲）的现场。
（参考：豚小屋）

**水上列车**
- 开在水面铁轨上的列车，黄昏发车；
- 空旷、安静，乘客只有女孩一行；
- 画面锚点：水面倒影、荒废车站、孤独旅行感。
（参考：海原电车）

**婆婆的住处（水边小屋）**
- 列车终点，临水小屋；
- 归还印章、获赠发绳的地方；
- 黑影最终留在这里。
（参考：钱婆婆之家）

**隧道口（回家之路）**
- 结尾：父母、女孩从这里走回现实；
- 少年在此目送，叮嘱"不要回头"；
- 画面锚点：阳光、草丛、隧道的黑暗出口。

---

## 物品设备

**35mm胶片影像（核心记录载体）**
- 全片以35mm胶片质感呈现：真实摄影机曝光、胶片颗粒、低饱和、夏季潮湿空气；
- 异常在影像上留下痕迹：纸质地图上出现未知道路、学生证上的名字模糊、最后一卷胶片末尾的底片空白；
- 伪纪录片"证据感"的核心载体。

**药丸**
- 恶臭客人留下的药丸；
- 一半喂给黑影使其吐出吞噬之物，一半救回受伤的少年；
- 全片最关键的道具，串起 EP03-EP04。
（参考：河神丸子）

**名字卡片**
- 写着女孩真名的卡片，少年偷偷归还；
- "不能忘记名字"主题的实体化。
（参考：写有"千寻"的名字卡片）

**契约**
- 与管理者签订的雇佣契约，签字即交出名字；
- 最终考验通过后作废。
（参考：油屋雇佣契约）

**印章**
- 少年盗取之物，被纸人诅咒的起因；
- 归还后一切平息，是 EP04-EP05 的推动物。
（参考：钱婆婆的印章）

**金子**
- 黑影用来诱惑浴场员工的金子；
- 女孩拒绝，成为"不被欲望吞掉"的关键选择。
（参考：无脸男的金子）

**纸人**
- 诅咒少年、把婴儿变成老鼠的符纸；
- 画面锚点：白色纸人如蛇般飞行、缠绕。
（参考：钱婆婆的式神）

**黑色虫子**
- 少年吐出、控制他的诅咒实体；
- 暗示管理者对少年从未放手。
（参考：汤婆婆控制白龙的虫蛊）

**发绳**
- 婆婆与大家一起编的护身符；
- 结尾在女孩发间闪光，证明神隐世界真实存在过。
（参考：千寻的发绳）
