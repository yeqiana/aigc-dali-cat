# EP03《雾中的另一座生活区》会话修订说明 V1.1

> 状态：STORY_LOCK_CANDIDATE / 待独立 Story Critic
> 适用基线：Story OS V2.0.3.5 + Series Refinement Patch

## 本集认知目标

**他们有完整的社会和生活。**

核心不是再次证明“那里有人”，而是证明那里存在长期、稳定、普通的社会秩序。

## 特殊条件与系列规则兑现

EP003 的清晨航拍不新增第二套异常规则，而是第一次明确证明：**两个社会的短暂重合并不依赖夜晚。**

前一晚山区持续降雨，接近天亮时雨势停止，气温下降，大量低云和湿雾仍滞留在山谷。男女主原本就计划早起上山看日出、拍云海，男主因此放飞随车携带的消费级无人机。

无人机穿过低云后，才进入此前被云层与现实山谷共同遮蔽的另一侧可见区域。

这里的因果关系必须保持为：

`普通旅行计划 → 雨后清晨 → 低云未散 → 无人机正常航拍 → 偶然穿过短暂重合范围`

不得表现为：
- 男主根据前两次经历推算出异常出现时间；
- 两人专门等待天气变化寻找入口；
- 日出、无人机或某种灯光主动开启通道；
- “云海”本身具有超自然功能；
- 只要复制相同天气条件就一定能够再次找到对方。

EP003 的意义在于把观众此前可能形成的“夜晚怪事”认知进一步修正为：真正反复出现的，是少数山区在雨后降温、低云压谷时形成的短暂重合窗口；黑夜、雨幕、玻璃雾气和清晨云海，只是不同一次接触所处的自然环境。

同时，本集仍不得解释这种现象为何发生。男女主最多只能意识到：**“前几次，好像也都是这种天气。”** 不能继续推导成完整理论。

## ordinary life density 与古文明展示锁

允许 EP003 成为全季**视觉规模峰值**，但展示对象必须是“仍在正常运转的前工业文明”，而不是遗迹旅游或仙宫奇观。

尺度展开顺序应保持：

普通家庭与生活动作
→ 农田 / 牲畜 / 运输
→ 市场交换 / 作坊
→ 水渠 / 石桥 / 固定道路
→ 大型石质公共工程
→ 成片城区与完整山谷文明

大型结构可以成为强视觉冲击，但必须满足：
- 仍在被人使用；
- 画面内保留人物、牲畜、运输、生产等现实尺度参照；
- 每一张展示都新增社会信息，禁止只换景别消费古城；
- 不得对应现实中国具体朝代，不出现可辨识唐宋明清服饰、宫殿、牌坊、中文匾额或长安式城市复刻；
- “古老感”服务于证明社会历史深度，不负责解释世界来源。

本集真正的认知升级仍然是：**那里不是几个异常人物，而是一个长期存在、正常生活的完整社会。**

## 终局亮区降调

缓存最后画面中，只允许在聚落远处一块不属于对面生活秩序的亮区里，看见一个极小、四方、**像车辆但无法确认**的白色轮廓。不得辨认出男女主停车位置，更不得看清车旁两个人。

不得做成：
- SUV 大特写；
- 传送门式构图；
- 世界重叠特效；
- 硬反转说明。

目标是让观众看一两秒才意识到：
**他们的世界里，也能从某个方向看到我们。**
