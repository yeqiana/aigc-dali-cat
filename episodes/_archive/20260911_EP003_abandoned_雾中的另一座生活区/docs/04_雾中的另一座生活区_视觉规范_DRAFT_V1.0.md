# 《雾中的另一座生活区》视觉规范 DRAFT V1.0

## 1. Profile

M-ROAD-2020｜2020s 川西自驾手机相册纪实

## 2. 本集主视觉

- 类型：普通情侣自驾旅行中的意外记录 / 非调查
- 核心问题：那边到底是不是一个完整社会？
- 核心异常：男女主在正常川西自驾途中遇到雨停窗口，男主只是顺手用车里原本用于拍风景的普通消费级无人机补拍山谷，却第一次看见一个完整生活中的社会；因多停留几秒，无人机从观察升级为设备越界并失联。

## 3. 本集专项硬要求

雨停后再飞无人机；无人机存在理由只允许是普通旅行拍风景；每个聚落景观必须承担一个社会推论；聚落不能仙侠化。Frame01 必须是 P01/P02 自拍或清晰正脸身份建立帧，强制沿用 EP001 已批准系列脸锚。Frame17–19 的亮区只能表现真实曝光/空间差异，禁止传送门、裂缝、能量边界。

## 4. 通用

- reality first
- ordinary life density
- available light
