## 1. V2 问题结论

旧选题池把“仪器输出 → 日志 → 档案 → 记录不可信”当成系列辨识度，导致不同地点共享同一个故事：摩尔斯、GPS、地磁、测年、邮件和学号只是在更换屏幕内容。

V3 改为：

`普通人的野外任务 → 关系人物带路 → 肉眼直见异常 → 一个与现场有关的规则 → 因现实/情感目标触发 → 异常直接改变人物与环境 → 任务及关系闭合 → 同源余波`

科考不是神秘机构，也不是解释异常的权威。它只提供人物为什么会进入冰川、退水旧镇、盐湖、溶洞或深海的可信理由。

## 2. 系列治理

### 2.1 人物

- 不再强制每篇出现固定六人组。
- 林澈可作为第一人称主角复用，但每篇只保留1名主要关系人物和0至1名功能性队友。
- 已有科考队合影与户外出发图继续用于林澈和常规队友锁定；父亲、导师、向导等新关系人物必须先补参考图。
- 关系人物必须承担隐瞒、亏欠、选择或告别，不能只负责讲知识。

### 2.2 科技

每篇最多使用一组主要技术，只能承担以下一种功能：

1. 帮助人物抵达正常人到不了的位置；
2. 在肉眼异常出现后确认异常范围；
3. 在行动中提供照明、绳索、定位或撤离帮助。

禁止连续两张展示仪器界面；日志、邮件、名单和旧档案原则上不承担主要推进。

### 2.3 节奏模式

- **鼠鼠模式：** 现实任务、关系、规则触发和现场对抗为主。
- **Zayn模式：** 单一异常母题跨载体复现并扩大到环境为主。
- **混合模式：** 只有同时具备强人物关系和清晰母题扩散时使用，两套标签都必须完整。

### 选择结论

1. 第一张就能同时出现退水旧镇和成排泥人，不依赖屏幕解释。

## 5. 淘汰规则

以下任一情况不得进入分镜：

- 前3张只能看到屏幕、报告、日志或队员表情。
- 删除地点名后，故事可原样替换到任何山、湖、洞穴或森林。
- 关系人物没有隐瞒与选择，只负责提供专业知识。
- 规则与异常母题无关，主角因为好奇故意触发。
- 中段连续展示三个以上证据，却没有人物动作或环境变化。
- 结尾没有完成野外任务和关系结果，只留下“记录不可信”。
- 再次使用哀牢山、红外相机、蹲着的人、未来时间戳或1985年档案。
