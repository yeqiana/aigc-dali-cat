## 双年龄一致性

1. 年轻复制体不是父亲的儿子、陌生青年或偶像化版本，必须能从眉骨、鼻形、耳形和长方脸认出是同一人。
2. 图11、13、17需要同时注入两张父亲参考图；现实父亲保持正常皮肤，年轻复制体保持湿泥皮肤。
3. 图20只注入年轻复制体参考图，但铁盒、蓝劳动服、泥肤和藻丝不得改变。
4. 泥化非血腥：禁止腐肉、伤口、眼球异常、断裂肢体、僵尸表情和雕像底座。
