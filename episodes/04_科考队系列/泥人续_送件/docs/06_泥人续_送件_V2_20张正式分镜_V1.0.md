## 一、正式锁定的因果链

`铁盒生成活人物品复制件 → 复制件带现实地址 → 复制件跨过该地址门槛 → 该住址成为泥人锚点 → 每完成一次投递，林澈家门口的年轻泥塑父亲向内靠近一道门槛 → 回收复制件只能让未完成泥人塌解 → 父亲锁箱沉水停止新扩散 → 已完成的泥塑林澈保留`

本篇不把复制件写成亡者遗物，也不把异常原因解释完。原件与复制件至少两次同框；复制物、住址和对应收件人泥人必须由画面直接证明，不依赖字幕单独解释。

## 二、角色、道具与动态锁

### 2.1 林澈

- 26岁水文研究生，黑色长发低马尾。
- 深蓝灰防水户外夹克、深色工装裤、黑色防水徒步鞋、旧红色双肩包。
- 第一人称只露无美甲无首饰的手、袖口、鞋、背包边缘或模糊倒影，不出现清晰正脸。
- 动态原则：每张至少有一个“正在”动作（开门、抽取、递送、回收、锁闭、后退等），镜头允许偏斜、遮挡或轻微运动模糊。

### 2.2 林国强与年轻泥塑父亲

- 林国强：58岁、存活；棕灰旧帆布夹克、深灰针织衫、褪色黑裤、黑色橡胶鞋；只在图13、18通过现实人物与物证出现。
- 年轻泥塑父亲：约28岁，沿用K1可辨认长方脸、眉骨、鼻形和耳形；1980年代褪色蓝劳动布外套；湿灰褐淤泥、白色钙化裂边、少量暗绿藻丝。
- 年轻泥塑父亲不行走、不攻击、不睁发光眼；用跨图站位变化表现靠近：门外/走廊 → 门槛 → 门内。

### 2.3 阿岚与第二收件人

- 阿岚：约25岁，短发，浅灰羽绒服、深色牛仔裤、旧帆布单肩包；只负责首位收件人和规则证据，不讲完整规则。
- 第二收件人：约65岁男性，深棕针织帽、褪色棕色棉马甲、灰黑长袖；其泥人复制针织帽、棕马甲和体态，不使用父亲蓝外套。

### 2.4 核心道具

- 锈红花纹铁皮照片盒：K1同一铁盒，边角磨损、局部水痕；图01闭合抱出，图03打开，图17重新装回，图18锁闭，图19沉水。
- 复制黄铜钥匙：原件干燥，复制件齿槽带湿泥、白钙线和藻丝；后期地址文字全部叠字。
- 复制蓝边搪瓷杯：原件与复制件缺口、蓝边、划痕完全对应；复制件内壁湿泥明显。
- 复制红背包部件：图16与林澈仍持有的原件同框；图20升级为完整泥塑林澈与复制背包。
- 亡妻姓名包裹：图17才出现，姓名由后期叠字，不依赖模型生成文字。

## 四、逐图正式分镜

### 图01｜异常进城【四图母版已通过】

- **功能：** 标题异常落地；把K1的铁盒和年轻泥塑父亲接入普通城市空间。
- **画面：** 林澈在屋内拉开金属防盗门，门外年轻泥塑父亲坐着抱锈红铁盒；铁盒闭合但边角滴水，地面只有一小片新鲜湿泥。
- **第一人称方法：** 前景为林澈握门把的手、深蓝灰袖口和门板遮挡；不出现主角脸。
- **角色/道具：** 年轻泥塑父亲、锈红铁盒、城市公寓门口。
- **字幕：** `泥人抱着铁盒跟回城后，我一直没敢开门。`
- **字幕功能：** 续篇承接 + 抛出异常；不解释规则。
- **母题/尺度：** 人形泥塑 + 铁盒 / 城市门口单点。
- **因果链接：** K1结尾的泥塑父亲与铁盒不再是旧镇远景，而进入林澈家门口。
- **必须看清：** 城市干燥走廊、泥塑父亲蓝劳动布外套、锈红铁盒、局部湿泥同时成立。
- **连续性风险：** 不能变成无脸通用泥人、真人满脸泥或站立攻击姿势。

### 图02｜铁盒生成旧钥匙

- **功能：** 把异常从“跟回来的东西”推进到“铁盒正在生成复制物”。
- **画面：** 林澈双手打开铁盒，盒内出现一把旧黄铜钥匙和一张留白地址纸条；钥匙看似普通，齿槽有湿泥痕。
- **第一人称方法：** 低头俯拍，手扶盒盖和捏住钥匙；地址纸条留干净区域供后期叠字。
- **角色/道具：** 林澈双手、铁盒、复制钥匙、地址纸条。
- **字幕：** `盒子里多了一把钥匙，下面压着一个地址。`
- **字幕功能：** 给出第一件物证与现实投递目标。
- **母题/尺度：** 复制钥匙 + 湿泥 / 手持物尺度。
- **因果链接：** 图01铁盒进入城市；图02确认盒内出现新物。
- **必须看清：** 黄铜材质、湿泥齿槽、无乱码纸条。
- **连续性风险：** 钥匙不能变成现代银色防盗钥匙，铁盒不能塞满杂物。

### 图03｜泥人逼近门槛【四图母版已通过】

- **功能：** 第一次直接同时呈现复制物材质和泥人距离变化。
- **画面：** 林澈正在把钥匙从打开的铁盒中提起，钥匙带出一缕湿泥；背景的年轻泥塑父亲已经从走廊坐到金属门槛前。
- **第一人称方法：** 双手、门槛和盒子形成前中后景；镜头略倾斜，保留抓拍感。
- **角色/道具：** 林澈双手、复制钥匙、铁盒、年轻泥塑父亲。
- **字幕：** `我低头看了几秒，再抬头时，它已经靠近了一道门槛。`
- **字幕功能：** 让观众注意位置递进，但不替画面解释复制规律。
- **母题/尺度：** 湿泥复制物 + 站位靠近 / 门槛尺度。
- **因果链接：** 铁盒出现复制钥匙后，年轻泥塑父亲位置变化。
- **必须看清：** 钥匙齿槽湿泥、空白地址纸条、泥塑父亲比图01更近。
- **连续性风险：** 泥塑父亲仍不行走、不站立，不可出现多个泥人。

### 图04｜按地址找阿岚

- **功能：** 关系人物进入，主角把复制钥匙送到地址。
- **画面：** 老居民楼室内，阿岚刚打开门，林澈的手把复制钥匙递向她；桌上有纸条留白和林澈手机。
- **第一人称方法：** 镜头站在门外，前景只露递物的手和袖口；阿岚半侧身，不正面摆拍。
- **角色/道具：** 阿岚、复制钥匙、手机、帆布包、门框。
- **字幕：** `纸条上的地址，是阿岚住的那栋旧楼。`
- **字幕功能：** 交代投递目标与关系入口。
- **母题/尺度：** 复制钥匙 / 第一个外部地址。
- **因果链接：** 图02地址指向阿岚；图04执行第一次送件。
- **必须看清：** 林澈主动递送，阿岚在真实居住环境中接物。
- **连续性风险：** 阿岚需保持短发、浅灰羽绒服和旧帆布包。

### 图05｜阿岚拿出原件

- **功能：** 推翻“铁盒归还遗失物”的普通解释。
- **画面：** 阿岚从自己仍在使用的钥匙圈上取下一把干燥旧黄铜钥匙，与林澈带来的湿泥复制钥匙放在桌边；她正低头比对，不看镜头。
- **第一人称方法：** 桌边近距离抓拍，林澈手停在复制钥匙旁，阿岚动作进行中。
- **角色/道具：** 阿岚、原钥匙、复制钥匙、钥匙圈、林澈的手。
- **字幕：** `她说，这把钥匙她一直在用，根本没有丢过。`
- **字幕功能：** 直接给出原件仍存在的证据。
- **母题/尺度：** 原件与复制件 / 双物件尺度。
- **因果链接：** 图04送件；图05收件人拿出原件。
- **必须看清：** 原钥匙干燥、复制钥匙湿泥，人物正在比对而非举证摆拍。
- **连续性风险：** 两把钥匙形状要高度接近，不能出现一串杂乱钥匙遮挡证据。

### 图06｜两把完全相同的钥匙【战略性无字幕候选】

- **功能：** 画面独立完成第一次规则证明：铁盒生成复制件，原件仍在现实中。
- **画面：** 阿岚一手拿干燥原钥匙，一手拿湿泥复制钥匙，两把钥匙在桌面上交叉对照；三角磨损、钥匙齿槽和划痕对应，复制件带白钙线与藻丝。
- **第一人称方法：** 林澈手机从桌面斜上方抓拍，阿岚正在把两把钥匙靠近比较；不使用居中产品照。
- **角色/道具：** 阿岚双手、原钥匙、复制钥匙、林澈袖口。
- **字幕：** **无字幕。**
- **字幕功能：** 让物证自己说话，作为混合模式的静音推论点。
- **母题/尺度：** 湿泥复制物 / 双物件近景。
- **因果链接：** 图05原件出现；图06完成逐项视觉比对。
- **必须看清：** 两把钥匙外形、磨损位置、干湿差异和复制材质。
- **连续性风险：** 不得用字幕补充“复制”，不允许两把钥匙仅仅是相似款。

### 图07｜复制钥匙跨过门槛

- **功能：** 触发跨门槛规则，第一次出现与收件人服装对应的泥人。
- **画面：** 林澈的手把湿泥复制钥匙放进阿岚家门内的玄关托盘；门外半暗处刚出现一具复制阿岚浅灰羽绒服轮廓的泥人，短发和站姿可辨。
- **第一人称方法：** 低机位贴近门槛，手、钥匙和门内泥人同框；阿岚身体被门框部分遮挡。
- **角色/道具：** 林澈的手、复制钥匙、阿岚、阿岚泥人、门槛。
- **字幕：** `钥匙一过门槛，门外就多了一个穿她衣服的泥人。`
- **字幕功能：** 规则首次明确可读，画面提供服装对应证据。
- **母题/尺度：** 复制钥匙跨门槛 + 对应泥人 / 住址尺度。
- **因果链接：** 图06确定复制；图07将复制件送入阿岚地址。
- **必须看清：** 钥匙正在跨门槛、泥人服装对应阿岚，不穿父亲蓝外套。
- **连续性风险：** 泥人不能与阿岚真人混成双胞胎，也不能出现攻击动作。

### 图08｜铁盒自动生成第二件

- **功能：** 规则可重复，城市扩散从单件物品进入第二载体。
- **画面：** 林澈回到公寓，铁盒在桌上自行打开，里面出现一只缺角蓝边搪瓷杯和新的留白地址纸条；盒盖仍在轻微回弹。
- **第一人称方法：** 镜头刚被林澈放到桌边，手正在伸向自动打开的盒盖；画面不对称、有轻微运动模糊。
- **角色/道具：** 铁盒、复制搪瓷杯、地址纸条、林澈手。
- **字幕：** `我还没回过神，盒子里又出现了一只缺角的杯子。`
- **字幕功能：** 推进第二次投递，不重复解释第一把钥匙。
- **母题/尺度：** 复制搪瓷杯 / 新载体。
- **因果链接：** 图07钥匙跨门槛成功；图08铁盒继续生成新物。
- **必须看清：** 杯子缺口、蓝边、湿泥内壁和地址留白。
- **连续性风险：** 不出现可读AI文字；杯子不能变成现代玻璃杯或满盒杂物。

### 图09｜把复制杯送到第二住址

- **功能：** 主角主动验证并再次越界，人物从观察者变成行动者。
- **画面：** 林澈在旧镇幸存者家门口，正把湿泥复制杯递给约65岁老人；老人伸手接杯，身后门内保持暗部。
- **第一人称方法：** 递杯的手占前景，老人身体被门框切边，轻微手抖；不拍成合影。
- **角色/道具：** 林澈手、复制杯、第二收件人、老居民楼门槛。
- **字幕：** `我想确认一次，把第二件也送到了纸条上的地址。`
- **字幕功能：** 说明主角的主动验证动机。
- **母题/尺度：** 复制搪瓷杯跨地址 / 第二住址。
- **因果链接：** 图08出现新地址；图09主角执行第二次送件。
- **必须看清：** 杯子正跨过门槛、收件人正在接，不是桌面静物。
- **连续性风险：** 收件人服装必须为棕马甲/针织帽，与父亲泥人区分。

### 图10｜原杯与复制杯同框【四图母版已通过；战略性无字幕候选】

- **功能：** 第二次规则证明；原件、复制件和对应人物泥人同时出现。
- **画面：** 老人正在从桌边抓起自己原来的干燥杯，与刚收到的湿泥复制杯做即时比对；两只杯缺口、双蓝边、划痕完全一致；老人身后半开的门内，穿棕马甲、戴棕针织帽的泥人刚跨出半步。
- **第一人称方法：** 林澈手正在接/指复制杯，镜头偏斜；老人低头比较，不看镜头，背景泥人有轻微运动模糊。
- **角色/道具：** 第二收件人、原杯、复制杯、对应泥人、林澈手。
- **字幕：** **无字幕。**
- **字幕功能：** 静音即可推出“原件仍在、复制件带泥、住址出现对应泥人”。
- **母题/尺度：** 搪瓷杯复制 + 收件人泥塑 / 人物与房间尺度。
- **因果链接：** 图09复制杯跨门槛；图10展示结果。
- **必须看清：** 两杯可逐项对照，泥人服装与老人对应，不能穿蓝劳动布外套。
