## 1. 一句话故事

我们进入卡拉先格尔完成老地震断裂带闭合测绘，却发现裂缝下面不是地层，而是一片方向相反、不会坠落、始终向外延伸的第二地面；为了完成最后一个测点，我主动打入测量钉，第二地面开始在岩芯、营地和车辆接触面中显形。

## 2. 现实进入与情绪锚点

- 主角：林澈，地震地质测绘员，第一人称。
- 现实任务：在撤站前完成一条旧地震断裂带的闭合测量，封存一组岩芯和原始测量记录。
- 情绪锚点：林澈刚因一次“为赶项目删掉异常原始点”的争议被调离原项目，这次必须把所有异常如实记录，哪怕结果让项目无法按时结题。
- 关系人物：程野，同龄搭档，负责地球物理测量；他想赶在天气恶化前提交合格数据，曾隐瞒上一轮测量中一段无法解释的横向回波。
- 关系闭环：程野最终不再删掉异常点，主动把原始数据和未解释的岩芯一起封存上报；不是被救，也不是认错式亲情和解。

## 3. 核心异常母题

### 3.1 母题定义

`反向地表 = 平整灰白土面 + 黑色细沙/褪色根系 + 进入物体被横向接住并留下朝外痕迹`

它不是入口，不是地下房间，不是平行世界，不是实体。读者只能确认：裂缝和接触面下存在一层不服从重力方向的“地面”，它会回应人的测量与移动。

### 3.2 三种载体与三级尺度

| 层级 | 载体 | 新增推论 |
|---|---|---|
| 小尺度 | 断裂缝底、测量绳、红色测量钉 | 物体不下坠，先被另一层地面横向接住 |
| 中尺度 | 岩芯、岩芯盒、帐篷脚、车辆底盘 | 反向地表不是裂缝视觉错觉，会沿接触面复现 |
| 大尺度 | 营地、断裂带两侧、封存岩芯 | 它会记录并延伸现实行动，终局痕迹方向朝向外部 |

### 3.3 规则

1. 进入裂缝的物体不会落到底部，而会横向贴住另一层地面。
2. 任何接触过反向地表的物体，回到现实后都可能出现水平土层或朝外痕迹。
3. 不能通过重复投掷物体“测试深度”；每一次测试都会扩大它在现实接触面上的显形。
4. 规则不是口头禁忌，而是程野从异常原始数据中归纳出的职业安全判断；林澈为完成任务主动违反第3条。

## 8. 结构风险与门禁

- 风险：裂缝容易被生成成普通深坑。对策：必须在关键帧中露出“平整第二地面 + 根系朝镜头 + 水平土层”，禁止只写深度。
- 风险：根系容易变成触手。对策：根系干燥、细、植物性，不缠绕人物，不主动攻击。
- 风险：空间异常容易被解释完。对策：字幕只写行动和看见的物理后果，不写平行世界、维度、地球背面。
- 风险：人物重新退回救援模板。对策：程野不掉落、不被拉回；高潮是数据是否如实提交与林澈是否主动触发规则。
- 风险：终局像“异常跟回家”。对策：只留封存岩芯内部痕迹，地点已经闭合，现实余波只改变证据含义。
