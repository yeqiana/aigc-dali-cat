- 核心形态：裂缝或接触面下方出现一层平整、连续、方向不明的灰白土面。

- 运动/规则：进入裂缝的物体不向下坠，而会被“另一片地面”横向接住；其上会出现与现实行动相关、但方向朝外的痕迹。
