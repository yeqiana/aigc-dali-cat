## 1. 一句话故事

幸存者林澈随「第二支科考队」回冰川撤站，实则是来还命：一年前他活着离开，是挚友季航把自己寄存进冰川、替他还了命。林澈主动碰冰赎回季航，却在冰层里看见第七个人影——是他自己。

## 2. 故事闭环

- 任务闭环：监测设备拆除（表面），真实任务「还命」完成。
- 关系闭环：林澈还清欠季航的命，季航的影子得以离开。
- 反转留白：林澈把命还回去，自己成了冰里「第七个影子」；所谓「第二支科考队」，本就是来顶替第一支的替身。

## 3. 角色 / 关系 / 母题 / 规则 / 结局

### 3.1 主角 林澈（第一人称，本人越界）

- 26岁，科考方向，黑色长发低马尾；深蓝灰冲锋衣、红色背包。
- 全篇只露手、袖口、鞋，不出现正面清晰脸。
- 关键转变：从「来撤站的队员」→「来还命的幸存者」→「早就是被寄存的人」。

### 3.2 关系人物 季航（同龄挚友，非长辈）

- 与林澈同龄，一年前为拉林澈一把、把自己留在了冰川里。
- 冰层里以「保持着拉人姿势的影子」出现，只对林澈有反应。
- 区别于旧公式：不是长辈、没有「隐瞒/自责」的心结，而是「单向托付」。

### 3.3 异常母题（换逻辑：寄存 / 还债，非复制）

- 核心形态 = 半透明冰体 + 冻结的私人物品 + 本人临死前的姿势。
- 规律 = 冰川把「没还完的东西」冻起来；寄存者本人触碰才会醒，醒来就结账。
- 三个载体：单个影子、六具整队影子、林澈自己新冻进去的影子。
- 三级尺度：掌心结霜、整面冰壁影子齐醒、第七个影子入冰。

### 3.4 规则（反转：不是「禁止碰」，是「碰了才醒」）

- 旧公式规则是「不能碰」；本版规则是「碰了才会醒，醒了就结账」。
- 主角的越界是**有意识的主动选择**，不是误触。

### 3.5 结局（反转：代价偿还，非跟回家）

- 林澈赎回季航后，发现自己怀里掉出的是自己的工牌——他一年前就死了。
- 最后一图：冰层里新冻进第七个人影，是林澈自己。
