## V3 最高优先级

1. 前3张直接看见生态、地形、身体或空间异常，不能先看仪器和档案。
2. 每篇先有普通人的现实任务和关系人物，再有科考身份。
3. 科技只负责抵达、确认范围或辅助行动，每篇最多一组主要技术。
4. 单篇必须完成任务和人物关系闭环，异常原因可以留白。
5. 默认20张，最多25张；每3至4张必须发生一次可见变化。
