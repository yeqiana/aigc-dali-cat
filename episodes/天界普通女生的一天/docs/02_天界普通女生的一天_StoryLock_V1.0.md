# 天界普通女生的一天 — Story Lock V1.0

## 核心定位

这是纯生活日常，不做恐怖、悬疑、调查、探秘或异常解释。主角 P01 是 24 岁的普通天界女生，长相好看但真实自然；P02（女）、P03（男）、P04（男）是她相识多年的普通好友。故事重点不是职业或任务，而是一个普通女生和朋友从早到晚怎样生活。

整体视觉以东方古风天界为主，现代元素不超过 10%。唯一明显承担“现代相册功能”的物件是 P01 的随身留影玉牌；建筑、衣着、食物、交通、消费与公共生活都保持朴素东方天界质感。画面必须偏写实、真实照片感，避免插画、仙侠海报、影楼摆拍、瓷白皮与过度梦幻。

## 一句话故事

一个好看但真实自然的天界普通女生，从清晨自拍开始，和男女好友一起吃早饭、走云桥、做一点普通轮值、吃午饭、逛旧云市、坐茶摊、看傍晚云海，再在街口道别回家，用 20 张随手照片记录完平凡的一天。

## 人物

- P01：24 岁，女，第一人称记录者。自然黑色中长发，米白浅青朴素衣裙，性格轻松，不承担英雄、调查或神秘角色。
- P02：24 岁，女，P01 的老朋友。齐肩半束发，喜欢逛小摊和挑发簪，和 P01 的互动最自然熟悉。
- P03：25 岁，男，清瘦自然，爱开轻松玩笑，通常会顺手帮朋友拿东西。
- P04：23 岁，男，略爱睡懒觉，常常迟到一点，但和三人关系很熟。

四人不是情侣团建，也不是职业小队；他们只是普通朋友。

## 当天线路

清晨住处云廊 → 居民区石阶 → 早餐摊 → 云桥 → 普通公共轮值房 → 家常食肆 → 旧云市 → 茶摊 → 西侧云桥 → 晚间街口 → P01 住处。

## 故事推进

1. **01–04 建立人和关系**：第一张就是 P01 自拍，P02 靠近帮她整理碎发，P03 端着早餐探头入镜；下楼吃早饭后 P04 迟到赶来，四人组完整。
2. **05–07 普通半日生活**：四人走云桥，P01 去做短暂普通轮值，朋友在窗外等她收工。工作只是生活的一小部分。
3. **08–10 午饭与临时改路线**：四人吃家常午饭，原本准备散开，P02 临时提议去旧云市逛发簪摊，后半天因此自然延长。
4. **11–15 旧云市与茶摊**：看普通小铺、试木簪、买点心、互相开玩笑，最后坐进茶摊聊一些不重要的小事。
5. **16–18 傍晚云桥**：看到西桥被夕光照亮，临时又走过去坐一会；最大场景是云海，但人物只是在看傍晚、分最后一包点心。
6. **19–20 回家**：街灯亮起，朋友在路口分开。P01 回到云廊，拍鞋边、空纸包、今天买的小木簪和最后一点晚霞，收起玉牌。

## 生活感原则

- 每张照片都必须像当天真实拍到的生活记录，不像剧情剧照。
- 朋友不是每张都对镜头互动；有些帧只是同处一地、走路、吃饭或做自己的事。
- 天界奇观只作为普通生活背景：云桥、云海、空中水渠、层叠街区都可以很大，但居民行为必须普通。
- 不出现神殿宣传片式宏大构图，不出现英雄姿态、法术展示、怪物、阴森、惊吓或“发现秘密”。
- 第一张必须自拍，并且能看清 P01 的自然真实脸和生活衣着。

## 人物利害与结尾

这集没有危机型利害。P01 真正想留住的是“今天和朋友一起闲晃了一整天”的普通快乐。Frame 10 临时改变后半日路线，是结构中点；Frame 17–18 的傍晚云桥和分点心是视觉与情感峰值；Frame 20 用一天留下的小物件收尾，把宏大的天界重新缩回一个普通女生的生活。

## 禁止项

- 禁止恐怖、惊悚、诡异、怪谈、异常调查。
- 禁止调查员、研究员、侦探、神职英雄、拯救任务。
- 禁止用现代城市、手机 UI、汽车、霓虹招牌等大面积现代元素。
- 禁止过度仙侠妆造、华丽仙袍、漂浮特效堆满画面。
- 禁止把好友关系拍成连续商业合照或情侣写真。
- 禁止复刻真实明星或网红面孔。

## NO-ANOMALY TEST

即使完全没有任何异常或神秘机制，这 20 张仍然是一篇完整的生活相册：起床、自拍、早餐、朋友会合、短暂轮值、午饭、逛街、茶摊、看晚霞、道别、回家。PASS。
