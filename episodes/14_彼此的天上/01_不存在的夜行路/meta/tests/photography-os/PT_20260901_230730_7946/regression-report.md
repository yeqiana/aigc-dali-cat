## 2. 逐帧结果与 5 问

### Frame 01 普通自驾开场

- 谁拍的：P01（男友），驾驶座停车时把手机举过方向盘
- 为什么此刻拍：终于兑现拖了很久的川西自驾，出发后第一次停车，随手记录
- 摄影者在哪里：驾驶座，透过挡风玻璃
- 正在发生什么：SUV 停在盘山公路休息区，前方山脊、云层、盘山路；方向盘、手、后视镜、遮阳板、海拔牌与导航入画
- 人物情绪：轻松、期待
- 生成耗时（估算）：约 60s
- 归一化：1086×1448 → 1080×1350

### Frame 02 白天山坡证据

- 谁拍的：P01，站在车旁
- 为什么此刻拍：停车休息时看到浅色裸岩和山脊缺口，顺手拍下白天基线，山坡上没有路
- 摄影者在哪里：停车带车旁两步，朝对面山坡
- 正在发生什么：下午有云，车头边缘入画，对面山坡裸岩与山脊缺口清晰
- 人物情绪：放松平淡
- 生成耗时（估算）：约 113s（首次横构图被归一化拒绝，重生成竖构图）
- 归一化：1122×1402 → 1080×1350

### Frame 03 晕车停车

- 谁拍的：P01，站在女友侧前方两步
- 为什么此刻拍：女友晕车不舒服，停下车让她吹风，拍下她缓一缓的日常瞬间
- 摄影者在哪里：停车带，副驾车门旁，站立低角度
- 正在发生什么：副驾门开着，女友蹲靠车门吹风，发丝被风吹动，前景车门遮挡
- 人物情绪：担心、心疼
- 生成耗时（估算）：约 70s
- 归一化：1122×1402 → 1080×1350

### Frame 04 第一盏灯

- 谁拍的：P01
- 为什么此刻拍：黄昏远山突然出现一个暖黄光点，本能举起手机拉近拍
- 摄影者在哪里：停车带边沿，背靠车头，朝对面山坡
- 正在发生什么：天快黑，手举手机对准远处光点，画面偏暗、手持抖动、暗部噪点
- 人物情绪：疑惑好奇
- 生成耗时（估算）：约 60s
- 归一化：1122×1402 → 1080×1350
- 测试发现：画面中手机屏幕显示相机界面，物理上不可能由该手机拍出；正式生产需禁止相机 UI 入画

### Frame 05 灯变多

- 谁拍的：P01
- 为什么此刻拍：光点变成一串沿山腰移动的灯队，继续拉近拍想看清是什么
- 摄影者在哪里：同一位置，背靠车头，数码长焦朝山坡
- 正在发生什么：一串暖灯沿山腰缓慢移动、前后保持距离，夜间长焦噪点涂抹、手抖，看不清细节
- 人物情绪：从好奇转向警觉不安
- 生成耗时（估算）：约 50s
- 归一化：1122×1402 → 1080×1350

## 5. 与旧版差异说明

本集是 docs-only 预生产包，从未生成过旧图、旧 Frame 输出、旧 Visual Test；对照口径为启用 Photography OS 前的既有视觉惯例与千寻首轮 VT（仅单帧质感，无摄影者/时刻契约）。

1. 旧：Visual Test 只验证单帧质感与构图；新：Photography OS 逐帧强制 5 问并绑定 Photographer / Moment 契约
2. 旧：前 3 张无开头规则；新：Opening Memory Contract 强制 01-03 建立人物关系和正常生活
3. 旧：构图可漂移为电影感/海报式；新：FIRST_PERSON_CASUAL_SNAPSHOT_V1 全局默认，禁全知第三人称、海报构图、整齐列队
4. 旧：无情绪曲线；新：Emotion Curve 01-05 从平静基线单调爬升至警觉不安
5. 实测：01/02/03/05 真实手机相册感明显增强（反光、遮挡、手部、噪点、树影、生活杂讯）；04 仍有相机 UI 入画的残余 AI 痕迹，是 Photography OS 尚未完全压制的一点

## 6. 结论

Photography OS 对"真实摄影感"的提升成立：5 帧全部回答 5 问，01-03 普通生活基线无异常，异常自 04 进入，情绪曲线爬升；禁止项全 PASS。残留问题 1 个（04 相机 UI 入画），不影响本回归测试结论，正式生产前需补 prompt 约束。
