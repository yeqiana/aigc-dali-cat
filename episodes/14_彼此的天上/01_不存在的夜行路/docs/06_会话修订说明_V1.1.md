## 核心修订

本集认知目标锁定为：**那里有人。**

核心因果链必须清晰为：

我们的车灯闪烁
→ 对面最前方的人停下 / 回头
→ 人主动做出传警动作
→ 后方人群逐步响应
→ 不同位置的人分别遮盖 / 熄灭自己的灯
→ 最后一盏灯由远处的人主动处理后消失

不得表现为“现代灯光触发异世界自动关闭”。

那里白天确实没有路；
昨晚确实不只是灯；
那些人真的对我们的动作作出了反应。
