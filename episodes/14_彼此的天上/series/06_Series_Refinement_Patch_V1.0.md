# 《彼此的天上》Series Refinement Patch V1.0

> 会话执行基线：Story OS V2.0.3.5 + Series Refinement Patch
> 性质：故事层 / 系列层人工修订说明
> 注意：本补丁不生成、不伪造任何 Story Critic、Visual Critic、recent-5、release manifest 等机器证据。

## 1. 系列认知递进锁

五集必须分别完成不同的观众认知升级：

1. EP01：那里有人。
2. EP02：他们也是具体的普通人。
3. EP03：他们有完整的社会和生活。
4. EP04：两边普通人可以在短暂重叠里互相帮助。
5. EP05：这种接触也许以前发生过，但生活最终会继续。

禁止连续两集只重复证明“异常存在”。

## 2. Audience Knowledge Progression Review

每集 Story Lock / Storyboard 复审时必须回答：

- 本集结束后，观众比上一集新知道了什么？
- 这个“新知道”能否仅由上一集内容替代？
- 如果删掉本集，整季认知链是否缺失一个不可替代节点？

若答案表明本集只是重复证明，则不得进入 Storyboard Lock。

## 3. Visual Consumption Diversity Review

连续画面不得只依赖：

- 山谷远景；
- 远处灯点；
- 数码长焦；
- 仅改变景别的同一异常。

优先使用真实生活消费差异：
普通室内、停车带、雨玻璃、生活动作、修屋、牲畜、市场、泥地、粗布、消费级无人机、掉地手机、出租屋电脑回看等。

## 4. EP02 / EP03 强制功能分离

EP02：近距离、个人化、一对一接触。
核心不是“会模仿动作”，而是“对面是具体的人，并有普通家庭关系”。

EP03：主动调查、设备越界、完整社会。
核心不是“又发现有人”，而是“对面有长期稳定的社会生活秩序”。

## 5. EP04 主题锁

EP04 不得做成传统异世界穿越片。

视觉高潮：
同一真实视野内出现现代碎石停车带与另一侧湿土路的自然空间错位。

情感高潮：
双方无法交流，也不理解彼此，但都看得懂“这个人要回去”，因此一边推、一边拉，共同完成救援。

## 6. EP05 收束锁

EP05 不解释异常来源，不给完整世界观答案。

古老记录最多提供一个强线索：
过去的人似乎也曾对某种异常亮物产生长期文化避讳。

不得明确出现：
现代汽车、手机结构图、现代服饰、时间穿越说明、历史档案式答案。

最终落点必须回到普通生活与私人记忆。
