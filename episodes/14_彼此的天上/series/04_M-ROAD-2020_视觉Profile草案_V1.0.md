# M-ROAD-2020｜2020s 川西自驾手机相册纪实 V1.0（草案）

> 用途：替代本系列机械继承 M00 的旧数码年代感。  
> 状态：Visual Lock 前候选 Profile，仍需三张真实校准图 + 独立视觉 Critic。

## 1. 核心

`reality_first + ordinary_life_density + available_light + unposed_capture + causal_imperfection + not_cinematic`

## 2. 时代

2020年代前半段。

设备感：
- 普通智能手机
- 数码长焦裁切
- 消费级无人机
- 普通SUV旅行记录

## 3. 画面

- 默认 4:5 / 1080×1350
- 不做电影宽银幕
- 不做青橙调色
- 不做过度HDR
- 阴雨/低云允许低对比
- 夜间数码长焦允许噪点、涂抹、细节不足
- 手机镜头出现雨滴、反光、轻手抖必须有因果
- 不为了“恐怖”强制压暗

## 4. 人物

- 不是写真
- 不刻意摆拍
- 大量人物只作为生活现场中的局部
- 对面人物不能整齐“群演站位”

## 5. 异常表现

优先：
- 同一地形前后差异
- 真实生活突然出现在不该存在的位置
- 局部接触面
- 同一视野中的空间错位

禁止：
- 发光裂缝
- 粒子特效
- 赛博乱码
- 魔法光环
- 仙侠雾气
- 概念艺术城市

## 6. 三张建议校准

1. EP01：白天下午真实川西停车带 + 同一山坡
2. EP03：雨停后低云山谷 + 普通生活密度的对面聚落
3. EP04：掉地手机低机位、雨滴、动作模糊的救援瞬间

EP04“双空间可读性”另做高风险附加验证。
