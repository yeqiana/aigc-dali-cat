## 二、角色锁

### 2.1 卖梨人 A（第一人称主角）

- 形象：四十岁上下，粗壮晒黑的手，褪色灰褐旧布衣，袖口磨损。
- 出镜：只露手、袖口、肩部局部，不出现清晰正脸。
- 服装：灰褐旧布衣主色贯穿全篇，袖口磨损位置固定。
- 常见动作：系红线、护梨、扒车斗、伸手夺梨、抱断靶、捡梨。
- 情绪线：图 01 警觉 → 图 03/05 愣住 → 图 07/08 急迫 → 图 13/14 确认 → 图 17/20 不安。
- 禁止：变富商、摊贩海报、道士；换服装主色。

### 2.2 异人 B：道士

- 形象：破巾絮衣，只露旧麻布袖口、手、肩头或背影，不做正面肖像。
- 行为：乞梨、吃梨种核、摘梨分众、挥镵砍树、扛树离去。
- 禁止：怪物化、发光、施法特效、仙侠造型、露清晰正脸、被追上或露脸。

### 2.3 功能人物 C：围观者 / 婆婆 / 摊主

- 只出现局部：旧布鞋、衣角、接梨的手、递钱的手。
- 作用：一市粲然转不安的群体背景；不承担解释。

## 五、母题与连续性规则

- 核心母题：梨蒂红棉线。三个载体：车梨的蒂 → 树上梨的蒂 → 断靶断口内的线；三个尺度：一颗梨 → 满树梨 → 整车梨消失加车把被砍。
- 每次复现增加信息：图 01 记号动机 → 图 03/04 同源异常 → 图 10 断口同源 → 图 14/19 系法一致确认 → 图 20 终局重读。
- 红线出现频率：关键转折图必现，过渡图可弱化但不换色、不换系法。
- 第一人称接入：手、袖口、木车边缘、墙角近景、油灯下拨梨。

## 六、禁止项

- 不使用促织的衣线、刻痕、木匣开缝元素。
- 不出现现代物件、发光红线、游戏化、第三人称古装海报、血腥暴力。
- 不解释幻术原理；道士不被追上、不露脸。
- 结尾不开启必须追更的新主线。
