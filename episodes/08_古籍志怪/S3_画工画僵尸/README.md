## 一、篇章定位

杭州画工刘以贤受邻人委托，为一名穿深青黑清代官袍的亡者绘制遗像。尸体极白的光头上只留一根清代长辫，两颊各有一个正红圆圈；画工落下一笔后，尸体同步模仿对应动作，嘴角逐渐出现不对称的怪异微笑，并一步步从床边逼近镜头。他为了完成这桩画工活继续作画，最后只能叫抬棺人用苕帚将尸体拂倒、重新入棺。

本篇的恐怖点不是僵尸突然扑脸，而是一个可以被数出来的动作规则：**我画一笔，尸体学一笔。**
