## 一、篇章定位

杭州画工刘以贤受邻人委托，为一名穿清代官服的亡者绘制遗像。楼上明明只有一具尸体，画工落下一笔后，官服尸体却同步模仿对应动作，并一步步从床边逼近镜头；他为了完成这桩画工活继续作画，最后只能叫抬棺人用苕帚将尸体拂倒、重新入棺。

本篇的恐怖点不是僵尸突然扑脸，而是一个可以被数出来的动作规则：**我画一笔，尸体学一笔。**

## 二、当前锁定

- 节奏模式：**混合模式（鼠鼠主行动 + Zayn视觉扩张）**

- 主角：杭州画工刘以贤，第一人称只露手、袖口、画纸、画笔和局部身体
- 现实任务：在抬棺人返回前完成遗像，取得画工钱
- 关系人物：死者的成年儿子；负责请画工、安排棺材和见证结果，不解释异常来源
- 核心母题：清代官服僵尸、湿墨黑线与尸体动作同步模仿，距离逐步逼近
- 终局方式：苕帚制服、尸体入棺、遗像留下无法确认由谁完成的最后一笔
