## 二、角色锁

### 2.1 角色 A：画工刘以贤

- 年龄：四十岁上下，成年男性。
- 身体识别：粗糙、带画工茧子的双手；手指关节明显；不做英雄化身材。
- 服装：褪色灰褐旧布长袖，袖口磨损、起毛，图 01/03/10/20 保持同一主色和磨损位置。
- 露出方式：第一人称只露双手、袖口、局部前臂、画纸和画笔；不出现清晰正脸。
- 行动轨迹：拿画纸进入 → 落笔试探 → 继续作画 → 后退护住画纸 → 指挥抬棺人 → 扶住完成遗像。
- 情绪轨迹：拿钱办事 → 迟疑 → 强撑 → 惊恐仍继续 → 现场应对 → 不敢确认最后一笔。
- 禁止：现代衣物、干净文人长袍、正面肖像、第三人称旁观、畸形手、额外手指。

### 2.2 角色 B：死者

- 身份：邻人已故成年男性，原文事件中的尸体，不扩写姓名、职业和死因。
- 服装：深青黑清代官袍、硬挺高领、旧官帽和低饱和官补暗纹，颜色和帽形不随镜头改变。
- 状态递进：
  - 图 01/02：平躺，完全静止。
  - 图 03/05/06/07：床边半起，手指、手腕跟随画工，距离比图 01 更近。
  - 图 09/10/12/14：肩膀、躯干和头部逐步复制，尸体越过床沿并向镜头前压近。
  - 图 17/18/19：被苕帚拂倒并重新入棺。
  - 图 20：棺材关闭，尸体不在棺外出现。
- 面部：可以辨认成年人轮廓，但不做腐烂、血腥、尖牙、发光眼睛和影视僵尸妆。
- 行动规则：画工先动，尸体后复制同一部位；每次复制都增加靠近镜头的距离，不独立完成没有画工动作对应的攻击。

### 2.3 角色 C：成年委托人

- 身份：死者的成年儿子，邀请画工完成遗像。
- 露出方式：手、袖口、门帘、楼梯口局部和后退动作；不承担解释异常的功能。
- 服装：深灰或褐色旧布衣，颜色比画工更暗，避免和画工袖口混淆。
- 行动轨迹：引画工进房 → 楼下等待 → 在门边询问 → 看见官服僵尸压近后后退 → 配合抬棺人封棺。
- 禁止：正面清晰肖像、巫者造型、符咒、预言式台词、突然变成主要恐怖实体。

### 2.4 角色 D：抬棺人

- 身份：完成现实任务闭环的功能群体。
- 露出方式：竹苕帚、手、鞋、衣角和局部肩膀；不做整齐群像。
- 行动轨迹：脚步逼近 → 带苕帚上楼 → 试探靠近 → 合力拂倒 → 抬棺入棺并封闭。
- 禁止：现代清洁工具、武器化动作、血腥搏斗、群体海报构图。

## 三、场景锁

### 3.1 场景 A：楼上死者房间

- 时代：清代杭州邻宅。
- 固定元素：旧木床、白灰床褥、木窗、粗木门框、低亮油灯、木楼梯入口、墙面暗部；官服僵尸的深青黑轮廓是房间里的主要视觉焦点。
- 空间关系：床在窗下或靠墙，油灯在床侧小案，楼梯和门框承担第一人称遮挡，棺材后段从楼梯侧进入。
- 光线：冷灰窗光压住暗部，低亮暖油灯只照画笔、墨线、尸体动作、苕帚、棺材缝和手部。
- 材质：旧木、官袍布料、官补暗纹、旧官帽、纸、墨、竹苕帚、棺材木纹；不出现现代光滑材料。
- 时间变化：图 01/03 清冷白灰；图 10 暗部加深；图 17/20 转为冷蓝黄昏混暖灯。

### 3.2 场景 B：楼梯与门口

- 作用：连接画工的在场视角、委托人的反应和抬棺人进入。
- 构图：门框和楼梯边缘常切入画面，不使用平整全景。
- 信息：脚步、后退的手、苕帚和棺材角度依次增加现场压力。

### 3.3 场景 C：封棺后的房间

- 作用：终局闭合，不重新开启新的超自然任务。
- 固定元素：合上的棺材、倒下的竹苕帚、遗像、空床、油灯和画工双手。
- 图 20 关键：画笔离开纸面，遗像只突出一条与官服僵尸最后手势对应的新墨线和墨珠；棺材和苕帚不可被裁掉。

## 四、道具锁

| 道具 | 固定特征 | 使用节点 | 连续性要求 |
|---|---|---|---|
| 毛笔 | 深褐木杆、黑色笔毫、中等长度 | 图 01～19 | 画工先动，不能悬空无手 |
| 遗像纸 | 粗糙米灰色纸，略卷边，竖幅 | 图 01～20 | 图 03 从官服和手部湿墨线开始，图 20 完成但保留一条新线和墨珠 |
| 墨碟 | 小型旧陶碟，黑墨，不发光 | 图 01、03、10 | 位置可变但不消失 |
| 油灯 | 玻璃灯罩或旧灯盏，低亮暖光 | 全篇 | 只作局部光源，不变成现代灯具 |
| 木床 | 深色旧木，白灰床褥 | 图 01～18 | 尸体状态变化必须在同一床铺上可回读 |
| 竹苕帚 | 细竹枝束成的旧扫帚，木柄 | 图 15～20 | 图 20 倒在床边，不能变成武器或现代扫把 |
| 棺材 | 深色粗木，简单合盖，木纹明显 | 图 15～20 | 图 20 必须关闭，尸体不在棺外 |

## 五、视觉母题锁

### 5.1 核心规则

`画笔动作先发生 → 遗像出现湿墨线 → 官服僵尸对应部位后复制 → 每次复制都更靠近镜头`

### 5.2 递进规则

- 第一次：画笔与尸体食指同向，证明存在同步。
- 第二次：画笔与尸体手腕、前臂同向，证明不是偶然抽动。
- 第三次：画工继续落笔，官服僵尸越过床沿压近镜头，规则开始影响现实空间和距离。
- 终局：尸体入棺，遗像保留一条新墨线，事实闭合但原因留白。

### 5.3 禁止变化

- 不增加第二种超自然规则。
- 不让尸体自行追逐、攻击或离开房间。
- 不用发光墨线、符咒、血迹或镜面倒影解释母题。
- 不把遗像画成完整的现代肖像或艺术品展示图。

## 六、图像质量与提交边界

- 测试图和正式图目标比例 9:16；生成器原始图可为 941×1672，最终成片阶段再统一到 1080×1920。
- `images/`、`publish/` 和中间图像默认不进入 Git。
- 只有未来单独生成并确认的角色参考图，才允许进入 `assets/characters/` 白名单路径。
- 任何图像生成结果先视觉检查，再决定是否保留；不以文件名或数量代替验收。
