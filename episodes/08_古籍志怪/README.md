> - 系列状态：**S1《促织》、S2《种梨》均已发布；字幕标准按种梨定稿（制作规范 5.4）固化**
> - 系列定位：从中国古代志怪小说、传奇和笔记中提炼单篇事件，改编为古代第一人称图文故事。
> - 当前首篇：`S1_促织/`

## 一、系列定位

本系列不是把现代职业故事换成古装，而是保留古籍志怪的叙事速度和因果结构：

`现实压力/日常任务 → 异物或异人直见 → 规则或禁忌 → 主角破禁 → 异常快速升级 → 人物得到结果或付出代价 → 现实余波`

古籍只作为故事母题和事件骨架来源，正式成片必须重新设计第一人称视角、视觉母题、人物关系和结尾物证，不直接复刻现代影视、动画、游戏角色或竞品画面。

## 二、视觉形态

- 方向：古代第一人称见证视角。
- 在场方式：手持竹笼、灯火、铜镜、门帘、衣袖、车轿、井沿、案几和近景遮挡建立拍摄者位置。
- 暂不出现现代手机、现代设备和现代职业场景。
- 画面仍要求主体偏位、局部遮挡、自然暗光、混合色温和可解释的拍摄位置。
- 当前形态是本系列的专属方案，不能视为替换全账号“现代手机图文左滑”规范；首篇必须先做视觉测试。

## 三、统一节奏

## 五、生产边界

- 默认每篇 20 张，最多 25 张。
- 第 3 张前必须直接看见异常，不能只靠古文字幕、档案或旁白说明。
- 每篇只养一个主要异常母题，至少规划 3 个载体和 3 个尺度。
- 古代身份、服装、建筑和道具必须服务于行动，不能连续堆叠古风场景。
- 单篇必须完成开篇任务和人物结果；异常来源可以留白。
- 结尾必须留下可拍摄的现实物证，并重新解释至少两张前图。
- 正式分镜前先完成图 01、03、10、20 四张视觉准入测试。
- 字幕按"种梨标准"（制作规范 5.4）：极短第一人称情绪句（单图 1~18 字），吐槽/自嘲/慌张 OS，因果交给画面，终局金句制造评论区钩子。
