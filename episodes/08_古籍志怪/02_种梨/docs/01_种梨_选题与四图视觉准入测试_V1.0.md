## 一、原作底本与改编定位

原文关键句：

> 道士乃即树头摘赐观者，顷刻向尽。已，乃以镵伐树，丁丁良久方断，带叶荷肩头，从容徐步而去。……始顾车中，则梨已空矣。又细视车上一靶亡，是新凿断者。……转过墙隅，则断靶弃垣下，始知所伐梨本，即是物也。一市粲然。

保留的物证链（原文本有）：**空车 + 断靶弃墙角 + “梨皆己物”**。

改编定位：

- 调性转换：原作“一市粲然”是嘲笑吝啬的喜剧；改编为**不安余波**——卖梨人发现记号出现在不该出现的地方，笑点全部换成“记号同源”带来的寒意。
- 原创化装置：**红线记号**（原作没有）。卖梨人给自家梨蒂系红线防偷，道士种核长出的满树梨全部带红线，断靶内芯也露出红线。红线把“同源”变成静音可读的物理证据。
- 边界声明：红线记号与本系列促织旧版已删除的“衣线转移”**完全不同**：促织衣线是旧版道具，已剔除；种梨红线是本文的原创记号，只在本篇生效。

## 二、核心异常母题

- 核心形态：梨蒂上的红棉线。
- 材质 / 颜色：暗红棉线，画面唯一亮色。
- 运动 / 生长规则：记号随梨转移；梨树即车把，断口同源复现。
- 三个载体：车梨的蒂（图 01）→ 凭空长出的树梨（图 03 / 06）→ 断靶内芯红线（图 10 / 12 / 20）。
- 三个尺度：一颗梨核 → 满树梨 → 整车梨消失 + 车把被砍。

视觉记忆句：

> 每颗凭空长出来的梨，蒂上都系着我今早给自家梨系的红线；最后我的车把被砍断，断口里露出同一根红线。

## 四、结构与节奏

### 鼠鼠节奏 S1-S8

- S1 日常代入：集市卖梨，给梨系红线做记号，生意尚可。
- S2 关系引路：破巾絮衣道士车前乞梨被拒，摊主劝、婆婆围观。
- S3 异常直见：道士种核，眨眼成树，枝头梨蒂带红线。
- S4 规则建立：树上每颗梨都带红线——记号不是巧合。
- S5 越界触发：卖梨人挤回自己车边，发现梨在变少，伸手想夺回。
- S6 可见对抗：道士砍树，树桩断面露出红线；车把齐根断掉。
- S7 人物闭环：卖梨人追到墙角，只捡到弃在墙根的断靶。
- S8 异常余波：他捏着分到的梨，蒂上红线与自己车上的系法一模一样。

### Zayn 视觉节奏 Z1-Z8

- Z1 可信进入：木车、黄梨、红线、市集晨光。
- Z2 母题直见：图 03 种核成树，梨蒂带红线（异常直见）。
- Z3 同源复现：满树梨带红线 → 围观者手中梨带红线。
- Z4 规律确认：红线只出现在“他的梨”上。
- Z5 人物卷入：卖梨人抢梨，卷入道士的幻术。
- Z6 尺度扩张：一棵树 → 整车梨消失 → 车把被砍。
- Z7 事件闭合：墙角断靶，木纹与车把一致。
- Z8 终局重读：断靶断面红线 + 手中梨红线，重读图 01 / 03 / 10。

## 五、四图准入测试

> 出图以 `docs/02_种梨_四图视觉准入测试与提示词_V1.0.md` 为准；本节省略版提示词不再单独维护。

### 图 01：现实任务 + 封面异常

- 功能：我是谁（卖梨人）、我在做什么（给梨系红线作记号）、哪里不对（道士的手停在车前）。
- 画面要求：木车、黄梨、蒂上红线、道士破巾絮衣手部；异常可做封面记忆点（一整排系红线的梨）。
- 中文生成提示词：古代集市清晨，卖梨木车前第一人称近景，粗糙成年男性的手将一根暗红棉线系在梨蒂上，木车里一排排黄梨的蒂都系着同样的红线，另一只破旧麻布袖口的手停在车前似在乞讨，身后灰蒙布棚与人群虚化，低照度自然晨光、偏斜手持、真实颗粒、竹篾木车材质，不出现清晰可读现代文字。
- 负向提示词：现代物件、手机、电灯、游戏 UI、正面清晰脸、对称海报、HDR、影楼古装照、道士发光、法阵光效、红色特效。
- 不通过表现：只有集市氛围没有红线记号；红线像装饰而不是“记号”。

### 图 03：异常直见

- 功能：读者直接看见异常——种下的核长出带红线的梨，不需要字幕解释。
- 画面要求：泥地土坑、梨核、破土小树、枝头梨蒂带红线；红线是画面唯一亮色。
- 中文生成提示词：古代街边泥地第一人称近景，破巾絮衣道士的手把一粒梨核按进土坑，坑边陶碗残汤，小树已长到齐腰高，枝头挂着几颗黄梨，每颗梨蒂都系着同一根暗红棉线，围观者的旧布鞋与衣角在画面边缘，冷灰市集光混一盏油灯、偏斜手持、真实颗粒，红线为唯一亮色，不出现清晰可读现代文字。
- 负向提示词：现代物件、发光梨、巨大化梨树、法阵、符咒、道士清晰正脸、舞台聚光、游戏化成长动画。
- 不通过表现：梨树只是普通长出来，红线看不清或不在梨蒂上。

### 图 10：不可逆物理变化

- 功能：异常真实影响现实——树被砍断，断面露红线；车把断、车梨空大半。
- 画面要求：被砍倒的梨树横地，树桩断面木纹里嵌着一根红线；背景卖梨人扑向断把空车。
- 中文生成提示词：古代街角第一人称近景，被砍倒的梨树横在地上，树桩断面木纹里嵌着一根暗红棉线，道士的破麻布袖口刚离开断口，背景里卖梨人扑向自己的木车，车把齐根折断、车斗里梨少了大半，市集人群退开，冷灰天光、真实木纤维与线头、偏斜手持、低照度纪实，红线为唯一亮色，不出现清晰可读现代文字。
- 负向提示词：发光树桩、魔法光效、道士施法、游戏道具掉落、巨大化树木、血迹。
- 不通过表现：树桩没有红线；画面只是“树倒了”而没有车把断裂的物理后果。

### 图 20：现实残留 + 终局重读

- 功能：留下可拍摄物证（墙角断靶 + 手中梨），红线同源，重读图 01（系红线）、图 03（树上梨带红线）、图 10（断口红线）。
- 画面要求：断靶弃于墙角、断口露红线；卖梨人手里捏着一颗梨，梨蒂红线一致；身后空车。
- 中文生成提示词：古代小巷墙角第一人称近景，被丢弃的半截车把横在墙根，断口里露出一根暗红棉线，卖梨人粗糙的手捏着一颗黄梨，梨蒂上系着同一根红棉线，身后是梨已空空的木车与暮色市集，冷蓝黄昏光混一盏暖油灯、真实颗粒、低照度、偏斜手持，红线与空车为画面重心，不出现道士。
- 负向提示词：道士再出现、未完待续感、发光、特效、正面清晰脸、现代物件。
- 不通过表现：结尾只有“空车”没有断靶红线；红线与图 01 / 03 系法不一致，读者无法回读。

## 七、风险

- 喜剧转悬疑：必须用“记号同源”替代“好笑”；“一市粲然”改成围观者手里的红线，不能拍成搞笑小品。
- 树梨 / 车把物证是全文最值钱资产，任何一图都不能弱化红线或断靶。
- 道士不能怪物化、发光、施法，保持“人间异人”；破巾絮衣是形象记忆点。
- 红线系法与系法细节（打结位置、长度）需在角色 / 道具锁定中固定，避免 20 张里漂移。
- 四图准入通过前，不直接写 20 张正式分镜。
