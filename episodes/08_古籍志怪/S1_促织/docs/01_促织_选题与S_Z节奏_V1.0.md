## 一、改编边界

本篇只提炼原作中的贡虫压力、家庭困境、异虫出现和身份余波，重新设计第一人称画面、母题规则和结尾物证。不直接复述原文段落，不复刻现代影视造型、台词、镜头或竞品画面。

古代第一人称是本系列拟定的专属视觉支线：通过手持竹笼、灯火、门帘、衣袖、井沿、案几和近景遮挡建立拍摄者在场，不出现现代手机。该风格尚未经过图片测试，不能替代全账号现有的现代手机随手拍规范。

## 二、选题卡

### 2.1 一句话故事

华阴县里正成名被限期征收贡虫，家产已尽仍抓不到合格蟋蟀；儿子落井昏迷后，家里出现一只行为像“认得他”的异虫，成名靠它完成交贡，却无法确认孩子和蟋蟀之间究竟发生了什么。

### 2.2 基础设定

| 字段 | 设计 |
|---|---|
| 地点 | 古代县乡、成名旧宅、荒墙、旧井、县衙斗虫场、贡虫押运路 |
| 主角 | 成名，家产将尽、被强行摊派交贡虫的里正 |
| 现实任务 | 在限期内抓到合格斗虫并交入县衙木匣 |
| 情绪锚点 | 第一次差事就可能拖垮全家，成名不想让妻子和孩子继续承受差役压力 |
| 关系人物 | 妻子；共同承受现实压力，推动求虫，但不解释异常来源 |
| 越界者 | 成名本人主动搜虫、开笼、追到井边并把异虫带入斗虫场 |
| 异常核心 | 黑褐蟋蟀、竹笼、井沿和孩子衣线之间发生同源转移 |
| 任务结果 | 贡虫按期交付，差役暂缓，家庭获得短暂喘息 |
| 人物结果 | 孩子醒来，但只记得自己在井边听见“有人在笼里敲门” |
| 现实残留 | 空竹笼内壁三道刻痕、孩子袖口缺一根线、贡虫木匣自行打开 |

### 2.3 标题抓力

推荐标题：

> 我叫成名，是华阴县被逼着交贡虫的里正，要在十天内抓到一只斗虫，可儿子落井醒来后，家里那只蟋蟀一直停在他床边。

短标题：`会认人的蟋蟀`

| 维度 | 得分 | 依据 |
|---|---:|---|
| 代入速度 | 2.8/3 | 身份、差事、期限和家庭压力明确 |
| 异常具体度 | 3.0/3 | “蟋蟀一直停在孩子床边”可直接画出 |
| 信息密度 | 3.7/4 | 贡虫任务、落井后果、蟋蟀异常和人物关系同时成立 |
| 总分 | **9.5/10** | 达到进入视觉测试的门槛 |

### 2.4 选题准入

- 地点有功能：县衙差役、里正宅、荒墙、旧井和斗虫场共同构成古代社会入口。
- 动机够日常且够痛：交贡虫是具体差事，失败会影响全家生计。
- 异常够具体：空竹笼、孩子衣线、蟋蟀敲击和床边停留可以被单图看懂。
- 真相可争论：蟋蟀是孩子的魂魄、借体异物，还是极端压力下的误认。

## 三、反同质化四把锁

| 锁 | 本篇设计 | 与已有高发形态的差异 |
|---|---|---|
| 越界者 | 成名本人主动进入荒墙、打开砖缝、掀开笼盖 | 不是长辈越界、主角旁观救援 |
| 关系人物 | 妻子是共同承受压力的伴侣 | 不是父亲、导师、哥哥带路 |
| 母题逻辑 | 异虫与人的身份/衣线发生寄存和转移 | 不是环境复制或替换住户 |
| 闭环方式 | 交贡完成、家境短暂改变、笼中物证留存 | 不是安全绳救援、认错、异常跟回家 |

四把锁全部改变，当前未发现换皮阻断项。

## 四、核心视觉母题

### 4.1 母题定义

`黑褐蟋蟀 + 湿黑甲壳/土黄粉尘 + 只在笼门、井沿和床沿之间跳跃，并逐次带走人物衣物的一根线`

### 4.2 剧情承载规则

1. 蟋蟀第一次出现时是普通大小，但敲击节奏和孩子敲床的节奏相同。
2. 每次蟋蟀跨过一个边界，都会带走一根人的衣线：笼门、井沿、床沿、斗虫台。
3. 蟋蟀不直接攻击人物；它通过移动、鸣叫和衣线转移让成名不断做出判断。
4. 终局衣线与孩子衣袖缺口吻合，但不直接证明“孩子变成了蟋蟀”。

### 4.3 载体与尺度

| 尺度 | 载体 | 新增信息 |
|---|---|---|
| 单体细节 | 蟋蟀、竹笼、衣线、井沿 | 异常第一次直见和身份线索 |
| 人物/房间 | 孩子床边、妻子收衣、成名手持竹笼 | 异常进入家庭并改变人物判断 |
| 空间/群体 | 斗虫场、县衙、贡虫押运路 | 异虫由家庭事件扩大到社会任务 |

## 八、评论区分裂钩子

### 事实层

- 孩子袖口的线究竟是什么时候断的？
- 竹笼里的三道刻痕是蟋蟀留下的，还是孩子醒来后留下的？

### 解释层

- 蟋蟀是孩子的魂魄寄存，还是成名一家在极端压力下误认了巧合？
- 巫者是在帮他们找虫，还是早就知道井边会发生什么？

字幕不直接提出这些问题，交给画面证据让读者自行争论。

## 十、风险与结构结论

- 不使用血腥肢解、儿童伤害细节或真实伤亡呈现；落井和昏迷用遮挡、井沿、空床和物件后果表达。
- 蟋蟀不做巨大化怪物，不做游戏角色化，不使用《植物大战僵尸》的角色、植物和敌人元素。
- 古代第一人称画面不能退化为第三人称古装海报；必须通过手、竹笼、灯火、衣袖和近景遮挡保持在场。
- 本篇新增“衣线转移”和“边界跳跃”规则，这是原创改编设计，不冒充原文事实。

**结构结论：有条件通过，允许进入四张视觉准入测试；不允许直接进入完整分镜、生图或发布。**

通过条件：

1. 图 01 和图 03 静音状态下能看懂“交贡虫”和“蟋蟀异常”；
2. 图 10 能看见主角主动破禁并造成物理后果；
3. 图 20 的空笼、衣线和孩子状态能形成至少两种合理解释；
4. 古代第一人称画面不退化为第三人称古装海报；
5. 蟋蟀母题能在 3 个以上载体和 3 个尺度上保持连续。
