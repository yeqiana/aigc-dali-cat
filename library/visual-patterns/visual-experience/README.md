## 1. 导演镜头、光影与异常隐藏

- 权威来源：`standards/导演镜头光影与异常隐藏规范_V1.0.md`
- 机器语法：`standards/directing_grammar_v1.json`
- 登记状态：`active_subordinate`（物理文件保留在 `standards/`，未移动）

可复用经验要点（非权威）：

- 借电影的结构语言——负空间、深景异常、框中框、前景遮挡后揭露、反射第二信息层、明暗边界揭露——但必须翻译成故事内真实摄影者能拍到的现实条件（门框、窗框、车窗、镜子、水面、路灯、屏幕光、墙体）。
- 景别与机位覆盖：全篇至少 1 张 extreme_wide/wide 与 1 张 close/detail，覆盖 3 种以上景别，同景别连续不超过 2 张。
- 「地点可回访，机位不可复印」：同一精确拍摄位置 `scene_position_id` 全篇不重复。

适用场景：构图与信息揭露设计、镜头规划参考。

## 2. 环境物理与异常放大

- 权威来源：`standards/环境物理与异常放大规范_V1.0.md`
- 登记状态：`active_subordinate`（物理文件保留在 `standards/`，未移动）

可复用经验要点（非权威）：

- Weather 是物理条件，不是滤镜；环境要能落到像素（ground_state / visibility / wind / precipitation / 材质等）。
- 异常可以比现实大很多，但必须靠尺度参照与前后级差在像素中成立，不能只靠字幕宣称「更大」。
- 条件效应只在满足物理前提时出现（如热浪需「室外 + 长视距 + 被加热地表」），不做全片滤镜化。

适用场景：环境/异常冲击设计、天气物理表现参考。

## 3. 真实性与共享风格锚点

- 权威来源：`standards/真实性与共享风格锚点规范_V1.1.md`
- 登记状态：`active_subordinate`（物理文件保留在 `standards/`，未移动）

可复用经验要点（非权威）：

- 把「真实私人记录感」从审美感觉升级为可复查项：普通相册四问、七项摄影红旗、结构化逐图审查字段、缺陷因果判断。
- 本主题只维护上述真实性判定，不定义校准张数、返修次数、发布张数等——那些由主规范唯一维护。

适用场景：真实性提示词约束、逐图审查参考。

## 4. 设备物理档案与参考预算

- 权威来源：`standards/设备物理档案与参考预算规范_V1.0.md`
- 登记状态：`active_subordinate`（物理文件保留在 `standards/`，未移动）

可复用经验要点（非权威）：

- 统一母版（M00）回答账号共同视觉语言；Capture Profile（内置 CP01–CP08）回答这个年代、这个设备实际怎样成像；设备物理与故事年代高于统一滤镜。
- 正式单帧参考默认 0–1 张，2 张为默认上限，超过需写不可替代理由。

适用场景：设备成像质感与参考预算提示词参考。
