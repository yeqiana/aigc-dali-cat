# Visual Pattern Library

日期：2026-09-11

## 用途

收集从历史人工创作中沉淀的视觉与提示词经验，作为可复用的 Pattern Source，
用于指导新的创作生成，而不是充当生产门禁规范。

## 定位

- 不直接进入生产门禁：validate / machine_gate / evidence_gate 不读取本目录。
- 供 Agent Prompt Builder / Visual Agent 构建提示词时参考。
- 来源于历史人工创作经验（V2 时期模板、镜头光影、环境物理、真实性锚点等）。
- 本目录不是 Production Standard，不建立第二权威。

## 冲突处理

本目录内容与 `standards/制作规范_正式版.md`（唯一权威规范）及其从属规范冲突时，
一律以 `standards/` 下的权威规范为准。

## 目录

- `documentary-realism/`：现实侵入式伪纪录片通用提示词模板。

## 边界说明

`standards/` 中仍在 `AUTHORITY_INDEX.json` 登记为 `active_subordinate` 的规范
（导演镜头光影、环境物理与异常放大、真实性与共享风格锚点、设备物理档案与参考预算）
本目录仅登记其“经验来源”定位，物理文件仍保留在 `standards/`，未被移动。
